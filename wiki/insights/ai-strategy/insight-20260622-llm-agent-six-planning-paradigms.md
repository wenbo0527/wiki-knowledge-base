# LLM Agent 六大规划范式深度解析：从推理增强到执行闭环的架构演进

> 🕵️ **Nick 摘要洞察**：这是 Agent 设计层的"分层架构全景图"——内层推理（CoT/ToT/GoT）+ 外层执行（ReAct/Reflexion/Plan-and-Execute）。文博 Agent 团队设计 Loop Engineering 时可对照本框架选型。

---

## 🧠 核心概述：Agent 规划能力的双层架构

LLM Agent 的规划能力是区分传统 Chatbot 与智能 Agent 的核心标志，其本质分为**内层思维过程规划**（推理结构层面）和**外层行动序列规划**（执行循环层面）两个独立层级。前者优化模型内部推理逻辑，后者定义外部交互流程，二者协同构成 Agent 的完整决策体系。

自主智能 Agent 的四大核心能力架构为：**感知（Perception）→ 规划（Planning）→ 记忆（Memory）→ 行动（Action）**，其中规划模块是决策中枢，直接决定复杂任务处理能力上限。

---

## 🔍 推理层规划范式：从线性链到图结构的演进

### （一）CoT（思维链，2022 Google）：线性推理基石
- **核心原理**：将复杂推理拆解为多步串行递进的子推理过程，通过显式输出中间步骤降低单次推理负荷，激活模型**涌现推理**能力。
- **两种形态**：
  - **Few-shot CoT**：通过 3~8 组样本示例实现垂直场景定制化推理
  - **Zero-shot CoT**：仅需添加 `Let's think step by step` 触发指令的通用方案
- **缺陷**：单链路不可逆、单点错误全局传导，无法处理多分支问题

### （二）Self-Consistency（自一致性）：多路径投票优化
- **核心改进**：通过调高 temperature 参数生成多条独立 CoT 推理链，采用**多数投票原则**筛选最优答案
- **优势**：低成本提升推理鲁棒性，有效规避单路径偶然错误
- **局限**：路径间无信息交互，算力资源浪费严重，推理时延随路径数 K 线性增长

### （三）ToT（思维树，2023 Yao）：树形搜索规划
- **突破创新**：将推理过程建模为**马尔可夫决策过程（MDP）+ 启发式搜索**，实现多路径探索与回溯
- **四大环节**：
  1. **扩展（Expansion）**：生成多个候选子思路
  2. **评估（Evaluation）**：量化分支可行性与成功概率
  3. **选择（Selection）**：保留高潜力分支（BFS/DFS/束搜索）
  4. **回溯（Backtracking）**：死胡同自动回退切换分支
- **适用场景**：24 点运算、填字游戏、复杂博弈推理等多方案决策场景

### （四）GoT（思维图，2023 Besta）：图结构高阶推理
- **核心突破**：引入**思维聚合（Aggregation）算子**，支持多分支结论合并收敛
- **结构优势**：以节点为顶点、逻辑依赖为有向边，构建任意有向图拓扑结构
- **超越 ToT**：在 LLM 任务得分上比 ToT 提升 62%，算力消耗降低 31%

> 📌 **Nick 洞察**：CoT → Self-Consistency → ToT → GoT 演进路径清晰——从"单链线性"到"多链并行"到"树形搜索"到"图聚合"。**文博 Agent 团队 Loop Engineering 设计可对照选型**。

## 🔁 执行层规划范式：从静态规划到动态反思

### （五）ReAct（Reason + Act，2022 Yao）：思考-行动交错循环
- **核心范式**：将推理与行动纳入**统一循环框架**，形成 **Thought → Action → Observation** 三段式闭环
- **核心机制**：
  - **Thought（思维）**：分析当前状态，决定下一步行动
  - **Action（行动）**：调用工具或执行操作
  - **Observation（观察）**：获取环境反馈，更新内部状态
- **关键优势**：
  - 推理过程**可解释可追溯**
  - 实时获取外部信息，避免幻觉问题
  - 支持多步交互决策
- **局限**：受上下文窗口限制，多轮交互成本高

### （六）Reflexion（自我反思，2023 Chen）：记忆驱动的迭代优化
- **核心理念**：引入**反思记忆模块**，Agent 通过自然语言反思失败经验，形成可复用的学习沉淀
- **三大组件**：
  1. **Actor（执行器）**：基于 ReAct 范式生成行动
  2. **Evaluator（评估器）**：对行动结果打分
  3. **Self-Reflection（自反思）**：生成文本反思，存入记忆库
- **优势**：跨任务持续学习能力，复杂决策场景表现提升显著
- **挑战**：反思质量高度依赖 LLM 自我评估能力，反思机制设计复杂

## 📊 双层范式对比分析

| 维度 | 推理层（CoT/ToT/GoT） | 执行层（ReAct/Reflexion） |
|:---|:---|:---|
| **核心目标** | 提升单次推理质量 | 优化多步交互效率 |
| **关注重点** | 思维过程结构化 | 行动-反馈闭环 |
| **资源消耗** | 算力密集（多路径） | 上下文密集（多轮） |
| **典型场景** | 数学证明、复杂规划 | 工具调用、网页浏览 |

## 🎯 实战选型指南

### 决策树
```
任务复杂度评估
├─ 简单推理 → Zero-shot CoT
├─ 中等复杂 → Few-shot CoT + Self-Consistency
├─ 多方案决策 → ToT（树搜索）
└─ 多分支聚合 → GoT（图推理）
       │
       ↓ 是否需要外部交互
       ├─ 否 → 推理层范式独立使用
       └─ 是 → 叠加执行层
              ├─ 单次交互 → ReAct
              └─ 长期学习 → Reflexion
```

### 性能基准
- **HotpotQA 多跳问答**：CoT 提升 30%，ToT 再提升 7-15%
- **ALFWorld 任务规划**：ReAct 比 Act-only 提升 34%
- **HumanEval 代码生成**：Reflexion 通过反思将 Pass@1 从 65% 提升至 89%

## 🔮 演进趋势

1. **推理-执行融合**：下一代范式将打破双层架构，实现"边推理边执行"的无缝衔接
2. **多模态扩展**：规划能力从纯文本扩展到图像、视频、音频的多模态场景
3. **元学习集成**：Agent 自动学习"何时用何种规划范式"，实现自适应切换
4. **群体智能**：多 Agent 协同规划，单一 Agent 的双层架构升级为群体决策网络
