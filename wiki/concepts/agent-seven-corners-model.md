> **框架来源**：基于文博分享的Agent能力评估方法论
> **创建时间**：2026-04-29
> **状态**：已实装

---

## 一、核心理念

**研究员的六芒星，本质上就是Agent应该具备的六种能力。**

Agent要成为研究员的"数字分身"，必须能复刻这些能力框架。

**关键差异**：
- 研究员 = 人的能力（认知能力）
- Agent = 系统能力（技术实现）

---

## 二、Agent七角能力模型

| 角位 | 能力名称 | 核心要求 | 技术实现关键 |
|------|---------|---------|------------|
| 第1角 | 目标解析能力 | 理解模糊指令，拆解为可执行任务链 | 意图识别+任务规划引擎 |
| 第2角 | 记忆系统 | 短期-任务-长期三层记忆 | 向量数据库+状态管理 |
| 第3角 | 人机协同能力 | 主动建议+关键确认+适时干预 | 主动交互+规则引擎 |
| 第4角 | 自我检查机制 | 识别幻觉边界+信息溯源+置信度标记 | 验证引擎+溯源系统 |
| 第5角 | 信噪比判断 | 可信度排序+降噪处理+摘要压缩 | 过滤算法+压缩引擎 |
| 第6角 | 结构化输出 | 按场景定制格式+可复用成果 | 模板引擎+知识沉淀 |
| 第7角 | 自主执行能力 | 规划-执行-验证-调整-交付闭环 | 工具调用+执行引擎 |

| 维度 | 核心要求 |

| **萃取沉淀** | 快速压缩信息、提炼核心要点、沉淀高价值碎片 |
| **洞察产出** | 预判、底层规律、隐性逻辑、策略级启示 |

## 四、七角 vs 六芒星对照

| 研究员六芒星 | Agent七角 | 关系 |
|------------|----------|------|
| 问题定义能力 | 目标解析能力 | Agent必须是研究员意图的"理解者" |
| 知识管理能力 | 记忆系统 | Agent必须是研究员知识的"承载体" |
| AI协作能力 | 人机协同能力 | Agent必须是研究员的"协作伙伴" |
| 批判验证能力 | 自我检查机制 | Agent必须具备验真边界意识 |
| 信息过滤能力 | 信噪比判断 | Agent必须能降噪和提纯 |
| 真理表达能力 | 结构化输出 | Agent必须能交付可复用成果 |
| — | 自主执行能力 | Agent特有的"行动闭环" |

**核心洞察**：Agent的七角，本质上是研究员六芒星的"技术实现版"，外加一个"自主执行"的闭环能力。

## 五、七角详解

### 第1角：目标解析能力

**定义**：理解模糊指令，拆解为可执行任务链

**具体要求**：
- 能理解模糊指令，并转化为可执行的任务链
- 能识别用户的真实意图，不是字面需求
- 能主动追问澄清，而不是盲目执行

**技术实现**：
```
用户: "帮我分析这个市场"
  ↓
Agent解析:
  1. 数据检索任务：获取行业增长率、关键指标
  2. 因素分析任务：识别政策/技术/市场变化
  3. 关联验证任务：验证各因素与增长率的相关性
  4. 结论生成任务：综合输出主要原因及证据链
```

### 第2角：记忆系统

**定义**：三层记忆结构

**三层架构**：

| 层级 | 存储内容 | 作用 |
|------|---------|------|
| **Layer 1** | 最近5-10轮对话 | 连贯性、指代消解 |
| **Layer 2** | 当前任务进度和状态 | 动态追踪任务完成度 |
| **Layer 3** | 用户偏好、历史规则、业务习惯 | 越用越懂你 |

**Agent额外要求**：
- 能自动积累知识（保留有效信息）
- 能主动更新知识库（识别新知识、剔除过时信息）
- 能管理知识边界（区分可信知识与待验证信息）

### 第3角：人机协同能力

**定义**：主动建议而非被动响应

**具体要求**：
- 能主动提出建议，而不是等用户明确指令
- 能识别何时需要人工干预，何时可以自主完成
- 能在关键决策点请求确认

**场景对比**：

| 传统Agent | 理想Agent |
|-----------|-----------|
| 直接输出报告 | 先问："你关心规模、格局，还是机会？" |
| 盲目执行 | 根据回答调整检索深度 |
| 单次输出 | 在关键结论后确认一致性 |

### 第4角：自我检查机制

**定义**：内置的验真机制

**具体要求**：
- 能识别自己输出的"幻觉边界"
- 能进行信息溯源（每条结论都能追溯到来源）
- 能标记置信度

**输出标记**：
- **强证据**：多个可信数据源支撑
- **弱证据**：单一信息源或推断
- **推断**：逻辑推理但缺乏直接证据

### 第5角：信噪比判断

**定义**：海量信息时的"瘦身术"

**具体要求**：
- 按可信度排序信息源（官方数据＞报告＞文章＞自媒体）
- 识别重复信息并进行合并处理
- 快速剔除低质量信息

**场景对比**：

| 传统Agent | 理想Agent |
|-----------|-----------|
| 检索100条，全部塞入上下文 | 先筛选前10条高质量信息 |
| — | 对剩余信息摘要压缩 |
| — | 必要时（用户追问）才展开 |

### 第6角：结构化输出

**定义**：输出"成果"而非"答案"

**具体要求**：
- 按用户场景定制输出格式（报告、清单、图表、代码）
- 用用户熟悉的语言风格表达
- 生成可复用的成果

**输出结构**：
```
1. 市场概览（含数据表格）
2. 增长趋势分析（含可视化图表）
3. 关键驱动因素（含证据链）
4. 结论与建议（含行动项清单）
5. 附录：数据来源与检索路径
```

### 第7角：自主执行能力

**定义**：完成"规划→执行→验证→调整→交付"闭环

**执行流程**：
```
1. 接收目标
2. 规划任务链（拆解为子任务）
3. 逐个执行子任务（调用工具、检索信息）
4. 验证执行结果（检查是否偏离目标）
5. 动态调整策略（发现问题立即修正）
6. 交付最终成果（结构化输出）
7. 形成学习闭环（沉淀经验、更新记忆）
```

## 六、七角测试方法

| 角位 | 测试方法 |
|------|---------|
| **第1角** | 给模糊指令"帮我准备下周汇报"，观察是否追问 |
| **第2角** | 第一次告诉Agent偏好，第二次观察是否调用 |
| **第3角** | 复杂任务中观察是否在关键点请求确认 |
| **第4角** | 观察结论是否附带来源标记或置信度说明 |
| **第5角** | 观察是否先筛选后输出，而非全部堆砌 |
| **第6角** | 观察输出格式是否可复用 |
| **第7角** | 观察是否完成闭环，而非每步都需要指令 |

**成熟标准**：覆盖5个以上即为成熟Agent。
