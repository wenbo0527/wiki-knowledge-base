# 📋 Code Examples 代码示例库 准入标准

> **制定时间**: 2026-04-30
> **制定者**: 尼克·弗瑞 🕵️
> **依据**: Simon Willison "Hoard Things You Know" 理念
> **适用范围**: `wiki/code-examples/` 目录下所有内容

---

## 1. 核心理念

> **"知道某事理论上可行 ≠ 亲眼见过它实现"** — Simon Willison

| 知识类型 | 价值层级 | 代码示例价值 |
|----------|----------|--------------|
| 理论知识 | 知道可能性边界 | ⭐ |
| **运行代码** | **具体实现参考** | **⭐⭐⭐⭐⭐** |
| 组合模式 | 多示例组合成新方案 | ⭐⭐⭐⭐ |

**代码示例的核心价值**：给Agent提供**可运行的证明**，而非纯文字描述。

---

## 2. 准入标准

### 2.1 必须满足的条件

| 条件 | 说明 | 判定标准 |
|------|------|----------|
| **✅ 可运行** | 代码必须能够实际执行 | 有完整的依赖声明和main函数 |
| **✅ 有来源** | 明确标注来源Insight | 在文件头注明 `来源: insight-YYYYMMDD-xxx` |
| **✅ 最小化** | 聚焦单一概念 | 单文件≤300行，或明确拆分 |
| **✅ 自文档化** | 代码即文档 | 有清晰注释和README |
| **✅ 有输出示例** | 展示运行效果 | 包含输入/输出示例 |

### 2.2 质量分级

| 等级 | 标准 | 说明 |
|------|------|------|
| **⭐⭐⭐⭐⭐** | 完全满足准入标准 + 有组合模式 | 最佳代码示例 |
| **⭐⭐⭐⭐** | 完全满足准入标准 | 高质量代码示例 |
| **⭐⭐⭐** | 满足基本准入标准 | 可接受的代码示例 |
| **⭐⭐** | 仅理论实现 | 需补充可运行证明 |
| **⭐** | 伪代码/片段 | 不纳入，正式实现后再入库 |

### 2.3 格式要求

```markdown
# {标题}

> 来源: insight-YYYYMMDD-{slug}
> 评级: ⭐⭐⭐⭐ (4/5)
> 创建时间: YYYY-MM-DD

## 概述
{一句话说明这是什么}

## 核心代码
```python
# 实际可运行的代码
```

## 使用示例
```python
# 展示如何调用
```

## 关联
- 来源Insight: [[insight-YYYYMMDD-xxx]]
- 相关示例: [[other-example]]
```

## 3. 目录结构规范

```
code-examples/
├── README.md                    ← 总索引（必须）
├── {category}/                 ← 按领域分类
│   ├── README.md              ← 分类索引
│   ├── example-1.py           ← 主代码文件
│   └── example-1-run.log      ← 可选：运行日志
```

### 推荐分类

| 分类 | 内容 |
|------|------|
| `multi-agent/` | 多智能体架构相关 |
| `context-management/` | 上下文管理相关 |
| `graph-memory/` | 图记忆实现 |
| `subagent-patterns/` | Subagent模式 |
| `harness/` | Harness工程化 |
| `workflow/` | 工作流模式 |

---

## 4. 目录准入标准

| 标准 | 要求 |
|------|------|
| 至少3个示例 | 新建分类至少包含3个相关示例 |
| 完整索引 | 必须有README.md |
| 来源映射 | 每个示例必须标注来源Insight |

---

## 5. 保鲜机制

| 机制 | 说明 |
|------|------|
| **来源关联** | 每个代码示例必须关联到来源Insight |
| **定期检查** | 每月检查代码是否过时（依赖变化等） |
| **淘汰规则** | 代码无法运行且无法修复 → 移至 `sources/archived/` |

---

## 6. 禁止事项

| 禁止 | 原因 |
|------|------|
| ❌ 纯理论/伪代码 | 无法验证可行性 |
| ❌ 无来源的代码 | 无法追溯依据 |
| ❌ 超过500行的单文件 | 违反最小化原则 |
| ❌ 无注释的代码 | 违反自文档化原则 |

```
