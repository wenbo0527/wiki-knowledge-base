# 营销套件落地综述
## 数字营销产品域 (PD-MKT) 综合介绍

---

## 一、开篇：产品定位与核心价值

### 1.1 行业背景与业务痛点

**传统营销困境**：

| 痛点类型 | 层面 | 具体表现 | 业务影响 |
|:---|:---|:---|:---|
| **工具分散** | 业务层 | 电销经营、AI外呼经营、APP经营独立，缺少有效协同 | 无法针对客户视角构建统一策略，触达体验割裂 |
| **效率低下** | 能力层 | 独立业务系统无法拥有海量数据处理和实时挖掘能力，能力难以复用 | 策略响应慢，难以支撑大规模精准营销 |
| **效率低下** | 业务层 | 各业务线独立经营，目标对齐难度大 | 资源重复投入，策略冲突，运营成本高 |
| **精准度不足** | 业务层 | 缺少有效的策略设计方法论，依赖经验判断 | 客群定位偏差，资源浪费严重 |
| **精准度不足** | 数据层 | 多源数据难以聚合分析，无法形成统一客户视图 | 策略设计缺乏数据支撑，效果难以追溯 |
| **合规风险** | — | 金融行业数据监管严格，合规校验缺失 | 违规触达风险高，客户投诉率上升 |

### 1.2 产品核心定位

> **营销套件是「以数据为核心、以自动化为引擎、以合规为底线」的一体化营销支撑平台，支撑客群经营与业务经营双轮驱动**

| 运营场景 | 定位 | 核心能力 |
|:---|:---|:---|
| **客群经营** | 以客户为中心，支撑客户全生命周期精细化运营 | 静态客群周期经营 + 热场景实时挖掘 |
| **业务经营** | 以业务为目标，支撑营销活动的组合化运营 | 多渠道 × 多权益 × 多产品 联合策划 |

**适配场景**：银行、持牌消金、互联网金融等金融行业营销场景

### 1.3 核心价值主张

| 价值关键词 | 内涵 |
|:---|:---|
| **数据驱动** | 全链路数据采集与智能分析 |
| **全流程自动化** | 策略配置到执行全链路自动化 |
| **合规可控** | 合规校验内嵌全流程 |
| **降本增效** | 减少人工干预，降低运营成本 |

## 三、客群经营支撑：功能架构

> 支撑「以客户为中心」的精细化运营，核心是客群中心提供数据底座，营销画布提供策略引擎，触达系统提供交付能力。

### 3.1 客群经营模式总览

| 模式 | 定位 | 触发方式 | 核心场景 |
|:---|:---|:---|:---|
| **静态客群周期经营** | 基于目标导向，定时触达促进客户完成关键业务动作 | 定时触发（日/周/月） | 促注册、促实名、促授信、促复购 |
| **热场景实时挖掘** | 基于用户实时行为，触发即时营销动作挽回流失 | 事件触发 | 转化断点召回、场景提额 |

### 3.2 静态客群周期经营

**核心目标**：促进客户完成关键业务动作，覆盖获客到转化的完整路径。

**典型场景**：

| 场景 | 业务目标 | 人群定义 | 触达策略 | 工具支撑 |
|:---|:---|:---|:---|:---|
| **促注册** | 提升注册量 | 曝光但未注册用户 | 定时触达 + 注册激励 | 客群中心-人群列表 + 营销画布-定时触发 + 权益中心-优惠券 |
| **促实名** | 提升实名率 | 注册但未实名用户 | 实名好处告知 + 权益引导 | 客群中心-标签管理 + 触达系统-多渠道 |
| **促授信** | 提升授信完成率 | 实名但未授信用户 | 授信流程引导 + 授信礼 | 客群中心-漏斗标签 + 营销画布-周期执行 |
| **促复购** | 提升复购频率 | 已授信但低频交易用户 | 复购激励 + 专属权益 | 客群中心-交易标签 + 权益中心-积分/券 |

**流程示意**：

```
业务目标设定（促注册/促实名/促授信/促复购）
      ↓
   目标客群圈选（漏斗各层级用户）
      ↓
   周期配置（定时触发规则）
      ↓
   多渠道触达 + 权益激励
      ↓
   效果监控（转化率追踪）
      ↓
   策略优化迭代
```

### 3.3 热场景实时挖掘

**核心目标**：实时识别转化断点，触发即时干预挽回流失用户。

**典型场景**：

| 场景 | 触发条件 | 响应策略 | 工具支撑 |
|:---|:---|:---|:---|
| **转化断点召回** | 用户在关键流程节点中断（如填写一半、签约前放弃） | 断点提示 + 即时权益激励 | 客群中心-事件管理 + 营销画布-事件触发 + 权益中心-即时券 |
| **场景提额** | 用户出现高价值行为（如按时还款、多频消费） | 即时告知提额机会 + 简化流程 | 客群中心-行为事件 + 触达系统-即时推送 |

**断点场景示例**：

| 断点位置 | 用户行为 | 干预策略 |
|:---|:---|:---|
| **注册断点** | 填写手机号后离开 | 短信触达 + 注册红包提醒 |
| **实名断点** | 身份证上传后未完成认证 | 认证指引 + 认证礼 |
| **授信断点** | 授信申请提交后未通过 | 补充材料指引 + 提额技巧 |
| **签约断点** | 产品页浏览但未签约 | 签约激励 + 限时权益 |
| **支付断点** | 加入购物车但未支付 | 支付提醒 + 限时优惠 |

**流程示意**：

```
用户行为事件 → 事件采集 → 断点识别 → 即时权益配置 → 实时触达 → 转化挽回
     ↑                                                                                    ↓
     ← ← ← ← ← ← ← ← ← ← ← 模型优化迭代 ← ← ← ← ← ← ← ← ← ←
```

### 3.4 功能模块对应关系

| 功能层次 | 核心能力 | 对应Epic | Feature |
|:---|:---|:---|:---|
| **数据底座** | 多源数据整合、标签工厂、ID-mapping | EPIC-MKT-CROWD | 事件管理、标签管理、人群列表、ID-mapping |
| **策略引擎** | 可视化编排、定时触发、事件触发、AB实验 | EPIC-MKT-CANVAS | 画布编辑、画布执行、画布统计 |
| **触达交付** | 多渠道触达、人机协同、频次控制 | EPIC-MKT-REACH + EPIC-MKT-SALES | 渠道管理、频控管理、外呼功能 |
| **权益激励** | 优惠券、积分、券包、预算管控 | EPIC-MKT-BENEFIT | 券模板、库存管理、审批流程 |

## 四、业务经营支撑：组合经营能力

> 支撑「以业务为目标」的组合化运营，核心是多渠道、多权益、多产品三者联合策划，实现业务增长。

### 4.1 业务经营模式总览

```
┌─────────────────────────────────────────────────────────────────────┐
│                          业务经营                                    │
├─────────────────────────────────────────────────────────────────────┤
│                                                                     │
│   多渠道组合          多权益组合          多产品组合                 │
│   ┌──────────────┐   ┌──────────────┐   ┌──────────────┐           │
│   │ 短信+推送+外呼│ × │ 优惠券+积分+ │ × │ 信用卡+消费贷│           │
│   │ +小程序+邮件  │   │ 券包+礼品   │   │ +理财+存款   │           │
│   │ 渠道优先级    │   │ 权益叠加规则 │   │ 产品组合推荐 │           │
│   └──────────────┘   └──────────────┘   └──────────────┘           │
│                                                                     │
│   组合策划 → 人群匹配 → 渠道分发 → 权益激励 → 产品转化             │
│                                                                     │
└─────────────────────────────────────────────────────────────────────┘
```

### 4.2 多渠道组合

**核心能力**：

| 能力 | 说明 | 工具支撑 |
|:---|:---|:---|
| **渠道优先级配置** | 根据客群特征自动选择最优渠道组合（如高净值客户优先人工电话） | 触达系统-策略管理 |
| **渠道协同避免冲突** | 同一客户多渠道触达时序控制，避免重复打扰 | 触达系统-频控管理 |
| **渠道效果追踪** | 各渠道转化率、成本、ROI对比分析 | 触达系统-数据统计 |

**典型场景**：

| 客群类型 | 渠道优先级 | 说明 |
|:---|:---|:---|
| **高净值客户** | 人工电话 > APP推送 > 短信 | 尊享服务体验，人工重点维护 |
| **价值成长客户** | APP推送 > 短信 > 外呼 | 自动化触达为主，人工辅助 |
| **潜力新客** | APP推送 > 短信 | 低成本渠道触达 |
| **沉默客户** | 短信 > APP推送 > 外呼 | 轻打扰，以权益吸引注意 |
| **流失召回客户** | 外呼 > 短信 > APP推送 | 人工电话重点攻关 |

### 4.3 多权益组合

**核心能力**：

| 能力 | 说明 | 工具支撑 |
|:---|:---|:---|
| **权益叠加规则** | 支持多权益组合配置（优惠券+积分+券包叠加使用） | 权益中心-券包管理 |
| **权益预算管控** | 权益发放总量控制、预算预警、ROI实时监控 | 权益中心-库存管理 |
| **权益生命周期管理** | 权益创建→配置→发放→核销→追溯全链路 | 权益中心-审批流程 |
| **差异化权益策略** | 不同客群差异化权益配置（等级权益、专属礼包） | 权益中心-权益配置 |

**权益组合类型**：

| 组合类型 | 适用场景 | 示例 |
|:---|:---|:---|
| **新人礼包** | 新客激活 | 首单立减券 + 双倍积分 + 新手指南 |
| **留存礼包** | 活跃维系 | 专属折扣券 + 积分翻倍 + VIP体验 |
| **召回礼包** | 流失挽回 | 大额满减券 + 专属礼品 + 人工回访 |
| **交叉销售礼包** | 产品推广 | 目标产品优惠券 + 关联产品体验券 |

### 4.4 多产品组合

**核心能力**：

| 能力 | 说明 | 工具支撑 |
|:---|:---|:---|
| **产品关联分析** | 基于客户持有产品，推荐关联产品组合 | 客群中心-标签管理 |
| **产品组合策略** | 交叉销售、升级推荐、组合定价 | 营销画布-策略配置 |
| **产品转化追踪** | 各产品转化率、周期、ROI监控 | 营销画布-统计 |

**产品组合策略**：

| 策略类型 | 客群特征 | 推荐产品组合 |
|:---|:---|:---|
| **交叉销售** | 已有存款客户，未购买理财 | 存款 + 理财产品推荐 |
| **额度升级** | 信用卡额度使用率高客户 | 额度升级 + 分期业务推荐 |
| **产品升级** | 高价值存款客户 | 定期存款 + 理财产品升级 |
| **新客引导** | 新注册客户 | 信用卡 + 消费贷 + 新手理财 |

### 4.5 组合经营流程

```
业务目标设定
      ↓
   客群圈选（客群中心-人群列表）
      ↓
   产品组合设计（营销画布-策略配置）
      ↓
   权益叠加配置（权益中心-券包管理）
      ↓
   渠道分发策略（触达系统-渠道管理）
      ↓
   AB实验验证（营销画布-AB实验）
      ↓
   全量执行（触达系统-自动执行）
      ↓
   效果追踪（营销画布-统计 + 触达系统-数据看板）
      ↓
   策略优化（基于数据的持续迭代）
```

### 4.6 组合经营典型场景

| 场景 | 业务目标 | 渠道组合 | 权益组合 | 产品组合 |
|:---|:---|:---|:---|:---|
| **信用卡分期推广** | 提升生息资产 | 短信+APP推送+外呼 | 分期手续费折扣券 + 积分奖励 | 信用卡 + 分期业务 |

| **消费贷推广** | 扩大贷款规模 | APP推送+短信+广告投放 | 利率折扣券 + 免息券 | 消费贷 + 信用卡 |
| **沉睡资产激活** | 提升存量客户活跃度 | 短信+APP推送 | 到期提醒 + 专属权益 | 各类产品交叉推荐 |

## 五、客群经营框架：静态客群 + 模型刻画体系

> 构建「静态客群 + 模型刻画」双维度客群视图，支撑精细化运营决策。

### 5.1 静态客群

静态客群是基于客户当前业务状态的分层，不随时间自动流转，需业务动作触发转换。

| 客群类型 | 定义 | 运营目标 | 核心策略 |
|:---|:---|:---|:---|
| **新户** | 新注册客户（通常注册时间 < 30天） | 促进完成首笔业务（首借/首分期/首交易） | 新户礼包、流程引导、限时激励 |
| **复购** | 有历史交易记录的客户 | 提升交易频次、扩大交易规模 | 复购激励、等级权益、交叉销售 |

**新户运营要点**：

| 阶段 | 目标 | 策略 |
|:---|:---|:---|
| **注册-实名** | 提升实名率 | 实名激励 + 流程简化 |
| **实名-授信** | 提升授信完成率 | 授信礼 + 授信指引 |
| **授信-首借** | 促进首笔借款/消费 | 首借优惠 + 额度管理 |
| **首借-复借** | 培养用信习惯 | 用信提醒 + 复借激励 |

**复购运营要点**：

| 客群 | 运营策略 |
|:---|:---|
| **高复购客户** | 专属权益、积分加倍、VIP服务 |
| **低频复购客户** | 复购激励、限时优惠、交叉产品推荐 |
| **沉默复购客户** | 定向唤醒、大额权益刺激 |

### 5.2 模型刻画

模型刻画是基于机器学习/规则引擎构建的动态客群标签，反映客户的行为特征和响应倾向。

#### 5.2.1 风险等级

| 风险等级 | 定义 | 营销策略 |
|:---|:---|:---|
| **低风险** | 信用良好、还款记录优秀 | 额度充足、优惠力度大、可接受高频触达 |
| **中风险** | 信用一般、偶有逾期 | 适度触达、关注还款提醒、权益适度 |
| **高风险** | 信用较差、多次逾期 | 审慎触达、合规优先、人工跟进 |

#### 5.2.2 营销响应层级

| 响应层级 | 定义 | 营销策略 |
|:---|:---|:---|
| **高响应** | 历史响应率高、触达效果好 | 重点覆盖、高频触达、优先推送 |
| **中响应** | 历史响应率一般 | 常规覆盖、中频触达、权益激励 |
| **低响应** | 历史响应率低、难触达 | 控制频次、优化渠道、差异化权益 |

#### 5.2.3 优惠敏感度

| 敏感类型 | 定义 | 营销策略 |
|:---|:---|:---|
| **价格敏感** | 对优惠券/折扣敏感，权益驱动明显 | 大额券/高折扣、限时优惠 |
| **服务敏感** | 对服务体验敏感，权益驱动不明显 | 专属服务、流程优化、VIP通道 |
| **混合敏感** | 价格+服务双重敏感 | 权益+服务组合拳 |

### 5.3 客群标签体系

**EPIC-MKT-CROWD（客群中心）** 提供多维度标签支撑：

| 维度 | 标签类型 | 说明 |
|:---|:---|:---|
| **静态客群** | 新户/复购 | 基于业务状态的客群分层 |
| **风险等级** | 低/中/高风险 | 信审评分 + 还款行为 |
| **营销响应层级** | 高/中/低响应 | 历史触达响应率模型 |
| **优惠敏感度** | 价格敏感/服务敏感/混合敏感 | 权益响应行为分析 |
| **生命周期** | 新客/成长/成熟/沉默/流失 | 时间维度分层 |
| **金融属性** | 高净值/价值/潜力/白名单等 | AUM + 信贷需求 |

### 5.4 组合分群策略

静态客群 × 模型刻画 形成精细化分群矩阵：

| 组合 | 特征描述 | 运营策略 |
|:---|:---|:---|
| **新户 × 低风险 × 高响应 × 价格敏感** | 优质新户，权益响应好 | 新户大礼包 + 首借优惠，优先覆盖 |
| **新户 × 中风险 × 中响应 × 服务敏感** | 普通新户，服务驱动 | 流程引导 + 专属服务，适度覆盖 |
| **复购 × 低风险 × 高响应 × 混合敏感** | 优质存量客户 | 复购激励 + 尊享权益，重点维护 |
| **复购 × 高风险 × 低响应 × 价格敏感** | 风险较高存量客户 | 审慎触达、合规优先、人工跟进 |

### 5.5 分群运营策略矩阵

| 客群 | 触达渠道优先级 | 权益策略 | 触达频次 | 策略类型 |
|:---|:---|:---|:---:|:---:|
| **新户（优质）** | APP推送 > 短信 > 外呼 | 新户礼包、首借优惠 | 入账后3天内 | 自动化 |
| **新户（普通）** | APP推送 > 短信 | 新户引导、流程激励 | 入账后7天内 | 自动化 |
| **复购（高响应）** | APP推送 > 短信 > 外呼 | 积分加倍、等级权益 | 每周1次 | 自动化 |
| **复购（低响应）** | 短信 > APP推送 | 定向权益、限时优惠 | 每两周1次 | 自动化 |
| **高风险客户** | 人工电话 > 短信 | 合规优先、审慎激励 | 按需 | 人工优先 |
| **价格敏感客户** | 全渠道 | 大额券/高折扣 | 高频 | 自动化 |
| **服务敏感客户** | APP推送 > 人工电话 | 专属服务、VIP通道 | 低频 | 人工+自动化 |

## 六、增长闭环：数据驱动迭代

> 基于 **AARRR 模型**实现全链路增长闭环，支持客群经营和业务经营的数据驱动优化。

### 6.1 增长闭环总览

```
实验设计 → 策略执行 → 数据采集 → 效果分析 → 策略优化
    ↑                                                  ↓
    ← ← ← ← ← ← ← ← ← ← ← ← ← ← ← ← ← ← ← ← ← ← ←
```

| 环节 | 工具支撑 | 说明 |
|:---|:---|:---|
| **实验设计** | 营销画布-AB实验 | 支持多版本策略并行测试 |
| **策略执行** | 触达系统-自动执行 | 按实验分组差异化触达 |
| **数据采集** | 客群中心-事件管理 | 全链路行为数据埋点 |
| **效果分析** | 营销画布-统计 | 转化率/留存率/ROI对比 |
| **策略优化** | 画布编辑-迭代更新 | 基于数据结论优化策略 |

### 6.2 AARRR各阶段支撑

| AARRR阶段 | 客群经营支撑 | 业务经营支撑 |
|:---|:---|:---|
| **获取(Acquisition)** | 客群中心-渠道标签 | 触达系统-精准投放 |
| **激活(Activation)** | 营销画布-新客激活流程 + 权益中心-新手礼包 | 多权益组合-新客礼包 |
| **留存(Retention)** | 客群中心-生命周期分层 + 营销画布-周期触达 | 多渠道组合-定期触达 |
| **变现(Revenue)** | 客群分群-精准营销 + 人工电销-高价值跟进 | 多产品组合 + 多权益激励 |
| **推荐(Referral)** | 营销画布-邀请有礼 + 触达系统-社交裂变 | 权益中心-裂变激励 |

### 6.3 关键指标体系

| 维度 | 指标 | 说明 |
|:---|:---|:---|
| **获客指标** | CAC、渠道转化率、ROI | 获取阶段效率 |
| **激活指标** | 激活率、Aha Moment达成率、新客转化周期 | 激活阶段质量 |
| **留存指标** | DAU/MAU、留存率、流失预警准确率 | 客户粘性 |
| **变现指标** | ARPU、LTV、分期转化率、交叉销售成功率 | 业务贡献 |
| **推荐指标** | K因子、裂变转化率、推荐ROI | 裂变效果 |

### 6.4 归因分析

| 归因类型 | 适用场景 | 说明 |
|:---|:---|:---|
| **首次触点归因** | 强调获客渠道价值 | 归功于客户的第一次触达 |
| **末次触点归因** | 强调转化临门一脚 | 归功于客户转化前的最后一次触达 |
| **线性归因** | 公平分配渠道贡献 | 各触点平均分配转化价值 |
| **时间衰减归因** | 强调近期触达 | 越近的触点归因权重越高 |
