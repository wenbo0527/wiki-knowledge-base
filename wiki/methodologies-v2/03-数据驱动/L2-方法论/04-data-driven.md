## 三、具体方法论详情

### 1. 闭环构建方法

**核心**：数据闭环怎么搭

**成熟框架**：AARRR / OSM
| 阶段 | 说明 |
|:---|:---|
| **Acquisition** | 获取 |
| **Activation** | 激活 |
| **Retention** | 留存 |
| **Revenue** | 收入 |
| **Referral** | 推荐 |

**OSM模型**：
```
Objective → Strategy → Measure
目标        策略      指标
```

**实践要点**：
- 明确北极星指标
- 设计指标分解链路
- 建立数据采集体系

**✅ 实践案例：6域23应用闭环**
- 北极星指标：数据资产使用率
- 分解链路：
  - 数据标准覆盖率
  - 数据质量达标率
  - 数据资产被引用次数
  - 数据驱动决策次数
- 数据采集：埋点+日志+血缘追踪

### 2. 评估方法

**核心**：怎么评估效果

**成熟框架**：
| 指标类型 | 说明 | 示例 |
|:---|:---|:---|
| **业务指标** | 与业务目标挂钩 | 转化率、GMV |
| **产品指标** | 产品能力评估 | DAU、留存 |
| **AI指标** | AI效果评估 | 准确率、召回率 |

**实践要点**：
- 定义清晰的评估标准
- 建立基准值和目标值
- 设置最低阈值

**✅ 实践案例：信用卡生息评估体系**
| 指标类型 | 具体指标 | 基准值 | 目标值 |
|:---|:---|:---:|:---:|
| 业务 | 生息资产规模 | 100亿 | 120亿 |
| 业务 | 新客转化率 | 5% | 7% |
| 产品 | 策略采纳率 | 40% | 60% |
| AI | 模型KS值 | 0.35 | 0.40 |
| AI | 意图识别准确率 | 80% | 90% |

### 3. 监控方法

**核心**：怎么监控质量

**成熟框架**：数据质量维度
| 维度 | 说明 |
|:---|:---|
| **完整性** | 数据是否缺失 |
| **准确性** | 数据是否正确 |
| **一致性** | 数据是否统一 |
| **时效性** | 数据是否及时 |
| **唯一性** | 数据是否重复 |

**实践要点**：
- 设置数据质量规则
- 建立异常告警机制
- 定期生成质量报告

**✅ 实践案例：数据质量问题工单闭环**
- 监控维度：
  - 数据完整性：每日增量数据量
  - 数据准确性：核心指标波动检测
  - 数据时效性：数据延迟告警
- 告警机制：
  - P0：数据完全不可用 → 立即告警
  - P1：数据超过阈值 → 2小时内处理
  - P2：数据质量问题 → 24小时内处理
- 闭环流程：发现问题 → 创建工单 → 分配责任人 → 处理 → 验证 → 关闭

### 5. 数据资产化方法（2026-06-22 新增 🆕）

**核心**：把一次性响应沉淀为可复用资产

**实践案例：Hermes Agent 重构得物数仓**（来源：insight-20260622-hermes-rule-pack-data-warehouse）

#### 5.1 三道治理门

| 治理门 | 作用 | 对应我们 |
|:---|:---|:---|
| **事实源门** | 需求可追溯到原始材料 | INC 报告链 |
| **预演门** | 系统模拟验证（dry-run）| Cron 自动监督 |
| **责任门** | 人工确认留痕 | 文博拍板 |

#### 5.2 规则包 (Rule Pack) 沉淀机制

```
新需求 → 材料收齐 → 历史找出 → 风险预演 → 过程留存
                                            ↓
                                    提炼为规则包
                                            ↓
                                    下次新需求自动关联
```

**核心思想**：把"老同事才知道"的判断写成可执行检查清单，形成知识复利效应。

#### 5.3 5 契约原则（可迁移能力设计）

| 契约 | 含义 |
|:---|:---|
| 输入 | 触发条件明确 |
| 边界 | 适用范围清晰 |
| 输出 | 期望结果可验证 |
| 失败处理 | 异常降级路径 |
| 经验回写 | 用后优化闭环 |

#### 5.4 量化收益（得物案例）

- 需求确认时间：数小时 → 分钟级
- 口径对齐效率：+60%
- 历史规则复用率：+80%
- 常规需求人力：0.5-1.0 → 0.1-0.3 人日（节约 70%）

### 4. 治理方法

**核心**：怎么治理数据

**成熟框架**：DAMA-DMBOK
| 领域 | 说明 |
|:---|:---|
| **数据标准** | 命名规范、口径定义 |
| **数据血缘** | 数据流转追踪 |
| **数据安全** | 权限、脱敏、审计 |
| **数据生命周期** | 创建、使用、归档、销毁 |

**实践要点**：
- 制定数据标准
- 建立血缘关系图谱
- 设计权限和脱敏规则

**✅ 实践案例：数据门户血缘治理**
- 数据标准：
  - 表命名规范：dim/fact/ods_业务域_实体
  - 字段命名：下划线分隔，全小写
  - 指标口径：标准定义文档
- 血缘追踪：
  - 字段级血缘：上游字段→下游字段
  - 表级血缘：ODS→DWD→DWS→ADS
  - 血缘可视化：一键穿透全部链路
- 权限管理：
  - 敏感字段脱敏
  - 权限申请审批流
  - 操作日志审计
