## 一、7月市场全景：红利占优，科技回调

### 1.1 大盘走势


| 指数   | 7月31日收盘  | 月度表现       |
| ---- | -------- | ---------- |
| 上证指数 | 3832.26  | 月线收阳       |
| 深证成指 | 13578.93 | 弱势震荡       |
| 创业板指 | 3343.96  | 月末反弹+3.06% |
| 科创综指 | 1819.90  | 月末反弹+3.69% |


7月31日收官日：科技股集体上涨带动反弹，全市场近4700只个股上涨，成交2.56万亿，较前日放量2015亿。但全月格局是**"红利占优，科技回调"**——煤炭月涨14.29%居首，石油石化、银行、食品饮料等防御板块涨幅居前；电子、通信等科技板块迎来显著调整。

### 1.2 核心事件线

- **7月上旬**：科技板块高位运行，科创50在7月8日已连续4天冲高回落，变盘信号初现
- **7月中旬**：科技板块剧烈震荡，科创50自高点最大回撤约27%，半导体指数同步下挫约30%。AI泡沫论甚嚣尘上，公募基金二季报密集披露，基金经理对AI估值分歧白热化
- **7月13日**：沪指跌破关键支撑位（年线附近），市场恐慌情绪集中释放
- **7月21日**：科技股单日反弹，科创50大涨10.73%，但随后再度陷入震荡
- **7月30日**：政治局会议定调"加大逆周期调节力度"，实施更加积极的财政政策和适度宽松的货币政策
- **7月31日**：月末反弹收官，多模态AI、PCB、人形机器人题材领涨

### 1.3 资金迁移特征

资金正从**极致抱团的AI赛道向防御性板块迁移**。公募基金二季报显示：

- 银行股占主动型基金重仓股比例降至1.01%的历史最低位（极度低配）
- 食品饮料重仓比例降至4.33%，处于2015年以来低位
- 非药基医药重仓持仓占比4.82%，为2010年以来最低位
- AI板块内部出现明显分化：科创50 PE达106.39，但部分实力龙头明年PE不到20倍

### 2.2 操作特征分析

**正确的事：**

1. **纪律执行到位**——7月10日"只观察不操作"、7月27日"开盘后再定操作"，在科技板块大幅回调前保持了仓位安全
2. **框架先行**——在7月13日大跌前已经构建了六维出清框架和建仓触发条件，不是跌了才想对策
3. **数据驱动**——7月14日委托ETF估值调研并要求统一数据口径，用数据验证而非情绪判断
4. **标准迭代**——7月22日主动修正科技方向估值判断标准，从近10年分位改为近1年分位+近半年辅助，适应高波动科技板块特性
5. **信号敏感**——7月8日注意到科创50连续冲高回落，在变盘前4天就发出了警觉

**值得反思的事：**

1. **7月13日是关键决策窗口**——跌破年线后问了"能不能建仓"，但最终没有建仓。从后看，7月31日科技股反弹，科创综指月末涨3.69%。但考虑到7月中下旬科技板块继续回调，不建仓的判断在当时是合理的
2. **止损方案制定偏晚**——7月29日才分析科创50止损方案，如果7月8日变盘信号时就预设止损线，应对会更从容
3. **日报频率高但决策密度低**——全月23个交易日几乎每天更新日报，但实际操作动作很少。日报的信息增量需要评估——是有效追踪还是仪式性追踪？

### 4.2 框架迭代记录

**7月22日关键迭代：**

- 原标准：科技方向用PE近10年分位<40%
- 新标准：科技方向用PE近1年分位<40%或PEG<1或PS近1年分位<30%，三条件取其一，同步参考近半年分位辅助判断
- 迭代原因：科技板块高波动特性下，近10年分位过于滞后，近1年分位更能反映当前周期位置

**评价：** 这次迭代方向正确。科技板块的估值周期与传统行业不同，用近10年分位会导致永远"看起来很贵"或永远"看起来不贵"的极端判断。近1年分位+半年辅助更贴合实际。但需要注意：近1年分位在科技板块单边下跌时会快速进入"低估"区间，需要防止"价值陷阱"——估值下降是因为基本面恶化而非市场非理性。

## 七、总结

7月你的投资操作可以概括为**"框架先行、纪律优先、信号敏感、执行到位"**。

最大的成绩不是赚了多少钱，而是在科技板块回撤27%-30%的过程中保持了仓位安全。六维出清框架在7月经受了第一次实战检验，低估值方向（红利、银行）的判断被市场验证，高估值科技方向的回避判断同样正确。

8月最值得关注的变化是**风格再平衡**——如果科技板块在中报业绩验证后出现分化（有业绩的涨、没业绩的继续跌），你的框架需要能区分"ETF内部的分化"而不仅仅是"板块整体的贵贱"。另外，创新药方向在7月数据中显示出被忽视的低位信号，值得8月重点评估。
