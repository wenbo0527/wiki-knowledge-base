| 字段 | 类型 | 说明 |
|:---|:---|:---|
| `repayPlan` | array<object> | 借据生成时的初始还款计划（覆盖所有期）|
| └ `period` | int | 期数（1 ~ installments）|
| └ `repayDate` | date | 本期应还日期 |
| └ `principal` | number | 本期应还本金 |
| └ `interest` | number | 本期应还利息 |
| └ `totalAmount` | number | 本期应还总额 = principal + interest |
| └ `prepayAmount` | number | 本期提前还款减免金额 |
| └ `benefitDiscount` | number | 本期权益减免金额（来自 `benefitRecords`）|

> **示例**：LON001（36 期借据）的 `repayPlan` 包含 36 行记录（period 1-36）

**v3.2 新增字段**（还款记录中需要展示的权益字段）：

| 字段 | 类型 | 说明 | demo 现有枚举 |
|:---|:---|:---|:---|
| `applicableBenefits` | array<enum> | 当前借据可用的权益（从 `benefitRecords` 关联）| 积分奖励 / 利率优惠 / 免息优惠 / 推荐奖励 / 权益升级 / 活动权益 |
| `usedBenefit` | string | 已使用的权益名称（如 "VIP专享利率优惠券"）| — |
| `benefitDiscount` | number | 权益减免金额（利率优惠/免息券/积分抵扣等）| — |
| `benefitDiscountType` | enum | 减免类型 | 利率减免 / 免息 / 积分抵扣 / 优惠券 |
| `isBenefitActive` | bool | 当前是否有生效中的权益 | true / false |

> **业务规则**：
> - 权益关联：每笔借据可关联 0-N 个 `benefitRecords`（通过 `productKey` 关联）
> - 减免计算：`benefitDiscount` 从 `benefitRecords.benefitAmount` 读取
> - 状态同步：若 `usedBenefit` 有值，`isBenefitActive = false`

#### Story-005：借据初始还款计划展示

| 字段 | 内容 |
|:---|:---|
| 角色-场景-价值 | 作为风控人员，在评估客户还款能力时，需要在客户360详情页查看每笔借据的初始还款计划（期数/应还时间/应还本金/应还利息/提前还款金额），以便判断客户的还款意愿和能力 |
| 优先级 | P0 |
| 状态 | 待开发 |

**验收标准**：

1. **客户360详情页顶部 TAB 栏**：在"借据"TAB 之后、"还款详情"TAB 之前的位置新增"借据初始还款计划"TAB
2. TAB 标题为"借据初始还款计划"
3. 列表展示字段：借据编号 / 期数 / 应还日期 / 应还本金 / 应还利息 / 提前还款金额 / 权益减免
4. 列表无数据时显示"该客户暂无借据初始还款计划"空状态
5. 列表加载时显示骨架屏
6. 默认按"应还日期"倒序
7. 金额字段千分位 + 元（¥）符号

**用户场景**：

- 场景1：风控评估还款能力 → 客户360详情页 → 滚动到"借据初始还款计划"Section → 看到每笔借据的全期还款计划
- 场景2：客服回应客户咨询 → 客户问"我每月要还多少" → 客服在 Section 中找到对应借据的初始还款计划
- 场景3：风控判断提前还款 → 查看"提前还款金额"列 → 决定是否给予减免
