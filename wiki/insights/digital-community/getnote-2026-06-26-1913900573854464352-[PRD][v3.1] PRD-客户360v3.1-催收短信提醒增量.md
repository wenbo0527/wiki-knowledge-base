## 四、Story 详情

### STORY-DEX-C360-COLLECT-SMS-001: 还款短信提醒列表展示

| 字段 | 内容 |
|:---|:---|
| 角色-场景-价值 | 作为客服/催收员,在客户360详情页 > 催收记录板块下,需要查看该客户历史收到的所有还款提醒短信明细,以便核实客户投诉、判断催收升级策略 |
| 优先级 | P0 |
| 状态 | 待开发 |

**验收标准**:
1. 客户360详情页 > 催收记录板块下,显示「还款短信提醒记录」子 Section 标题
2. 列表展示 7 列:短信内容、发送状态、送达状态、发送时间、错误状态、发送来源、回复状态
3. 列表列顺序固定,与表头顺序一致
4. 列表无数据时,显示空状态文案"该客户暂无还款短信提醒记录"
5. 列表加载时显示骨架屏,加载失败显示"加载失败,点击重试"

**字段展示规范**:

| 列 | 字段名 | 数据类型 | 取值/示例 | 空值处理 |
|:---:|:---|:---|:---|:---|
| 1 | 短信内容 | 文本 | "【XX金融】尊敬的用户..." | 截断 50 字符 + "...";hover 气泡看全文 |
| 2 | 发送状态 | 枚举 | 已发送 / 发送中 / 发送失败 | 必填 |
| 3 | 送达状态 | 枚举 | 已送达 / 未送达 / 未知 | 必填 |
| 4 | 发送时间 | 日期时间 | 2026-06-11 09:30:00 | 必填,格式 `YYYY-MM-DD HH:mm:ss` |
| 5 | 错误状态 | 文本 | 通道拥堵 / 号码错误 / 已退订 / 空号 | 仅当「发送状态=发送失败」时有值;其他显示 "—" |
| 6 | 发送来源 | 枚举 | 系统定时 / 人工触发 / MA 触发 / 催收员手动 | 必填 |
| 7 | 回复状态 | 枚举 | 未回复 / 已回复 / 已回复(无效内容) / 已退订 | 必填 |

### STORY-DEX-C360-COLLECT-SMS-002: 列表分页与排序

| 字段 | 内容 |
|:---|:---|
| 角色-场景-价值 | 作为客服/催收员,需要按发送时间倒序浏览短信列表,并支持分页,避免单页过长影响查阅 |
| 优先级 | P0 |
| 状态 | 待开发 |

**验收标准**:
1. 列表默认按「发送时间」倒序排序(最新短信在最上方)
2. 支持分页,默认每页 20 条
3. 分页选项支持切换 10 / 20 / 50 / 100 条/页
4. 切换分页大小时,自动回到第 1 页
5. 列表底部显示"共 X 条,当前 Y/Z 页",支持跳转指定页

---

### STORY-DEX-C360-COLLECT-SMS-003: 时间区间筛选

| 字段 | 内容 |
|:---|:---|
| 角色-场景-价值 | 作为催收员,在评估长期逾期客户是否升级法务时,需要查看该客户近 90 天的短信提醒记录,需支持时间区间筛选 |
| 优先级 | P0 |
| 状态 | 待开发 |

**验收标准**:
1. 列表上方显示时间区间筛选器,包含「开始日期」「结束日期」两个日期选择器
2. 默认区间为「近 30 天」(从昨日倒推 30 天,含今日)
3. 支持自定义起止日期,起止日期可互换
4. 结束日期不能晚于当前日期;开始日期不能晚于结束日期
5. 提供快捷选项:「近 7 天 / 近 30 天 / 近 90 天 / 近 180 天 / 近 1 年 / 全部」
6. 切换时间区间后,自动重新查询并回到第 1 页
7. 日期选择器与 v3.0「产品+授信时间查询」使用同款组件(代码复用)

### STORY-DEX-C360-COLLECT-SMS-004: 短信内容展开查看

| 字段 | 内容 |
|:---|:---|
| 角色-场景-价值 | 作为客服,在客户投诉时,需要看到短信的完整内容(列表中 50 字符截断不够用) |
| 优先级 | P1 |
| 状态 | 待开发 |

**验收标准**:
1. 鼠标 hover「短信内容」列超过 50 字符的记录,显示 Tooltip 气泡展示完整内容
2. 气泡最大宽度 400px,超出换行
3. 「短信内容」列在 PC 端可点击「展开」按钮,切换为完整内容(再次点击「收起」)
4. 移动端无 hover,直接「展开/收起」按钮
5. 完整内容支持复制(选中即复制)

### STORY-DEX-C360-COLLECT-SMS-005: 字段空值与截断规则

| 字段 | 内容 |
|:---|:---|
| 角色-场景-价值 | 作为产品规范,需统一所有字段的空值/截断展示规则,避免研发实现不一致 |
| 优先级 | P0 |
| 状态 | 待开发 |

**验收标准**:
1. 「错误状态」列仅在「发送状态=发送失败」时有值;其他情况(已发送/发送中)显示 "—"
2. 「短信内容」列超过 50 字符截断为前 50 字符 + "...";等于或不足 50 字符完整展示
3. 「发送时间」格式统一为 `YYYY-MM-DD HH:mm:ss`;不允许只显示日期不显示时间
4. 空值统一用 "—" 占位,不允许显示 "null" / "undefined" / 空字符串
5. 字段内容含 HTML 特殊字符时,需转义后展示,不允许 XSS 注入

### STORY-DEX-C360-COLLECT-SMS-006: T+1 数据同步接入

| 字段 | 内容 |
|:---|:---|
| 角色-场景-价值 | 作为架构师,需保证短信平台每日 T+1 推送的数据能正确接入客户360,确保客服次日可看到前一日短信 |
| 优先级 | P0 |
| 状态 | 待技术评审 |

**验收标准**:
1. 短信平台每日凌晨(具体时间待钟离确认)推送前一日短信数据
2. 客户360后端提供数据接入接口(具体协议待钟离技术方案)
3. 数据入库失败时,记录失败日志并告警(钉钉/飞书群)
4. T+1 数据次日 09:00 前可查(给客服开门时间)
5. 重复数据按「客户ID+发送时间」去重(同一条短信不能出现多次)
6. 历史数据回溯支持(回溯窗口期待钟离确认,建议 90 天)

## 七、字段类型与状态机

### 7.1 发送状态枚举

| 枚举值 | 含义 | 触发条件 |
|:---|:---|:---|
| 已发送 | 短信平台网关成功发出 | 网关返回 200 |
| 发送中 | 短信平台网关处理中 | 网关排队 |
| 发送失败 | 短信平台网关失败 | 网关返回 4xx/5xx 或超时 |

### 7.2 送达状态枚举

| 枚举值 | 含义 | 触发条件 |
|:---|:---|:---|
| 已送达 | 用户手机已签收 | 运营商回执成功(若有) |
| 未送达 | 用户手机未签收 | 运营商回执失败 / 号码错误 |
| 未知 | 暂无回执数据 | 无运营商回执通道 / 通道超时 |

> 字段合并说明: 原「接受状态」与「发送状态」的「已发送」有重叠,本次合并为「送达状态」,语义从"运营商回执"扩展为"是否到用户手机"。

### 7.3 发送来源枚举

| 枚举值 | 含义 |
|:---|:---|
| 系统定时 | 系统按预设规则定时触发(如 T-3 提醒) |
| 人工触发 | 客服/催收员手动发起 |
| MA 触发 | 营销自动化平台触发(非还款场景,可能为附属场景) |
| 催收员手动 | 催收员在催收系统中点击触发 |

### 7.4 回复状态枚举

| 枚举值 | 含义 |
|:---|:---|
| 未回复 | 用户未回复 |
| 已回复 | 用户回复且内容有效 |
| 已回复(无效内容) | 用户回复但内容无效(如表情、错别字) |
| 已退订 | 用户回复 TD / T 退订关键词 |

### 7.5 错误状态文本

- 取值由短信平台返回,常见值:通道拥堵、号码错误、已退订、空号、运营商拦截、签名错误、内容违规
- 仅在「发送状态=发送失败」时显示
- 不在本系统中枚举,直接透传上游文案
