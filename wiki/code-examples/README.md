## 代码示例原则

### 1. 可运行性
每个示例必须有：
- 完整的依赖声明
- 可执行的main函数
- 输入/输出示例

### 2. 最小化
每个示例应该：
- 聚焦单一概念
- 代码量控制在100行内
- 易于理解和修改

### 3. 自文档化
每个示例应该包含：
- 清晰的文件头注释
- 关键代码行注释
- 使用说明和输出示例
