## 三、检索流程

### 3.1 向量检索

```python
# 1. Query 向量化
query_embedding = ollama.embed("用户查询")

# 2. Chroma 向量检索
results = chroma.query(
    query_embeddings=[query_embedding],
    n_results=20
)
```

### 3.2 BM25 检索

```python
# 1. Query 分词
query_terms = tokenize("用户查询")

# 2. BM25 打分
scores = bm25.score(query_terms, doc_idx)

# 3. 返回 Top-20
results = sorted(scores, reverse=True)[:20]
```

### 3.3 RRF 融合

```python
def rrf_fusion(vector_results, bm25_results, k=60):
    """
    倒数排名融合
    score(doc) = Σ 1/(k + rank_in_method)
    """
    fused_scores = {}
    
    for i, doc in enumerate(vector_results):
        fused_scores[doc.id] += 1 / (k + i)
    
    for i, doc in enumerate(bm25_results):
        fused_scores[doc.id] += 1 / (k + i)
    
    return sorted(fused_scores.items(), key=lambda x: x[1], reverse=True)
```

### 3.4 评分归一化

```python
# Min-Max 归一化
score_min = min(fused_scores.values())
score_max = max(fused_scores.values())

normalized = (score - score_min) / (score_max - score_min)
```

## 六、分块策略

### 6.1 按标题层级分块

```
文档结构:
# H1 - 文档标题
## H2 - 章节1
### H3 - 小节1.1
内容...
### H3 - 小节1.2
内容...
## H2 - 章节2
```

### 6.2 Token 限制

- **L1**: 按 H1/H2/H3 分块
- **L2**: 超 512 tokens 按段落二次拆分
- 保留元数据：product_domain, epic, doc_type, heading_level

## 七、评估指标

| 指标 | 目标 | 实际 | 状态 |
|:---|:---:|:---:|:---:|
| **MRR@10** | > 0.7 | **1.000** | ✅ 超标 |
| **Recall@10** | > 0.85 | **0.810** | ⚠️ 接近 |
| **延迟 P99** | < 500ms | **~200ms** | ✅ 达标 |

### MRR@10 (Mean Reciprocal Rank)

第一个正确答案的平均位置：

```
MRR = 1/N × Σ 1/rank_i

示例: 如果正确答案在第1位，MRR = 1.0
      如果正确答案在第3位，MRR = 0.333
```

### Recall@10

前 10 结果中相关文档的比例：

```
Recall@10 = 相关文档数 / 预期相关文档总数
```
