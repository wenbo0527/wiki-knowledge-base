## 一句话概括

**数据驱动 = 用数据发现问题 → 分析原因 → 验证效果**

---

## 核心问题

| 问题 | 回答 |
|:---|:---|
| **发现什么问题** | 数据监控 |
| **原因是什么** | 数据分析 |
| **方案有效吗** | A/B测试/效果验证 |

---

## 数据驱动闭环

```
┌─────────────────────────────────────────┐
│              数据闭环                    │
├─────────────────────────────────────────┤
│                                          │
│  ① 指标定义                              │
│      ↓ 定义要监控的指标                   │
│  ② 数据采集                              │
│      ↓ 埋点/日志/ETL                     │
│  ③ 数据分析                              │
│      ↓ 发现异常/趋势                       │
│  ④ 决策行动                              │
│      ↓ 制定策略/优化方案                  │
│  ⑤ 效果验证                              │
│      ↓ 回到①验证指标变化                  │
│                                          │
└─────────────────────────────────────────┘
```
