## 一、AB实验解决的核心问题

### 核心价值

> **解决因果推断问题**，明确动作A与结果B的关联（区别于相关性）

### 因果关系三条件

| 条件 | 说明 |
|:---|:---|
| **有方向** | A导致B |
| **有先后** | A在B之前发生 |
| **有改变** | A变化导致B变化 |

### AB实验 vs 历史数据分析

| 对比维度 | AB实验 | 历史数据分析 |
|:---|:---|:---|
| **场景特性** | 面向真实场景的测试 | 基于历史数据的回溯分析 |
| **时效性** | 先验性强，从假设到结论时间成本低 | 需经历投放-回收-分析-优化传统链路 |
| **效率** | 可并行进行，提升决策效率 | 串行分析，周期较长 |

## 二、实验规划前的关键准备

### 核心准备要素

| 要素 | 说明 |
|:---|:---|
| **验证假设** | 明确验证假设及提升比例 |
| **显著性水平** | 如5% |
| **统计功效** | 如80% |
| **指标体系** | 核心指标 + 护栏指标 |
| **边际误差** | 可接受波动范围 |
| **关停值** | 护栏指标的底线 |

### 案例参数示例

| 参数 | 值 |
|:---|:---|
| **实验假设** | 为特定场景用户提供利息减免券，提升5%营收 |
| **核心指标** | 营收金额 |
| **护栏指标** | 点击转化率、成交金额、全产品营收 |
| **最小流量** | 2000笔转化订单 |
| **预计周期** | 2周 |
| **显著性水平** | 5% |
| **统计功效** | 80% |
| **流量分配** | 50%派券（实验组）vs 50%不派券（对照组） |

## 三、实验落地挑战

### 跨部门协作问题

| 部门 | 疑虑 |
|:---|:---|
| **研发** | 无法将满足条件客户均匀分成两组 |
| **业务** | 要求实时监控，方向错误时需尽早关停 |
| **页面产品** | 现有页面改造实验可能与目标客群冲突 |
| **数据分析** | 追踪任务过多，无法及时完成数据处理 |

### 核心待解决问题

1. 如何快速创建和修改实验？
2. 如何保证分流均匀性？
3. 多实验冲突时如何确保效果不受影响？
4. 如何实现实验数据实时监控？
5. 如何提升数据分析效率？
