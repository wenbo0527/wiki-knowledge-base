## 二、需求背景

### 2.1 触发
2026-06-12 15:21 文博在飞书提出需求:客户360中,「业务核心明细 TAB」下的「用信列表」需增加「用信产品 ID」字段(业务展示用的产品编号)。

### 2.2 业务价值
- 业务人员在查看客户用信记录时,需要通过「用信产品 ID」快速定位到具体的产品定义
- 业务方核账 / 风控排查时,用产品 ID 反查上游产品系统
- 与「产品名称」配合,形成"产品编号 + 产品名称"双重定位(防止同名产品混淆)

### 2.3 归属与承接
- **产品域**: PD-DEX 数据探索
- **Epic**: EPIC-DEX-CUSTOMER_360 客户360全景能力
- **Feature**: FEAT-DEX-CUSTOMER_360-REALTIME-001 SU 贷实时业务数据
- **Story**: STORY-DEX-CUSTOMER_360-REALTIME-004 用信列表展示(已在 v1.0 定义)
- **承接方**: **data_community_pm** (Agent,口语化称呼"研发团队 2",**非人类团队**)
- **派活方式**: A2A 协议 (`openclaw agent --agent data_community_pm --message ...`)
- **本次不开发**: PRD 编写是 Tony 职责,代码改动归 data_community_pm

## 三、字段定义

### 3.1 字段基本属性

| 属性 | 内容 |
|:---|:---|
| 字段名(中文) | 用信产品 ID |
| 字段名(数据层) | `productKey` |
| 数据类型 | 字符串(String) |
| 业务含义 | 业务展示用的产品编号,**非**数据库主键 |
| 取值示例 | `CREDIT_SELF_001`、`CREDIT_SELF_002`、`LN-2024-009`、`LN-2025-007` |
| 数据来源 | 上游 API 返回(已在 `mock/customer360.ts` 中定义) |
| 是否必填 | 是(上游保证必有值) |
| 是否唯一 | 否(同一产品可多次用信) |

### 3.2 与现有字段的关系

| 字段 | 关系 | 区别 |
|:---|:---|:---|
| 产品名称(`productName`) | 互补 | 名称是"给人看的",ID 是"给系统查的";同一 ID 对应同一名称 |
| 用信编号(`loanNo`) | 无关 | `loanNo` 是单次用信记录的 ID(借据号),`productKey` 是产品的 ID |
| 三方客户号(`thirdPartyCustomerId`) | 无关 | 三方客户号标识客户身份,与产品无关 |

## 四、Story 增量规范

### STORY-DEX-CUSTOMER_360-REALTIME-004: 用信列表展示(增量)

| 字段 | 内容 |
|:---|:---|
| 角色-场景-价值 | 作为**业务人员**,在**查看客户用信详情**时,需要**通过"用信产品 ID"快速定位到具体的产品定义**,以便**与上游产品系统对账、风控排查** |
| 优先级 | P0 |
| 状态 | 待开发 |
| 变更类型 | 增量 — 在 v1.0 Story 基础上,列定义从 5 列扩展为 6 列 |

**验收标准**(本版本 v1.1):

1. ✅ 功能标准:以表格形式展示用信记录
2. ✅ **列定义(6 列)**:产品名称、用信产品 ID、用信时间、借款金额、余额、状态
3. ✅ **「用信产品 ID」列规范**:
   - 列标题:用信产品 ID
   - 列宽:120px
   - 数据格式:字符串(直接透传上游 `productKey` 值)
   - 空值处理:上游无值时显示 "-"
   - 可点击复制(沿用现有"借据号"等列的 copyable 交互)
4. ✅ 状态标识:正常(绿色)/ 逾期(红色)/ 结清(灰色)
5. ✅ 分页:默认 20 条/页,支持切换
6. ✅ **特殊说明**:自营产品无三方借据号,无需展示
7. ✅ **列位置**:「用信产品 ID」列紧贴「产品名称」列右侧(便于"编号+名称"对照阅读)

**v1.0 旧列定义(供对比)**:

| 列名 | 说明 |
|:---|:---|
| 产品名称 | 用信产品名称 |
| 用信时间 | 用信发生时间 |
| 借款金额 | 借款本金(元) |
| 余额 | 当前待还金额(元) |
| 状态 | 用信状态 |

**v1.1 新列定义**:

| 列名 | 说明 | 示例 |
|:---|:---|:---|
| **产品名称** | 用信产品名称 | SU贷-极速版 |
| **🆕 用信产品 ID** | 业务展示用的产品编号(数据层 `productKey`) | `CREDIT_SELF_001` |
| 用信时间 | 用信发生时间 | 2026-05-01 |
| 借款金额 | 借款本金(元) | ¥50,000.00 |
| 余额 | 当前待还金额(元) | ¥45,000.00 |
| 状态 | 用信状态 | 正常/逾期/结清 |
