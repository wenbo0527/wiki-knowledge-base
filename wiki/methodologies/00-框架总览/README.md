## 三、能力关系网

### 3.1 关系图

```
需求决策 ──指导──▶ 产品设计 ──依赖──▶ 数据驱动 ──验证──▶ 价值闭环
    ▲                                                        │
    │                    支撑                                │
    └──────────────────────────────▶ 风险防控 ◀─────── 约束
                                     ▲
                                     │
                            技术理解 ──支撑──▶
```

### 3.2 六大关系

| 关系类型 | 能力对 | 说明 |
|:---|:---|:---|
| **指导** | 需求决策 → 产品设计 | 需求决策指导产品设计方向 |
| **依赖** | 产品设计 → 数据驱动 | 产品设计依赖数据验证 |
| **验证** | 数据驱动 → 价值闭环 | 数据驱动验证价值ROI |
| **支撑** | 价值闭环 → 需求决策 | 价值评估支撑需求决策 |
| **支撑** | 技术理解 → 需求决策/风险防控 | 技术可行性支撑决策和风控 |
| **约束** | 风险防控 → 技术理解 | 风控约束技术选型 |

### 3.3 跨能力案例

| 案例 | 涉及能力 | 关系类型 |
|:---|:---|:---|
| ChatBI | 产品设计+数据驱动+风险防控 | 三重关联 |
| 数据门户 | 产品设计+数据驱动+价值闭环 | 三重关联 |
| 跨渠道指标 | 数据驱动+价值闭环 | 双重关联 |

详见：[能力关系网.md](能力关系网.md)

### L1: 流程步骤（做什么）

| 能力 | 四步流程 |
|:---|:---|
| 01 价值闭环 | 论证→运营→衡量→迭代 |
| 02 需求决策 | 识别→分析→评估→输出 |
| 03 数据驱动 | 采集→分析→执行→验证 |
| 04 产品设计 | 理解→设计→原型→迭代 |
| 05 技术理解 | 分类→评估→设计→输出 |
| 06 风险防控 | 识别→评估→控制→监控 |
