# 视觉锚定偏差：VLM 评估的系统性风险

## 一、核心发现

### 研究问题

图像上的数字锚点会系统性地偏差 Vision-Language Model 的质量判断。

### 关键数据

| 发现 | 数据 |
|:---|:---|
| **锚定效应大小** | 是严重图像质量下降的 **2.5 倍** |
| **受影响范围** | 6 个 VLM，5 个架构家族，全部受影响 |
| **统计显著性** | ANOVA eta² = 0.18-0.77, p < 0.001 |
| **可解释性** | 锚定效应不可简化为视觉变化 |

### 核心结论

> **图像上的数字锚点比图像质量退化对 VLM 判断的影响更大。**

---

## 二、技术细节

### 实验设计

1. 在图像上嵌入数字锚点
2. 测试 6 个主流 VLM
3. 测量锚点对质量判断的影响
4. 分层探测分析 (Layer-wise probing)

### 关键实验结果

#### 锚定效应 vs 质量退化

```
锚定效应: +2.5x (相对于严重图像质量下降)
```

这意味着：
- 一个很小的数字（如 "$9.99"）可能比图像严重模糊对 VLM 判断的影响更大

#### 分层分析

| Layer 范围 | 现象 |
|:---|:---|
| **L1-L11** | 锚定分类饱和 |
| **L12-L34** | 次优预测层 |
| **更深层** | 最优预测层 (R² = 0.69-0.91) |

#### 架构差异

| 融合模式 | 模型数量 |
|:---|:---|
| **Instant fusion (L1-L2)** | 2 |
| **Partial fusion** | 1 |
| **No fusion** | 3 |

## 三、对实践的启示

### ⚠️ VLM 评估风险

| 风险场景 | 问题 |
|:---|:---|
| **电商图像** | 价格标签锚定 → 错误的质量判断 |
| **医学图像** | ROI 数字标记 → 偏差诊断 |
| **文档理解** | 页码/编号 → 错误的内容理解 |

### 评估设计建议

```
□ 评估 VLM 时移除图像上的数字标注
□ 在数字丰富的场景使用 VLM 要格外谨慎
□ 考虑在更深层做任务相关的探测
□ 留意不同架构的融合模式差异
```

---

## 四、认知更新

### 旧认知
- VLM 对图像内容的理解是客观的
- 图像上的数字是"噪声"，不影响判断

### 新认知
- 数字锚定是系统性偏差源
- 锚定效应是图像质量影响的 2.5 倍
- 需要主动消除锚定干扰
