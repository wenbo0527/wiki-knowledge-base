**正文**：

### 背景

之前分享过关于midscene.js实现UI自动化的方案，但实践效果不好：midscene.js需要通过截图、视觉识别元素，一个用例跑下来可能要几分钟。

因此研究了另一套更高效的方案：基于Playwright CLI + 无障碍树，构建配套Skill系列实现UI自动化。

### 一、核心概念

#### 什么是Playwright？

Playwright 是微软开发的 Web 自动化与端到端（E2E）测试框架，用于自动控制浏览器、模拟用户操作、验证页面功能。

#### 什么是Playwright CLI？

MCP本身是一种扩展AI能力边界的方式，但MCP会把完整工具Schema（函数名、参数、类型、描述、枚举…）**全部塞进上下文，导致token爆炸**。因此在AI Agent中，CLI的方式越来越受推崇。

Playwright CLI是在命令行里驱动浏览器的工具，底层用的是Playwright那套浏览器自动化能力。

#### 什么是无障碍树？

按下F12点击Elements，看到的是DOM树——一堆div、span、嵌套很深的节点。

**无障碍树**是浏览器在DOM之上整理的另一棵"给辅助技术用"的树，读屏软件、系统无障碍接口都靠它。每个节点带有：
- **role**：按钮、链接、文本框等
- **可访问名称**：屏幕朗读读出来的那段字
- **state**：是否禁用、是否勾选等

它会将关键元素抓取下来，用ref表示（如e105表示用户名输入框）。

**优势**：不是视觉识别，而是对DOM进行解析，**一次生成，后续可复用**。

### 二、实战案例

#### 1、环境准备
- 实战项目准备
- nodejs安装（playwright-cli前置）
- playwright-cli安装

#### 2、Skill下载与安装

配套的Skill主要有3个主Skill + 1个辅助Skill：

| Skill | 功能 |
|-------|------|
| 探索+生成JSON用例 | AI探索页面，生成结构化JSON用例 |
| JSON→Excel可视化 | 将JSON用例转为Excel便于评审（非必要） |
| 执行用例 | 执行JSON用例，支持中断恢复 |
| 辅助Skill | 辅助能力 |

#### 3、页面探索&测试用例编写

用户提供：页面URL + 需求文档/详细测试用例（输入越详细，生成越精准）

AI自动执行流程：
1. 调用playwright-cli，用有头模式打开浏览器
2. 进行无障碍快照采集（对每个变化页面）
3. 生成JSON文件作为UI自动化用例

JSON用例示例结构：
```json
{
  "step": 1,
  "element_ref": "e105",
  "action": "fill",
  "value": "username",
  "expected": "e107"
}
```

#### 4、Excel可视化（可选）

通过Skill将JSON用例转为Excel，便于可视化阅读和评审（但JSON对AI更友好）。

#### 5、执行用例

执行命令：`/playwright-cli-execute-stop-zh + json用例文件`

执行过程中：
- AI能自动识别验证码图片并输入
- 遇到AI无法解答的会暂停，等待人工解答
- **脚本自愈能力**：识别错误的元素 → 重新快照生成 → 修改脚本 → 重新执行

### 总结

本次用例中：
- AI对界面进行了快照处理，识别相关元素
- 能够在用例不足时自己探寻页面元素以补充用例
- 执行速度十分快速
- 能够识别基础验证图片并进行输入操作
- 能够进行脚本自愈，对于识别错误的元素则重新快照生成、修改元素并重新执行
