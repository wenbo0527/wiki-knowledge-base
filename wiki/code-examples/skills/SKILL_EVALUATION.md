## 一、核心理念

**建立有效的Skill维护机制，让大家越来越好**

| 维度 | 问题 | 权重 |
|------|------|:---:|
| **能自动化** | 这个Skill能自动执行吗？ | 25% |
| **有人使用** | 最近30天被调用过几次？ | 25% |
| **功能独特** | 有其他Skill替代吗？ | 25% |
| **持续评估** | 能定期复审优化吗？ | 25% |

## 二、四维评价模型

### 2.1 能自动化 (25%)

| 等级 | 标准 |
|------|------|
| ⭐⭐⭐⭐⭐ | scripts/完整，可自动执行 |
| ⭐⭐⭐⭐ | 有scripts/，部分自动 |
| ⭐⭐⭐ | 流程清晰，可半自动 |
| ⭐⭐ | 依赖人工判断 |
| ⭐ | 完全人工 |

**检查清单**:
- [ ] 有scripts/目录？
- [ ] scripts/可独立运行？
- [ ] 是否把重复操作脚本化了？
- [ ] 错误处理是否完善？

### 2.2 有人使用 (25%)

| 等级 | 标准 |
|------|------|
| ⭐⭐⭐⭐⭐ | 每周>5次调用 |
| ⭐⭐⭐⭐ | 每周3-5次调用 |
| ⭐⭐⭐ | 每周1-2次调用 |
| ⭐⭐ | 每月1-2次调用 |
| ⭐ | 3个月无调用 |

**检查清单**:
- [ ] 触发词是否清晰？
- [ ] 触发词是否优化（Use when + Don't use for）？
- [ ] 有被错误触发的记录吗？

### 2.3 功能独特 (25%)

| 等级 | 标准 |
|------|------|
| ⭐⭐⭐⭐⭐ | 唯一，无替代 |
| ⭐⭐⭐⭐ | 主要功能独特 |
| ⭐⭐⭐ | 部分功能重复 |
| ⭐⭐ | 大量重复 |
| ⭐ | 完全重复 |

**检查清单**:
- [ ] 有其他Skill做同样的事吗？
- [ ] 是否可以合并到其他Skill？
- [ ] 触发词是否有重叠？

### 2.4 持续评估 (25%)

| 等级 | 标准 |
|------|------|
| ⭐⭐⭐⭐⭐ | 有验证流程+定期复审 |
| ⭐⭐⭐⭐ | 有定期复审 |
| ⭐⭐⭐ | 有简单检查清单 |
| ⭐⭐ | 偶尔检查 |
| ⭐ | 从不检查 |

**检查清单**:
- [ ] 有Discovery验证吗？
- [ ] 有Logic验证吗？
- [ ] 有Edge Case处理吗？
- [ ] 最近30天更新过吗？

## 三、mgechev最佳实践对照

| 最佳实践 | 说明 | 我们的现状 |
|---------|------|------------|
| **SKILL.md < 500行** | 保持精简 | ⚠️ 部分超过 |
| **渐进式披露** | 案例移至references/ | ⚠️ 待优化 |
| **触发词优化** | Use when + Don't use for | ⚠️ 大部分缺失 |
| **scripts/确定性** | 重复操作脚本化 | ✅ 部分实现 |
| **references/一级深度** | 不过深嵌套 | ✅ 符合 |

## 五、持续评估机制

### 5.1 评估节奏

| 时间 | 动作 | 执行人 |
|------|------|--------|
| 每日 | Skill调用统计 | 自动(系统) |
| 每周 | 异常检查(0调用/高频失败) | 派蒙 |
| 每月 | 四维评分复审 | 尼克 |
| 每季度 | 去留决策+合并优化 | 派蒙+文博 |

### 5.2 状态流转

```
🟢活跃 ──────→ 🔵标准 ──────→ 🟠待改进
   ↓              ↓              ↓
 持续使用        偶尔使用       无人使用
   ↓              ↓              ↓
 自动执行       优化提醒    → 🔴待处理
                                     ↓
                                  合并/废弃
```

### 5.3 异常处理

| 异常 | 检测 | 处理 |
|------|------|------|
| **3个月无调用** | 月度检查 | 🟠→🟠待改进，通知维护者 |
| **触发词误触发** | 周度检查 | 更新触发词 |
| **SKILL.md > 500行** | 季度检查 | 拆分到references/ |
| **功能完全重复** | 季度检查 | 合并到其他Skill |

### 结构规范
□ SKILL.md < 500行
