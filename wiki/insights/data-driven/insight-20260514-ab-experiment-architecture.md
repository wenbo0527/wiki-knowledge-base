## 核心定位

作为中台核心产品，AB实验平台主要包含三大模块：

| 模块 | 说明 |
|:---|:---|
| **实验的创建与管理** | 实验配置、分组策略 |
| **实验的运行与部署** | 流量分发、功能开关 |
| **实验的复盘** | 数据分析、可视化报表 |

---

## 核心架构

```
用户请求 → 流量分配 → 实验分组 → 实验执行 → 数据收集
              ↓           ↓           ↓           ↓
           Hash分流    桶位划分    策略应用    指标采集
```

### 流量分流机制

| 机制 | 说明 |
|:---|:---|
| **Hash分流** | 基于用户ID进行Hash分配 |
| **正交分层** | 不同实验层之间互不干扰 |
| **流量互斥** | 同层实验流量不重叠 |

### 正交分层设计

```
Layer 1: 产品实验（流量A）
    ↓
Layer 2: 推荐实验（流量B，与A正交）
    ↓
Layer 3: 营销实验（流量C，与A、B正交）
```

## 关键概念

| 概念 | 说明 |
|:---|:---|
| **实验桶** | 实验分组容器 |

| **流量比例** | 实验组占比 |
| **置信度** | 统计显著性 |
