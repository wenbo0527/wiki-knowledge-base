## 四、统计显著性

### 4.1 参数设定

| 字段 | 值 |
|:---|:---:|
| **置信水平** | 95% |
| **统计功效** | 80% |
| **最小样本量** | 计算值 |

### 4.2 功效计算

```
样本量计算公式：
n = 2 × (Z_α/2 + Z_β)² × σ² / δ²

其中：
- Z_α/2 = 1.96 (95%置信度)
- Z_β = 0.84 (80%功效)
- σ² = 方差
- δ² = 最小可检测差异
```
