## 四、ROI计算

```
总收益 = 增量收入 + 成本节省 + 风险规避 + 效率提升
       = X万/年

总成本 = 研发成本 + 运维成本 + 数据成本 + ...
       = X万/年

ROI = (总收益 - 总成本) / 总成本 × 100%
    = (X - X) / X × 100%
    = X%
```
