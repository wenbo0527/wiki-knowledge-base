---

## AI记忆痛点

### 现有AI的核心局限

- **上下文窗口≠记忆**：类似人类"说完就忘"的短期记忆
- **重复错误现象**：同一操作需多次确认

### 核心问题

缺乏"记住怎么做对用户有用"的机制

---

## 进化引擎工作原理

### 核心差异：从"知其然"到"知其所以然"

| 维度 | 普通AI | 进化引擎AI |
|:---|:---|:---|
| 结果处理 | 仅知道得分 | 分析得分原因 |
| 行为调整 | 随机尝试 | 主动调整策略 |
| 核心能力 | 无因果理解 | 理解因果，主动优化 |

---

## 两大关键机制

### 1. 任务后自动复盘系统

**归因标签体系（7类）**：

| 类型 | 标签 |
|:---|:---|
| 🔴 错误类 | 验证不够、太急躁 |
| 🟡 方法类 | 方法不对路、工具没用好 |
| 🟠 策略类 | 过度谨慎 |
| 🟢 成功类 | 策略合适 |

**"顿悟"触发**：同一归因标签出现≥3次，生成指导后续策略的洞察

### 2. 五阶段推理框架

```
事实锚定 → 方案发散 → 价值评估 → 风险扫描 → 综合决策
```

动态适配：写代码加强"事实锚定"和"风险扫描"，写文案提高"方案发散"权重

## 仿生进化六步法

| 进化阶段 | 引擎实现方式 |
|:---|:---|
| 🧪 试错 | 每次任务结束对做法打分 |
| 🧬 变异 | 对高分做法微调产生新变种 |
| 🏆 适者生存 | 保留高分做法，淘汰低分策略 |
| 🔀 基因重组 | 组合两种好方法的优点形成新策略 |
| 📚 代际积累 | 经验跨任务传递 |
| 🧠 元认知 | 理解失败/成功原因 |
