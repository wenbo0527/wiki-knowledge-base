## 二、分流机制详解

### 分流节点

**定义**：决定用户分流的具体页面或业务环节

#### 实验类型划分

| 类型 | 分流位置 | 典型场景 |
|:---|:---|:---|
| **客户端实验** | 用户APP端 | 页面样式/改版 |
| **服务端实验** | 后台业务系统 | 策略/算法优化 |

## 三、分流比例：流量分层与正交设计

### 核心概念

| 概念 | 说明 |
|:---|:---|
| **层（Layer）** | 相互独立的业务环节 |
| **正交性** | 用户在不同层的分桶结果相互独立 |

### 分桶实现步骤

| 步骤 | 操作 |
|:---|:---|
| **1** | 确定请求Tag（UserID/DeviceID/CookieID/手机号） |
| **2** | 选择Hash函数（优先BKRT hash） |
| **3** | 计算分桶：Hash(Layer, Tag) % 1000 |

### 流量筛选原则

| 原则 | 说明 |
|:---|:---|
| **同层内** | 多个实验时，流量仅命中一个实验 |
| **不同层** | 流量随机独立命中 |
| **重复分流** | 同一流量两次经过分流服务，命中结果一致 |

### 正交分层效果

```
实验层1: A(10%), B(20%)
实验层2: C(30%), D(40%)
        ↓ 正交
组合流量: AC(3%), AD(4%), BC(6%), BD(8%)
```

**价值**：一份流量可同时参与N个实验

## 四、流量均匀性评估

### 同层不同组均匀性

```
hash_diff = 同层不同组用户数量标准差 / 同层不同组用户数量均值
```

数值越小，均匀性越好

### 不同层间均匀性

```
层间差异 = 不同层不同组用户数据交集标准差 / 不同层不同组用户交集均值
```

数值越小，层间相关性越低（正交性越好）
