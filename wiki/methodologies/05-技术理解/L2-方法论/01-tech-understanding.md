## 三、具体方法论详情

### 1. 机器学习认知方法

**核心**：理解ML原理，能和算法对话

**成熟框架**：
- 监督学习/无监督学习/强化学习
- 分类/回归/聚类
- 特征工程/模型训练/模型评估

**实践要点**：
- 能看懂模型训练的流程
- 能和算法工程师对齐评估指标
- 能把业务问题转化为ML问题

**✅ 实践案例：数据门户指标体系**
- 问题：如何让业务方自助找数、用数？
- 技术选型：传统检索 vs NLP语义检索 vs 混合
- 评估指标：查准率、查全率、响应时间
- 经验：不是所有场景都适合ML，要看数据规模和用户需求

---

### 2. 工作流引擎认知方法

**核心**：理解工作流引擎，能设计业务流程

**成熟框架**：
- DAG（有向无环图）
- 节点/边/条件分支
- 串行/并行/依赖

**实践要点**：
- 能设计复杂的业务流程
- 能处理异常和重试
- 能优化流程性能

**✅ 实践案例：营销套件画布**
- 问题：运营人员如何自主配置营销策略？
- 技术方案：可视化画布 + 节点编排 + 条件分支
- 关键设计：串行执行 vs 并行触达、定时触发 vs 事件触发
- 经验：业务人员不关心底层DAG，只关心"拖拽-配置-发布"

---

### 3. Agent选型框架方法

**核心**：什么时候用Agent，怎么选

**成熟框架**：
- 单Agent vs 多Agent
- ReAct / Plan-and-Execute / Voice
- Tool use / Memory

**实践要点**：
- 判断任务复杂度决定是否需要Agent
- 选择合适的Agent架构
- 设计Agent间的协作方式

**✅ 实践案例：ChatBI对话式取数**
- 问题：业务人员想用自然语言查询数据
- 技术选型：NL2SQL（单Agent） vs 多Agent协作
- 实现方案：意图识别 → SQL生成 → 结果校验
- 经验：不是所有查询都需要复杂Agent，简单意图直接规则匹配更快

---

### 4. 模型评估方法

**核心**：准确率、召回率等指标的业务含义

**成熟框架**：
- AUC/KS/F1-score
- 混淆矩阵
- 业务阈值设定

**实践要点**：
- 把技术指标翻译成业务语言
- 根据业务场景设定合理的评估标准
- 建立模型性能与产品指标的映射

**✅ 实践案例：信用卡风控模型**
- 背景：风控模型需要高准确率，金融场景不容忍过多坏账
- 技术指标：KS值、AUC、IV值
- 业务转化：坏账率、千人逾期率、资产不良率
- 关键经验：模型评估要翻译成业务语言，业务方才能理解

---

### 5. 策略AI认知方法

**核心**：什么时候用规则，什么时候用AI

**成熟框架**：
- 规则引擎适用场景：明确输入、固定规则、100%精确
- AI适用场景：模糊输入、复杂规则、概率输出

**实践要点**：
- 用五维判断表评估是否适合AI
- 设计规则+AI的混合方案
- 确定边界和降级策略

**✅ 实践案例：营销策略规则+AI推荐**
- 背景：生息产品推荐，单月提升3000万
- 技术方案：专家规则（黑名单、准入规则）+ AI推荐（个性化推荐）
- 规则处理：高风险客户直接拒绝
- AI处理：中等风险客户的个性化产品推荐
- 关键经验：规则守底线，AI提效率，两者结合最优

---

### 6. Agent评估方法

**核心**：怎么评估Agent效果

**成熟框架**：
- 任务完成率
- 准确率/幻觉率
- 响应时间/Token消耗
- 用户满意度

**实践要点**：
- 定义Agent成功的标准
- 建立量化评估体系
- 持续监控和优化

**✅ 实践案例：ChatBI效果评估**
- 评估维度：SQL正确率、查询效率、用户体验
- 量化指标：
  - 意图识别准确率 > 85%
  - SQL生成成功率 > 90%
  - 平均响应时间 < 3秒
  - 用户满意度 > 4分（5分制）
- 监控体系：埋点追踪+日志分析+定期review

## 四、技术选型决策树

```
业务问题
    ↓
需要AI吗？
    ↓
┌─────────────────────────────────────────┐
│ 判断维度：                                  │
│ 1. 问题边界清晰吗？→ 不清晰 → AI可能适合    │
│ 2. 数据规模够大吗？→ 不够 → 规则可能更好  │
│ 3. 容错率要求高吗？→ 要求高 → AI风险大    │
│ 4. 已有成熟方案吗？→ 有 → 不需要AI        │
│ 5. AI优势明显吗？→ 不明显 → 不需要AI       │
└─────────────────────────────────────────┘
    ↓
结论：投入 / 观察 / 放弃
```
