# Skill 档案模板

> **版本**: v1.0
> **日期**: 2026-05-22
> **制定者**: 派蒙（大总管）
> **用途**: 为每个 Skill 建立标准档案页

---

## 📋 必填字段

| 字段 | 说明 | 示例 |
|:-----|:-----|:-----|
| **Skill 名称** | 唯一标识 | `brainstorming` |
| **版本** | 语义化版本 | `v1.2.3` |
| **分类** | 所属分类 | 通用/内容/技术/调研/基础设施 |
| **负责人** | 主要维护者 | Nick |
| **来源** | ClawHub/自建/预装 | ClawHub |
| **用途** | 一句话说明 | 结构化头脑风暴 |
| **状态** | 就绪/待配置/停用 | 就绪 |

---

## 📊 评分信息（四维评估）

| 维度 | 分值 | 说明 |
|:-----|:-----|:-----|
| **实用性** | /25 | 解决实际问题的能力 |
| **稳定性** | /25 | 运行可靠，无异常 |
| **易用性** | /25 | 文档清晰，容易上手 |
| **安全性** | /25 | 无安全隐患 |

| 维度 | 分值 | 说明 |
|:-----|:-----|:-----|
| **总分** | /100 | 四维合计 |
| **等级** | A+/A/B/C/D | 见评分标准 |

### 评分标准

| Grade | Score | Meaning |
|:------|:-----:|:-------|
| 🏆 A+ | 95-100 | Elite performance |
| ✅ A | 85-94 | Excellent |
| 👍 B | 70-84 | Good |
| ⚠️ C | 50-69 | Needs work |
| ❌ D | <50 | Broken |

## 📁 目录结构

```
wiki/
├── concepts/
│   └── skill-classification.md     # Skill 分类总览
├── entities/
│   └── skills/                      # Skill 档案目录
│       ├── brainstorming.md         # 示例：brainstorming
│       ├── humanizer.md
│       ├── requirement-understanding.md
│       └── ...
└── _templates/
    └── skill-profile.md             # 本模板
```

---

## 🔧 使用方法

1. 复制本模板到 `entities/skills/<skill-name>.md`
2. 填写所有必填字段
3. 更新 `_registry.md` 中的索引
