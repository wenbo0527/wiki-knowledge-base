### 1.2 业务挑战

| 挑战 | 说明 |
|:---|:---|
| **渠道分散** | 银行多个APP/渠道，数据分散 |
| **指标不一致** | 各渠道对同一指标定义不同 |
| **归因困难** | 无法串联用户跨渠道行为 |
| **用户ID割裂** | 不同渠道用户ID无法关联 |

---

## 二、解决方案

### 2.1 统一ID体系

| 方案 | 说明 |
|:---|:---|
| **注册ID** | 用户手机号作为统一注册标识 |
| **全局ID** | 身份证号作为跨渠道全局唯一标识 |
| **ID Mapping** | 建立ID映射关系，实现数据串联 |

### 2.2 ID Mapping能力

```
用户注册ID → 手机号
用户全局ID → 身份证号
产品ID、渠道ID → 统一管理

实现：
- 同产品用户全流程数据可串联
- 跨产品用户数据可串联
```

## 四、跨渠道归因

### 4.1 归因方法

| 方法 | 公式 | 适用场景 |
|:---|:---|:---|
| **加法拆解** | Y = ΣXi | 绝对值指标（UV、销售额） |
| **乘法拆解** | Y = ∏Xi | 转化率类指标 |
| **比率型拆解** | Y = A/B | 比率类指标 |

### 4.2 归因案例

```
全站商品详情页浏览量(IPV)拆解：
IPV = UV × UV转化率 × 人均IPV

通过乘法拆解定位：
- UV变化对IPV波动的贡献
- 转化率变化对IPV波动的贡献
- 人均IPV变化对IPV波动的贡献
```
