### 📈 当下AI热潮处于什么阶段？

AI是**革命性技术**，但已出现**典型泡沫迹象**。
- **技术本质**：先取代躯体功能 → 再取代可计算机化的思维 → 逐步替代更高层次的推理能力。
- **泡沫定义**：价格大幅上涨 + 公司表现亮眼 → 最终崩盘。
- **历史参照**：1929年大萧条前（电力、汽车、飞机、无线电普及）、2000年互联网泡沫。
- **形成机制**：
  - 全民确信技术会成功 → 忽略价格 → 借钱下注 → 价格持续攀升。
  - 上升期资产增值 = 抵押品变多 → 可借更多钱 → 效应不断复合。
- **关键概念**：**财富 ≠ 金钱**，账面财富无法直接消费，必须变现成现金。
  说白了，股票涨出来的纸面富贵，没卖出去换成钱之前，都不算真的赚了。

### 💥 泡沫为什么会破裂？

**利率上升 + 股票供给增加**是两大核心诱因。
- **直接导火索**：需要抛售资产换现金的情况出现，最常见的是**央行加息**。
  - 经济过热、通胀上行 → 央行收紧货币政策 → 利率上升。
  - 债务人需筹更多钱还债 + 高利率下债券收益 > 股权收益 → 资金从股市流出。
- **供给端压力**：股票几乎是**最容易生产的东西**，公司大量发行股票融资，供给快速增加。
- **泡沫是程度问题**：不是非黑即白的"有/没有"，关键看股票在谁手里。
  - 强势持有者（专业投资者）→ 抗跌性强。
  - 弱势持有者（缺乏专业知识、加杠杆、买杠杆ETF）→ 市场一下跌就恐慌抛售。
- **下行螺旋**：价格下跌 → 亏钱 → 抛售资产还债 → 需求减少 → 收入下降 → 进一步下跌，通常伴随**经济衰退**。
- **AI行业的特殊困境**：
  - 无法精确判断资金流入量 → 要么投不足被对手甩开，要么巨额投入。
  - 典型案例：融资5000万美元，估值10亿美元 → 账面有10亿股票，但没人真付了10亿，也没法直接花股票。

### 🌍 这一切发生在怎样的大周期里？

我们正处于**80年大周期的衰落阶段**，秩序正在更迭。
- **大周期时长**：平均约**80年**（约一个人的一生），上一轮起点是1945年二战后。
- **周期规律**：
  - 主导大国建立秩序 → 世界相对和平。
  - 债务积累、内部冲突、外部冲突交汇 → 秩序瓦解。
  - 债务出清、货币体系重构、国内秩序重建 → 开启新周期。
- **微观短周期**：衰退到衰退约**6年**（上下浮动3年）。
  - 衰退 → 货币宽松 → 繁荣 → 泡沫 → 通胀上升 → 货币收紧 → 再衰退。
- **长期增长底色**：知识一旦习得不会遗忘，技术持续进步，人类学习和执行能力不断提升，长期趋势向上。
- **当前位置**：美国、英国等国处于周期后期，特征是**过度负债 + 权力丧失**，正处于"衰落的崩溃期"。

### 🌐 世界秩序正在怎么变？

权力正在转移，世界可能走向**区域化**。
- **500年研究视角**：周期可量化（负债水平、教育水平、竞争力等），像体检一样客观。
- **规则 vs 权力**：二战后美国主导的"基于规则的秩序"（联合国等），一旦与权力冲突，**权力往往胜过规则**。
- **中国的角色**：
  - 没有占领或控制其他国家的意愿，核心目标是避免被孤立、受伤害，然后做好自己。
  - 在大多数国家已是**比美国更大的贸易伙伴**，资本持续涌入。
- **最可能的走向**：中美都保持强大实体地位 → 世界更多按区域划分（美洲、亚太等），避免大规模战争。
- **历史对照**：当前变化与**大英帝国衰落**时非常相似，美国的经济和军事影响力正在被侵蚀。

### ⚔️ 地缘冲突暴露了什么？

美国的全球执行力**比想象中脆弱**。
- **伊朗与霍尔木兹海峡**：
  - 美国**并不希望发动战争**，民众担心油价上涨和人员伤亡，且要求速战速决，而这种方式打不赢战争。
  - 伊朗有**9000万人口**，无法轻易长期占领和控制。
  - 伊朗战争是巨大错误，暴露了美国执行力的脆弱性，类似当年英国在苏伊士运河的处境——威胁不再有效。
- **亚洲格局变化**：
  - 许多国家原本认为美国会在亚洲扮演制衡角色，现在意识到美国可能不想"现身"。
  - 部分美国军事基地甚至可能成为负债，中国在该地区拥有巨大影响力。
- **非军事权力**：以芯片为例，若封锁台湾芯片出口通道，会导致**全球股市崩盘**，这种威胁能力本身就是权力。

### 🤖 AI会怎么改变工作和财富分配？

脑力劳动者面临被替代风险，**贫富差距会进一步拉大**。
- **进化路径**：
  - 农业时代 → 工业革命（机器取代体力劳动）→ AI时代（取代可计算机化的思维，且不断向高层次推理延伸）。
- **受益方**：拥有能取代劳动者的创意的**资本家**。
  - 企业收入中，劳动者分配份额下降，所有者份额上升。
- **就业冲击**：
  - 前0.1%~10%的顶尖群体，能积极利用AI自我加速，站在最前沿。
  - 普通脑力工作者，有被取代的风险，大学毕业生就业难度显著增加。
  - 泡沫破裂时冲击更大：公司为了生存裁员，同时用AI智能体/机器人替代员工。
- **财富分配**：
  - 约**61%的美国成年人**持有股票，但最富有的10%家庭持有近**90%的股票**。
  - 股票所有权高度集中 → AI带来的财富增长大部分流向顶端，进一步拉大贫富差距。
- **人类的独特价值**：情感和直觉是AI不具备的，能发挥人类智慧并与AI合作的人，将处于最前沿。

### 💡 普通人该怎么应对？

**你唯一的资产就是你自己**，适应力比聪明和努力更重要。
- **核心策略**：提升自己，让自己能以更优厚的报酬出售时间。
- **前10%法则**：处于人才梯队前10%，世界任你驰骋。
  - 金字塔顶端总能获得数倍于平均的溢价，多投入10%的时间精力提升，可能获得**两倍回报**。
- **技能的场景价值**：同样的技能，在不同行业/场景下价值天差地别。
  - 例子：同样是驾驶，Uber司机和私人专职司机报酬差距巨大。
- **适应力优先**：
  - 历史证明，最成功的不是最聪明或最努力的，而是**最善于适应环境**的物种和人群。
  - 你无法预知未来会怎样（比如谁能想到ClaudeCode会让程序员焦虑）。
- **行动方向**：先最大化认知 → 再利用AI等工具最大化效用 → 从事有成就感的工作，寻找自身本性与人生道路的契合点。

### 😊 金钱和幸福是什么关系？

越过基本线后，**金钱与幸福相关性很低**。
- 目标是达到"无需为生计惊慌"的水平，有足够经济支撑维持想要的生活，同时保持激情。
- 原则：让工作与热爱合二为一，同时不要忽略金钱的部分。
- 例子：达利欧热爱大自然，而这几乎不需要花钱。
