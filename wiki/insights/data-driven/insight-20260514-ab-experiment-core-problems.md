## AB实验核心问题

### Q1: AB实验主要解决什么问题？

**核心价值**：解决**因果推断**问题，明确动作A与结果B的关联（区别于相关性）。

### 因果关系三条件

| 条件 | 说明 |
|:---|:---|
| **有方向** | A导致B，不是B导致A |
| **有先后** | A发生在B之前 |
| **有改变** | A变化时B随之变化 |

## 实践挑战

### 常见问题

| 问题 | 说明 |
|:---|:---|
| **样本量不足** | 流量太小，结论不可靠 |
| **时间窗口** | 实验周期太短 |
| **指标选择** | 选择了错误的指标 |
| **辛普森悖论** | 分组数据与整体数据矛盾 |
| **新颖性效应** | 用户初期好奇心导致正向偏差 |

---

## 解决方案

| 策略 | 说明 |
|:---|:---|
| **样本量计算** | 提前计算所需最小样本量 |
| **AA实验** | 验证分流是否均匀 |
| **分层实验** | 控制混杂因素 |
| **长期追踪** | 观察持续效果 |
