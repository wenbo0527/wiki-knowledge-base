## 三、具体方法论详情

### 1. 三维思考方法

**核心**：技术×场景×价值怎么平衡

**成熟框架**：
| 维度 | 说明 | 平衡点 |
|:---|:---|:---|
| **技术** | 准确率、响应时效 | 技术可行性 |
| **场景** | 用户体验、易用性 | 场景适配性 |
| **价值** | 单次成本、商业ROI | 商业价值 |

**实践要点**：
- 不是追求单一维度最优
- 而是找到平衡点
- 根据业务场景调整权重

**✅ 实践案例：智能客服阈值平衡**
- 背景：智能客服需要平衡准确率和并发能力
- 技术维度：
  - 意图识别阈值从0.9→0.85
  - 准确率从95%→92%（微降）
  - 并发处理能力提升40%
- 场景维度：
  - 用户体验：92%准确率仍可接受
  - 响应速度：提升40%让用户更快得到回复
- 价值维度：
  - 成本：调用量增加但单次成本降低
  - 收益：更多用户得到及时服务
- **关键经验**：不是追求100%准确，而是平衡用户体验和商业效率

### 2. TCO测算方法

**核心**：总拥有成本怎么算

**成熟框架**：
| 成本项 | 说明 |
|:---|:---|
| **API调用费** | Token消耗 |
| **数据清洗** | 数据预处理成本 |
| **提示工程** | Prompt维护成本 |
| **模型运维** | 监控、迭代成本 |
| **合规审查** | 安全审计成本 |
| **人工兜底** | 必要时的人工介入 |

**实践要点**：
- 算清楚显性成本
- 算清楚隐性成本
- 留有buffer

**✅ 实践案例：营销套件成本测算**
| 成本项 | 月度成本估算 |
|:---|---:|
| API调用 | 5000元（10万次） |
| 数据清洗 | 2000元（数据校验） |
| Prompt维护 | 1000元（持续优化） |
| 模型运维 | 3000元（监控/迭代） |
| 人工兜底 | 5000元（10%人工介入） |
| **合计** | **16000元/月** |

**收益测算**：
- 原来人工配置成本：200元/策略
- 现在AI辅助：50元/策略
- 每月配置策略：200个
- **月度节省**：200×200 - 200×50 = 30,000元
- **月度净收益**：30,000 - 16,000 = **14,000元**

**关键经验**：不仅要算技术成本，还要算隐性成本（人力、时间）

### 3. ROI论证方法

**核心**：价值怎么证明

**成熟框架**：
| 方法 | 说明 | 适用场景 |
|:---|:---|:---|
| **替代成本法** | 替代了多少人力 | 效率提升类 |
| **增量收入法** | 带来了多少增量 | 收入提升类 |
| **防御性价值法** | 避免了多少损失 | 风险控制类 |

**ROI计算公式**：
```
ROI = （收益 - 成本）/ 成本 × 100%
```

**实践要点**：
- 量化每项收益
- 量化每项成本
- 设定期望回收周期

**✅ 实践案例：信用卡生息+3000万/月**
| 收益项 | 月度价值 |
|:---|---:|
| **增量收入** | +3000万（生息产品推荐） |
| **成本节省** | 100万（人力优化） |
| **总收益** | **3100万/月** |

| 成本项 | 月度成本 |
|:---|---:|
| **研发投入** | 50万（分摊） |
| **模型运维** | 10万 |
| **数据成本** | 20万 |
| **总成本** | **80万/月** |

**ROI计算**：
```
ROI = （3100万 - 80万）/ 80万 × 100% = 3775%
```

**关键经验**：
- 用增量收入法证明AI价值
- 成本要算全（不只是技术成本）
- 周期选择要合理（12个月回本是合理预期）
