# 助贷监管再升级：上海支付机构关停“7+4”类地方金融组织自动划扣服务深度解析

### **🔍 核心监管措施（背景）**

**监管行动概况**
- **监管对象**：**“7+4”类地方金融组织**（7类包括小额贷款公司、融资担保公司、区域性股权市场、典当行、融资租赁公司、商业保理公司、地方资产管理公司；4类包括投资公司、开展信用互助的农民专业合作社、社会众筹机构、地方各类交易场所）。
- **核心措施**：上海部分支付机构陆续**关停上述机构的支付账户自动划扣服务**（含助贷类担保费、服务费自动划扣和还款代扣）。
- **例外情况**：助贷机构的**科技主体支付通道**目前仍正常使用，相关权益类收费暂不受影响。
- **时间节点**：部分支付机构计划在**5月底完成对所有涉及商户的有序清退工作**。

### **📜 监管政策脉络（过程）**

| 时间 | 监管动作 | 核心内容 |
| :--- | :--- | :--- |
| **2025年底** | 专项监管措施 | 要求支付公司不得为金融机构特别是小贷公司开立支付账户；对内部年化收益率（IRR）超过24%的机构进行审查，严禁为高息业务提供通道支持 |
| **2026年初** | 全量客户合规排查 | 部分支付机构完成排查，杜绝违规网贷业务支付通道；启动全业务线合规专项排查；终止与涉嫌违规地方金融机构合作 |
| **2026年5月** | 上海地区执行关停 | 宝付、通联等支付机构关闭“7+4”类机构自动划扣服务；计划5月底完成商户清退 |
| **2026年起** | 支付机构评级新规 | 《非银行支付机构分类评级管理办法》将**金融类高风险商户占比、违规代扣投诉率**纳入核心考核指标 |

### **🎯 切断违规套利支付通道（细节）**

#### **(一) 支付机构执行情况**
- **宝付回应**：依据《非银行支付机构监督管理条例》《银行卡收单业务管理办法》等法规，对风险商户采取**暂停服务、限期整改、终止合作**等措施，防范金融风险。
- **行业现状**：上海助贷机构已开始**切换至其他地方支付机构**，以减少业务影响；小额贷款、融资担保、商业保理、融资租赁等组织受冲击最为明显。

#### **(二) 重点打击的违规模式**

博通咨询金融行业首席分析师王蓬博指出，此次行动重点打击三类违规模式：
1. **“双融担”叠加服务费**
2. **月系融担商城马甲变相高息**
3. **砍头息加代扣捆绑**  
目的是解决行业通过**多层嵌套、费用拆分**规避综合融资成本24%上限的问题。

### **🔄 构建“助贷新规+支付严管”闭环（影响）**

#### **(一) 监管逻辑与效果**
- **治理闭环**：从后端查产品转向前端断资金链路的**穿透式监管**，断支付比查产品更有效（查产品存在事后核查滞后、违规模式隐蔽等痛点）。
- **上海先行意义**：作为监管先行先试地区，执行存量清零、新增禁入要求，可降低高舆情高纠纷业务敞口，减少现场检查和评级降级风险。

#### **(二) 多方影响分析**

| 主体 | 短期影响 | 长期影响 |
| :--- | :--- | :--- |
| **借款人** | 可能被动陷入逾期，触发征信上报，**个人征信不良记录激增** | 融资渠道规范化，综合成本下降 |
| **“7+4”类机构** | 月系融担机构核心收入中断；还款代扣、服务费收取渠道受阻 | 合规机构转向银行直连；高风险机构退出市场 |
| **支付公司** | 10%—30%营收下滑；存量商户流失；系统改造成本上升 | 完成高风险业务出清，优化合规评级，避免吊销牌照风险 |
| **助贷行业** | 中小机构退出；行业加速出清 | 集中度提升，向持牌化、标准化、透明化发展；利润空间压缩 |

### **💡 专家观点与建议（补充）**

#### **(一) 不同立场观点**
- **王蓬博（博通咨询）**：断支付直接卡住违规业务资金流转闭环，是有效监管手段；行业将分化，头部合规机构通过银行直连过渡。
- **苏筱芮（素喜智研）**：普适性关停可能带来误伤，应按分级分类原则精准施策；无缓冲“硬着陆”可能引发连锁影响。
- **胥莉（上海交大安泰学院）**：助贷机构可能转向银行直连、自有场景运营及低费率模式。

#### **(二) 政策优化建议**

苏筱芮建议：
1. 为存量机构预留**通道迁移、业务整改、资金平稳流转的时间**
2. 避免对合规与违规主体不加区分、全域关停
3. 坚持**分类施策与扶优限劣**相统一，为合规机构提供稳定发展环境
