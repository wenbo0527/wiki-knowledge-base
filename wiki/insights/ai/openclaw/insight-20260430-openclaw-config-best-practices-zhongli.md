## 8. VIBE CODING最佳实践（Get笔记总结）

### 8.1 核心原则

| 原则 | 说明 |
|:---|:---|
| **可控** | 任务拆解为最小单元 |
| **可恢复** | Checkpoint保存，错了回退 |
| **可累积** | 完成的模块拼成系统 |

### 8.2 实践技巧

**渐进式输入**：
- 不要一次性给AI大量代码
- 每次只做1个组件
- 验证后再做下一个

**Checkpoint机制**：
```markdown
## Component_XXX
- 状态：✅完成
- 输出文件：xxx.ts
- 问题记录：无
```

**格式验证门控**：
- 每个阶段检查格式一致性
- 确保输出规范统一

### 8.3 Git版本管理

```bash
# 大变更前打tag
git tag -a "before-重构" -m "重构前版本"

# 如有问题快速回滚
git checkout before-重构
```
