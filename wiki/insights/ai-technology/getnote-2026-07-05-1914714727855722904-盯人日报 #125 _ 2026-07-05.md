### ⭐ 值得深读

📍 **Andrej Karpathy（概念）→ Google Cloud** · Google Cloud Blog / Geeky Gadgets · 2026-07-02
📝 **Google把Karpathy的"LLM维基"私房方法，做成了一个开放标准。** Google Cloud发布 **Open Knowledge Format（OKF，开放知识格式）**，正式把Andrej Karpathy今年4月提出、随后被社区（含Harrison Chase的Wiki Memory）广泛沿用的"LLM-wiki模式"标准化。核心极简：一个装满Markdown文件的目录 + YAML头部（metadata/tags/categories），**不需要SDK、不需要专有运行时、不需要数据库或搜索索引**——任何Agent都能读、任何人都能生产。它把"给AI用的知识库"从各家私有实现，收敛成一份人类可读、Agent可解析、可被持续交叉引用和维护的活文档规范。多家（Geeky Gadgets/Substack/SEOSiteTool）确认其定位为"为AI Agent而生的Markdown标准"。
🔗 [Geeky Gadgets：Google Releases Open Knowledge Format (OKF) to Standardize Karpathy LLM Wikis](https://www.geeky-gadgets.com/google-okf-llm-wiki-standard/)
💡 **为什么重要：** 长尾人物概念被巨头"收编成标准"的信号，且直接命中老刀关注的Agent记忆/上下文工程主线。跨期看：#123（Harrison Chase"Wiki Memory Pattern"，结构化Wiki替代无限上下文）→#124（社区衍生DeepFlow等落地）→#125 Google出手把它变成开放格式。关键转折：**"Agent记忆"从各家实验性范式，第一次有了跨厂商的开放规范载体**——而且刻意做成"无SDK、纯Markdown"的极简形态，意在成为通用底座。对老刀：这正是内斯塔工作流本身在用的"MEMORY.md/知识库"模式被官方标准化——判断"Agent长期记忆用什么格式沉淀"这件事，OKF可能是接下来一年的关键锚点，值得纳入长线主题跟踪。

📍 **唐杰 / 智谱 Z.ai** · SCMP / VentureBeat · 2026-07-01/02
📝 **智谱给GLM-5.2配上官方"驾驶舱"ZCode，用1/10价格正面撞Claude Code。** 智谱（海外称Z.ai，港股名"知识图谱技术"）7/1推出 **ZCode**——GLM-5.2的官方agentic coding harness（编码智能体外壳），SCMP定性为"中国公司把矛头对准Anthropic"。产品逻辑与Anthropic的Claude Code、OpenAI的Codex CLI一致：**不再只发一个裸API，而是把前沿模型+第一方Agent外壳打包成完整工具**，直接对标Cursor/Claude Code/GitHub Copilot。杀手锏是价格：GLM-5.2向所有GLM Coding Plan订阅用户开放，"**只有Anthropic高端Claude Code和Claude Max档位的十分之一**"；API定价$1.40/$4.40（输入/输出，每百万token），比Claude Opus 4.8（$5/$25）便宜最高82%。同期SCMP也点出Anthropic正移除Claude Code里针对中国用户的隐藏追踪代码，两者交锋加剧。
🔗 [VentureBeat：Z.ai launches ZCode to challenge Cursor, Claude Code and GitHub Copilot](https://venturebeat.com/technology/z-ai-launches-zcode-to-challenge-cursor-claude-code-and-github-copilot-in-ai-coding)
💡 **为什么重要：** 中国AI一手落地，且是竞争维度的关键升级。跨期看：#123（GLM-5.2调用量连续九周领跑）→#124（Kimi K2.7 Code被微软内嵌进Copilot）→#125 智谱**自己造harness**。信号很清晰：中国厂商正从"提供便宜好用的模型"，升级到"提供从模型到工具外壳的完整栈"——ZCode是要在Claude Code/Cursor统治的编码Agent入口上，用价格撕开缺口。对老刀：这是判断"中国AI能不能拿下开发者日常工作流入口"的直接观测点。模型可以被跑分追平，但**harness=用户每天打开的那个工具**，一旦形成使用习惯，比模型能力更难被替换。

## 态势判断

1. **"Agent记忆"从私有范式走向开放标准，入口之争提前打响**：跨期对比：#123（Harrison Chase提"Wiki Memory Pattern"，把无限上下文换成结构化Wiki）→#124（社区DeepFlow等衍生落地）→#125 **Google出手把Karpathy的"LLM维基"标准化为OKF**（纯Markdown+YAML、无SDK）。关键转折：过去一年各家都在私下摸索"怎么给Agent做长期记忆"，现在第一次有了跨厂商的开放格式载体，而且刻意做成极简通用形态。值得跨期盯：OKF会不会像MCP一样成为事实标准、Anthropic/OpenAI是否跟进或另立门户——**谁定义了Agent的记忆格式，谁就握住了Agent生态的一块地基**。对内斯塔自身工作流也是直接相关：MEMORY.md/知识库这套做法正在被官方化。

2. **中国AI的竞争从"模型跑分/价格"升级到"harness入口 + 定价机制"两条新战线**：跨期对比：#123（GLM-5.2调用量九周领跑、美国份额从72%跌至33%）→#124（Kimi被微软内嵌进Copilot）→#125 智谱**自建ZCode harness**（1/10价格撞Claude Code）+ DeepSeek**引入峰谷定价**（首次给高峰加价）。关键分野：一边是智谱往上走——从"提供模型"到"提供从模型到工具外壳的完整栈"，抢开发者每天打开的那个入口；另一边是DeepSeek往回收——从"无脑降价抢份额"到"承认算力有时段稀缺性、分时调度"。信号：中国开源阵营正在同时解两道题——**分发权**（harness=习惯）和**可持续性**（低价路线遇到算力硬约束）。值得盯：ZCode能不能真的从Claude Code/Cursor手里抢到开发者习惯，以及峰谷定价会不会成为全行业跟进的新常态——若如此，"AI像水电一样便宜普惠"的叙事将首次出现裂缝。
