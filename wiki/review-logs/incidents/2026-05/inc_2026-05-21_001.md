## 问题描述

agent_task_board.py wrapper 参数解析有误，导致创建任务时需要手动指定参数位置，不能用 --flag value 格式。

## 影响分析

| 影响范围 | 说明 |
|:---|:---|
| **功能影响** | 无法方便地使用CLI创建任务 |
| **用户体验** | Agent使用时需要记忆错误格式 |
| **数据影响** | 无数据损失 |

## 根因分析

### 技术层面

1. **直接原因**：argparse 参数解析顺序问题
2. **深层原因**：使用了位置参数而非可选参数

### 关键问题

> wrapper 层的参数传递逻辑与原生 argparse 不兼容

## 解决措施

### 已尝试的措施

| 时间 | 措施 | 结果 |
|:---|:---|:---|
| 14:05 | 使用 python3 task_tool.py 直接调用 | ✅ 成功 |
| 14:10 | 修复 wrapper 参数解析 | ✅ 成功 |

### 最终解决方案

```bash
# 改用 argparse 子命令方式
# 简化版：
python3 agent_task_board.py list --status pending
python3 agent_task_board.py create --title "xxx" --type SOP --assignee Tony --created-by Paimon
```
