## 产品定位

| 维度 | 说明 |
|:---|:---|
| **官方定位** | 「The open-source managed agents platform」（开源的代理管理平台） |
| **实际体验定位** | 融合AI代理的**项目管理工具**（类似Linear + AI Agent） |

---

## 核心创新

**「分时系统」概念**

> 多个AI Agent可以像人类团队一样分工协作，每个Agent处理不同的任务或同一任务的不同阶段。

---

## 核心功能

| 功能 | 说明 |
|:---|:---|
| **Agent管理** | 创建、配置、监控多个AI Agent |
| **任务分配** | 将任务分配给合适的Agent |
| **协作编排** | 定义Agent之间的协作流程 |
| **结果汇总** | 整合多Agent的输出 |

---

## 应用场景

| 场景 | 说明 |
|:---|:---|
| **并行处理** | 多个任务同时处理 |
| **流水线** | 任务按阶段分工 |
| **评审流程** | 多个Agent互相审查 |
| **研究助手** | 分工收集、分析、汇总 |
