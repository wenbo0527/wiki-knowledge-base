# 📊 Templates 文档模板 质量评价体系

> **制定时间**: 2026-04-30
> **制定者**: 尼克·弗瑞 🕵️
> **定位**: 评估文档模板质量，指导模板入库/迭代决策
> **适用范围**: `wiki/templates/` 及 `文档仓库/产品管理项目/模板/`

---

## 1. 评价维度

### 1.1 四维评价模型

| 维度 | 说明 | 权重 |
|------|------|------|
| **🔷 完整性** | 模板结构是否完整 | 30% |
| **🔷 可用性** | 是否易于理解和使用 | 25% |
| **🔷 规范性** | 是否符合团队文档规范 | 25% |
| **🔷 实用性** | 是否能直接产出高质量文档 | 20% |

### 1.2 评分标准

| 等级 | 分数 | 说明 |
|------|------|------|
| ⭐⭐⭐⭐⭐ | 90-100 | 卓越模板，团队最佳实践 |
| ⭐⭐⭐⭐ | 75-89 | 优秀模板，可直接使用 |
| ⭐⭐⭐ | 60-74 | 良好模板，需小幅调整 |
| ⭐⭐ | 45-59 | 一般，需较大改动 |
| ⭐ | <45 | 较差，不推荐使用 |

## 2. 详细评价标准

### 🔷 完整性 (30%)

| 等级 | 标准 |
|------|------|
| ⭐⭐⭐⭐⭐ | 所有章节完整 + 元信息 + 更新日志 + 使用说明 |
| ⭐⭐⭐⭐ | 章节完整 + 元信息 + 更新日志 |
| ⭐⭐⭐ | 主要章节完整 |
| ⭐⭐ | 部分章节缺失 |
| ⭐ | 章节混乱或不完整 |

**检查清单**:
- [ ] 元信息完整（版本/日期/作者/状态）
- [ ] 主要章节齐全
- [ ] 相关资源章节
- [ ] 变更记录章节
- [ ] 使用说明/指南

### 🔷 可用性 (25%)

| 等级 | 标准 |
|------|------|
| ⭐⭐⭐⭐⭐ | 变量清晰 + 示例完整 + 说明详细 |
| ⭐⭐⭐⭐ | 变量清晰 + 有示例 |
| ⭐⭐⭐ | 基本可理解 |
| ⭐⭐ | 需要查阅才能理解 |
| ⭐ | 难以理解 |

**检查清单**:
- [ ] 变量命名有意义（如 `{{date}}` 而非 `{{x}}`）
- [ ] 有填写示例
- [ ] 有章节说明
- [ ] 格式清晰易读
- [ ] 有使用指南

### 🔷 规范性 (25%)

| 等级 | 标准 |
|------|------|
| ⭐⭐⭐⭐⭐ | 完全符合规范 + 有版本控制 + 分级标注 |
| ⭐⭐⭐⭐ | 符合主要规范 |
| ⭐⭐⭐ | 基本符合规范 |
| ⭐⭐ | 部分不符合 |
| ⭐ | 严重不符合规范 |

**检查清单**:
- [ ] 符合Wiki命名规范
- [ ] 有版本号标注
- [ ] 有状态标注（草稿/评审/正式）
- [ ] 有分级标注（公开/内部/敏感）
- [ ] 变更记录格式规范

### 🔷 实用性 (20%)

| 等级 | 标准 |
|------|------|
| ⭐⭐⭐⭐⭐ | 可直接使用 + 产出质量高 + 节省>50%时间 |
| ⭐⭐⭐⭐ | 可直接使用 + 产出质量较高 |
| ⭐⭐⭐ | 可使用，需要小幅调整 |
| ⭐⭐ | 需要较大改动 |
| ⭐ | 基本不可用 |

**检查清单**:
- [ ] 可直接复制使用
- [ ] 产出文档结构规范
- [ ] 能覆盖大多数场景
- [ ] 有常见场景示例
- [ ] 节省撰写时间

## 3. 入库决策

### 3.1 入库标准

| 类型 | 入库阈值 | 说明 |
|------|----------|------|
| **正式入库** | ≥60分 | 可进入正式模板库 |
| **暂存观察** | 45-59分 | 需要改进后再入库 |
| **不入库** | <45分 | 不符合标准 |

### 3.2 状态定义

| 状态 | 标识 | 说明 | 分数范围 |
|------|------|------|----------|
| **最佳实践** | 🏆 | 团队标杆模板 | ≥85 |
| **标准模板** | ✅ | 正式可用 | 60-84 |
| **待改进** | ⚠️ | 需改进 | 45-59 |
| **废弃** | ❌ | 不推荐 | <45 |

### 3.3 状态转换

```
⚠️待改进 → ✅标准模板: 改进后达到60分
⚠️待改进 → ❌废弃: 30天内未改进
✅标准模板 → 🏆最佳实践: 多次使用反馈优秀
✅标准模板 → ❌废弃: 发现严重问题
```

## 4. 模板分类体系

### 4.1 模板分类

| 分类 | 代码 | 说明 |
|------|------|------|
| **产品域模板** | PD | 产品域说明文档 |
| **Epic模板** | EPIC | Epic说明文档 |
| **Feature模板** | FEAT | Feature说明文档 |
| **PRD模板** | PRD | 产品需求文档 |
| **技术模板** | TECH | 技术方案/架构设计 |
| **操作手册** | OPS | 产品操作手册 |
| **日志模板** | LOG | 会议纪要/变更记录 |
| **检查清单** | CHECK | 检查类模板 |

### 4.2 模板命名规范

```
{分类代码}-{名称}.md
示例:
- PD-产品域说明文档.md
- TECH-技术方案.md
- LOG-会议纪要.md
```

## 5. 模板质量评审流程

### 5.1 评审时机

| 时机 | 说明 |
|------|------|
| **新建评审** | 新模板创建后入库前 |
| **定期复审** | 每半年复审一次 |
| **问题触发** | 发现使用时问题 |
| **版本升级** | 模板重大更新后 |

### 5.2 评审流程

```
┌─────────────────────────────────────────────────────────────┐
│                    模板评审流程                              │
├─────────────────────────────────────────────────────────────┤
│                                                              │
│  Step 1: 自评                                               │
│  └── 贡献者对照四维检查清单自评                              │
│                                                              │
│  Step 2: 试用验证                                          │
│  └── 用模板实际产出一份文档，验证可用性                       │
│                                                              │
│  Step 3: 四维评分                                          │
│  └── 完整性/可用性/规范性/实用性                             │
│                                                              │
│  Step 4: 综合定级                                           │
│  └── 计算加权总分，确定等级                                   │
│                                                              │
│  Step 5: 入库决策                                           │
│  ├── ≥60分 → 正式入库                                       │
│  ├── 45-59分 → 暂存，待改进                                │
│  └── <45分 → 退回                                          │
│                                                              │
│  Step 6: 评审记录                                           │
│  └── 记录到 TEMPLATE_EVALUATION_LOG.md                      │
│                                                              │
└─────────────────────────────────────────────────────────────┘
```

### 5.3 评审记录格式

```markdown
## {模板名称} 评审记录

| 日期 | 评审人 | 综合分 | 等级 | 状态 | 备注 |
|------|--------|--------|------|------|------|
| 2026-04-30 | 尼克 | 78 | ✅ | 标准模板 | 实用性高 |
```

## 7. 与其他体系的关系

### 7.1 体系对比

| 体系 | 评估对象 | 核心指标 | 入库阈值 |
|------|----------|----------|----------|
| **RSS源评估** | 信息源 | 产出质量文章数 | TIER升降 |
| **Code Examples评估** | 代码样例 | 六角综合评分 | ≥60分 |
| **Template评估** | 文档模板 | 四维综合评分 | ≥60分 |

### 7.2 协同关系

```
Template产出文档 → Code Examples素材
Code Examples可复用模块 → 模板优化
模板质量 → 文档质量 → Wiki质量
```
