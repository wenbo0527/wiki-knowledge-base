# Agent Workflow：从任务自动化的四种核心环节到实践框架

> **版本**: v1.0

## 核心定义

> **TL;DR**: Agent Workflow = LLM智能体 + 可编排的任务流程，核心是"以LLM为决策核心，把复杂任务拆成步骤，在可控框架内动态规划、反思迭代"。

### 与传统Workflow的关键差异

| 维度 | 传统Workflow | Agent Workflow |
|:---|:---|:---|
| **流程特性** | 流程写死 | 框架半固定 |
| **决策方式** | 规则驱动 | LLM动态决策 |
| **灵活性** | 无自主决策 | 可规划、可工具、可反思 |
| **适用场景** | 简单重复任务 | 复杂长链路任务 |

---

## 四环节核心工作流

### 1. Understand（理解）

| 要素 | 说明 |
|:---|:---|
| **核心功能** | 将模糊的高层目标转化为明确的技术需求 |
| **输入** | 模糊目标（如"优化数据管道"） |
| **输出** | 明确的技术需求 |
| **关键** | 理解边界和约束 |

### 2. Plan（规划）

| 要素 | 说明 |
|:---|:---|
| **核心功能** | 生成可操作的多步方案 |
| **输入** | 明确的技术需求 |
| **输出** | 结构化的执行计划（Plan） |
| **决策内容** | 任务执行顺序、依赖关系、是否并行 |

### 3. Execute（执行）

| 要素 | 说明 |
|:---|:---|
| **执行方式** | 按计划执行LLM推理、工具调用、API请求等 |
| **技术核心** | Function Calling + 工具路由 |
| **输出** | 中间结果、工具返回数据 |
| **关键** | 按计划执行，不偏离 |

### 4. Critique（反思）

| 要素 | 说明 |
|:---|:---|
| **核心功能** | 评估执行结果，判断是否达标、是否出错 |
| **评估内容** | 是否达标、是否存在错误、是否需要重试/调整 |
| **关键** | 自我校验、错误回溯、结果优化 |
| **输出** | 评分、问题点、修正方案 |

---

## 反思机制详解

> **来源**: 原文"最接近人类智能的环节"

### 反思类型

| 类型 | 说明 | 产出 |
|:---|:---|:---|
| **即时反思** | 每次工具调用后 | 结果评估、问题识别 |
| **任务反思** | 任务完成后 | 整体评估、改进建议 |
| **跨任务反思** | 跨任务模式识别 | 经验沉淀、规则提取 |

### 反思闭环

```
执行 → 反思 → 更新 → 下一轮执行
  ↑                            │
  └────────────────────────────┘
```

### 反思与更新的区别

| 环节 | 说明 |
|:---|:---|
| **反思（Reflection）** | 评估结果是否达标/出错 |
| **更新（Update）** | 更新记忆/计划，进入下一轮 |

## 规划与执行的模式选择

### ReAct模式（边想边做）

| 特点 | 适用场景 |
|:---|:---|
| 快速响应 | 简单任务 |
| 实时交互 | 用户直接对话 |
| 短周期 | 单轮或少量多轮 |

### Plan-and-Execute模式（先规划再执行）

| 特点 | 适用场景 |
|:---|:---|
| 结构化执行 | 复杂任务 |
| 长周期 | 高代价操作 |
| 难回滚场景 | 需要先规划再执行 |

### 选择依据

| 维度 | ReAct | Plan-and-Execute |
|:---|:---|:---|
| **任务复杂度** | 简单 | 复杂 |
| **操作代价** | 低 | 高 |
| **回滚难度** | 易 | 难 |
| **用户交互** | 多 | 少 |

## 工具调用设计

### Function Calling核心

| 要素 | 说明 |
|:---|:---|
| **定义** | LLM调用外部工具的能力 |
| **输入** | 自然语言指令 |
| **输出** | 结构化函数调用 |

### 工具数量控制

| 经验值 | 说明 |
|:---|:---|
| **≤10个** | 单Agent最佳工具数量 |
| **40-50个** | 召回率从95%骤降至30%的临界点 |

## 实践建议

### 规划环节常见问题

| 问题 | 原因 | 解决 |
|:---|:---|:---|
| **计划偏离** | 执行中发现新信息 | 反思后调整计划 |
| **过度规划** | 试图规划所有细节 | 分段规划，保留调整空间 |
| **计划僵化** | 不接受计划外情况 | 保留反思和调整机制 |

### 反思环节常见问题

| 问题 | 原因 | 解决 |
|:---|:---|:---|
| **反思不足** | 只看结果，不看过程 | 分层反思 |
| **反思过度** | 反复重试无法推进 | 设置重试上限 |
| **反思失真** | 自我服务偏差 | 外部验证 |
