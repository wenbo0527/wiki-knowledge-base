## 价值评估框架

### ROI 计算

```
ROI = (收益 - 成本) / 成本 × 100%

其中：
- 收益 = 收入增加 + 成本节约 + 风险降低
- 成本 = 开发成本 + 维护成本 + 机会成本
```

### TCO 分析

| 成本类型 | 说明 | 周期 |
|:---|:---|:---|
| **采购成本** | 许可/购买费用 | 一次性 |
| **实施成本** | 开发/集成/培训 | 一次性 |
| **运营成本** | 人力/基础设施 | 年度 |
| **维护成本** | 修复/升级 | 年度 |
