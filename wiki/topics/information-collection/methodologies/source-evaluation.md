# 来源评估体系

> 如何评估和分级信息来源，确保情报质量
> 版本: v1.0
> 创建: 2026-05-01

---

## 1. 为什么需要来源评估

```
问题:
├── 信息过载: 太多信息，无法处理
├── 质量参差: 有价值的只有少数
├── 时效性: 过时信息价值大打折扣
└── 可靠性: 假信息和噪声影响判断

解决:
├── 来源分级: 按质量/优先级分类
├── 动态调整: 根据产出调整等级
└── 质量控制: 源头保证而非事后过滤
```

### 2.1 权威性 (Authority)

```
定义: 来源的背景、资质、认可度

评估问题:
├── 这个来源在领域内的声誉如何？
├── 有哪些背书？（引用数、背书机构）
├── 过去预测/分析准确吗？
└── 是否是直接当事人？

评分标准:
1分: 匿名/未知来源
2分: 普通个人/媒体
3分: 有一定影响力的个人/机构
4分: 领域内知名专家/机构
5分: 公认的权威，一手信息源

示例:
├── 5分: OpenAI官方博客、Nature论文
├── 4分: Lilian Weng博客、a16z文章
├── 3分: 技术媒体、行业协会报告
├── 2分: 社交媒体帖子、论坛讨论
└── 1分: 匿名评论、垃圾邮件
```

### 2.2 专业性 (Expertise)

```
定义: 来源在特定领域的知识深度

评估问题:
├── 这个来源是否专注于该领域？
├── 是否有相关背景/资质？
├── 是否能理解复杂的技术/概念？
└── 是否能提供独特洞察？

评分标准:
1分: 无相关背景
2分: 泛泛而谈
3分: 有基本理解
4分: 深度理解，能提供洞见
5分: 顶级专家，有一手研究

示例:
├── 5分: 论文作者、一线研究者
├── 4分: 资深从业者、技术博主
├── 3分: 有经验的记者、分析师
├── 2分: 入门级内容、转述者
└── 1分: 完全不相关
```

### 2.3 时效性 (Timeliness)

```
定义: 信息的及时程度和更新频率

评估问题:
├── 信息是什么时候发布的？
├── 来源多久更新一次？
├── 信息是否仍然有效？
└── 是否是"新闻"还是"历史"？

评分标准:
1分: >2年前或永久有效(方法论)
2分: 1年前
3分: 3-6个月前
4分: 1周-3个月前
5分: 24小时内或持续更新

示例:
├── 5分: Twitter实时、官方最新公告
├── 4分: 本周博客、本月报告
├── 3分: 本季度分析、近期论文
├── 2分: 去年报告、历史数据
└── 1分: 多年旧闻、过时趋势
```

### 2.4 独立性 (Independence)

```
定义: 来源是否有利益相关，能否客观

评估问题:
├── 来源是否有商业/政治利益？
├── 是否在推广特定产品/观点？
├── 是否经过同行评审？
└── 信息是否被过滤或编辑？

评分标准:
1分: 有强烈利益相关，明显偏颇
2分: 有利益相关，可能偏颇
3分: 不明确，可能有影响
4分: 基本独立，少量利益相关
5分: 完全独立，客观第三方

示例:
├── 5分: 学术论文(无利益)、独立分析师
├── 4分: 中立媒体、无利益冲突博主
├── 3分: 行业媒体、咨询公司报告
├── 2分: 供应商博客、招聘JD
└── 1分: PR稿、自家产品宣传
```

### 2.5 准确性 (Accuracy)

```
定义: 信息的真实程度和可验证性

评估问题:
├── 信息是否有具体来源/引用？
├── 事实是否可验证？
├── 是否有数据支撑？
├── 论证逻辑是否严密？
└── 是否被其他可靠来源证实？

评分标准:
1分: 无法验证，可能是假的
2分: 极少来源支撑
3分: 有一定来源，但未核实
4分: 有多个来源，基本可信
5分: 一手来源，完全可验证

示例:
├── 5分: 官方文件、一手采访、原始数据
├── 4分: 有引用的分析、知名媒体报道
├── 3分: 行业传闻、无具体来源
├── 2分: 推测性内容、未经证实的说法
└── 1分: 假新闻、阴谋论
```

### 2.6 可获取性 (Accessibility)

```
定义: 获取信息的难度和成本

评估问题:
├── 信息是否公开？
├── 是否需要付费？
├── 是否需要特殊权限？
├── 是否容易持续追踪？
└── 法律/道德上是否合规获取？

评分标准:
1分: 无法获取/违法获取
2分: 高昂付费、复杂权限
3分: 适度付费或需注册
4分: 免费但需登录
5分: 完全公开免费

示例:
├── 5分: 公开博客、RSS、GitHub
├── 4分: 需注册、简单登录
├── 3分: 邮件订阅、免费报告
├── 2分: 付费报告、conference talks
└── 1分: 内部数据、付费论文、非法获取
```

## 4. TIER分级管理

### 4.1 分级标准

| 等级 | 综合分 | 扫描频率 | 文章数限制 | 处理深度 |
|:---:|:------:|:--------:|:----------:|:--------:|
| **TIER_1** | ≥4.0 | 每日 | 全量/最多50篇 | Layer 3 |
| **TIER_2** | 3.0-3.9 | 每周 | 最多30篇 | Layer 2 |
| **TIER_3** | 2.0-2.9 | 每两周 | 最多10篇 | Layer 1 |
| **不推荐** | <2.0 | - | - | - |

### 4.2 晋升/降级规则

```
晋升条件:
├── TIER_3 → TIER_2: 30天内产出≥3篇被引用
├── TIER_2 → TIER_1: 30天内产出≥5篇被引用，或≥2篇深度分析
└── 需手动评估确认

降级条件:
├── TIER_1 → TIER_2: 连续30天无任何产出
├── TIER_2 → TIER_3: 连续60天无任何产出
└── 自动降级，但可手动提升

清除条件:
├── 连续60天无任何产出
├── 出现重大错误/假信息
└── 来源关闭/不可访问
```

## 5. 动态评估流程

### 5.1 每月评估

```
评估流程:

Step 1: 收集产出数据
├── 统计各来源本月产出
├── 记录被引用/使用情况
└── 收集质量反馈

Step 2: 计算综合得分
├── 使用加权评分
├── 对比上月得分
└── 识别得分变化

Step 3: 调整分级
├── 晋升/降级判定
├── 更新分级列表
└── 通知相关人员

Step 4: 寻找新来源
├── 尝试新博客/工具
├── 评估是否值得加入
└── 放入TIER_3测试
```

### 5.2 评估工具

```python
# 来源评估计算器
source_evaluation = {
    "name": "来源名称",
    "dimensions": {
        "authority": 4,      # 1-5
        "expertise": 5,
        "timeliness": 4,
        "independence": 4,
        "accuracy": 5,
        "accessibility": 5
    },
    "weights": {
        "authority": 0.25,
        "expertise": 0.20,
        "timeliness": 0.15,
        "independence": 0.10,
        "accuracy": 0.20,
        "accessibility": 0.10
    },
    "scenes": {
        "default": {"weights": "默认权重"},
        "investment": {"authority": 0.30, "accuracy": 0.25},
        "research": {"expertise": 0.30, "timeliness": 0.25}
    }
}

def calculate_score(source, scene="default"):
    weights = source["weights"]
    if scene != "default":
        weights = source["scenes"][scene]
    
    score = sum(
        source["dimensions"][dim] * weights[dim]
        for dim in weights
    )
    return round(score, 2)
```

## 7. 常见问题

### Q1: 没有评分5分怎么办？

```
回答:
5分是理想状态，4分以上就是优质来源
关键是建立分级体系，持续优化
每季度审核一次，逐步提升来源质量
```

### Q2: 如何评估Twitter来源？

```
回答:
Twitter比较特殊，时效性强但准确性参差
建议:
├── 核心KOL给4分(权威+专业)
├── 普通用户一般2-3分
├── 特别关注: 有具体来源的推文
└── 用于发现线索，而非深度信息
```

### Q3: 付费来源值得吗？

```
回答:
看场景:
├── 投资决策: 付费报告有价值
├── 技术研究: 免费公开论文足够
└── 日常追踪: 优先免费来源

原则:
├── 先用免费来源建立基础
├── 发现需求后再考虑付费
└── 评估ROI (时间成本 vs 价值)
```
