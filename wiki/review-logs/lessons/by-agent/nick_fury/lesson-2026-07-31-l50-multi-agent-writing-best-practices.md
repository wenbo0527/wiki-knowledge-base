## L-50.2 4 层 × 4 agent 矩阵（角色不重叠）

**原则**：多 agent 写作 = L4 调度 + L3 创作 + L2 评审 + L1 沉淀。每层 agent 不重叠，升级路径清晰。

```
L4 调度（派蒙）→ L3 创作（Nick/Tony/Zhongli）→ L2 评审（派蒙+文博）→ L1 沉淀（Nick+wiki auto）
```

**可执行动作**：
- 任何任务必先归类到 4 层之一
- 同 agent 不跨层（如 nick_fury 不同时是 L3 + L1）

## L-50.3 派单 3 件套是底线（候选 #117+#129+#172+#235 4 次教训）

**原则**：Task ID + 验收标准 + 截止时间，缺一不可。

**可执行动作**：
- 接派单前必 grep `task_id` + `验收` + `截止`
- 缺任何一项 → 拒绝接单 + sessions_send 派蒙补

## L-50.7 边界守住 5 条（不替决策 / 不脑补 / 不擅推）

| 边界 | 实战案例 |
|:---|:---|
| **不替文博决策** | 调研后给框架 · 决策权在文博 |
| **不假设需求** | 追问场景 → 确认需求 → 给框架 |

**可执行动作**：
- 任何外部动作前必 grep "授权"/"确认"
