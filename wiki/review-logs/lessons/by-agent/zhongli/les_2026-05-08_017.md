## 背景

dfd-app（数据发现域微前端子应用）在 portal-shell iframe 中加载空白，所有 JS 资源 HTTP 200 正常加载，但 Vue 未挂载，无控制台错误日志，`window.dfdApp` 为 undefined。

## 核心教训

### 1. Vite 动态导入 + terser = TDZ 炸弹

**现象**：`__vite__mapDeps` 包装函数访问尚未初始化的跨 chunk 变量。

**触发条件**：
1. Vite 对动态 `import()` 路由页面创建独立 chunks（如 `DiscoveryLayout-xxx.js`）
2. terser 压缩改变了这些 chunks 之间的引用顺序
3. `arco-design` 和 `vue` 的循环依赖通过 `__vite__mapDeps` 被放大

**危险信号**：
- 控制台**完全无日志**（静默失败，JS 在某个 chunk 报错后整体停止）
- 所有资源 HTTP 200，但页面空白
- 路由组件（如 `DiscoveryLayout`）在独立 chunk 中

**解法**：强制所有 vendor 打包到单一 chunk，消除跨 chunk 引用：
```ts
optimizeDeps: {
  exclude: ['vue', '@arco-design/web-vue', 'vue-router', 'pinia', 'echarts']
}
```

> **注意**：`manualChunks: undefined` + 上述 exclude 组合使用才能完全解决问题。单独使用 `manualChunks: undefined`（默认路由分割）时 terser 仍会产生多个 vendor chunks，TDZ 问题依然存在。

### 2. rsync 保留权限是静默杀手

**现象**：`rsync -avz` 默认保留源文件权限，本地 root 构建的 `index.html`（600）上传后 www-data 无法读取，nginx 500 无声发生。

**预防**：
```bash
# 方案 1：rsync 后统一修复权限
rsync -avz --delete dist/ root@host:/var/www/html/app/ && \
ssh root@host "chown -R www-data:www-data /var/www/html/app/ && chmod -R 755 /var/www/html/app/"

# 方案 2：rsync 时指定权限
rsync -avz --delete --chmod=755 dist/ root@host:/var/www/html/app/

# 方案 3：在构建端设置正确权限后再上传
chmod 644 dist/index.html && rsync -avz --delete dist/ root@host:/var/www/html/app/
```

### 3. 502 Bad Gateway ≠ 代码问题

**nginx upstream 无响应**（端口 8081 无服务监听）会直接返回 502，与前端代码无关。

**排查顺序**：
1. `ssh root@host "ps aux | grep product"` 检查后端进程
2. `curl -s http://localhost:8081/api/v1/` 直接测试 upstream
3. `tail /var/log/nginx/error.log | grep 502` 确认 upstream 连接失败
4. 确认控制台是否有 `falling back to mock data` 日志判断是否有 fallback

## 知识卡片

### Vite 生产构建 chunk 策略

| 场景 | 配置 | 风险 |
|:---|:---|:---|
| 默认代码分割 | `manualChunks: undefined` | 多个 vendor chunks，TDZ 风险 |
| 强制单 vendor chunk | `manualChunks(id) { if (id.includes('node_modules')) return 'vendor' }` | 3.5MB gzip 1MB，可接受 |
| 排除特定包 | `optimizeDeps.exclude: ['pkg']` | 配合上面使用，完全消除懒加载 |

### dfd-app 最终配置

```ts
build: {
  rollupOptions: { output: { manualChunks: undefined } },
  optimizeDeps: {
    exclude: ['vue', '@arco-design/web-vue', 'vue-router', 'pinia', 'echarts']
  },
  minify: 'terser',
  chunkSizeWarningLimit: 2000
}
```

## 下次遇到类似问题

1. 先确认是**所有资源 200 但页面空白**（TDZ）还是**资源本身加载失败**
2. 检查控制台是否完全无日志（静默 JS 失败 → TDZ 或模块加载错误）
3. 优先尝试 `optimizeDeps.exclude` 强制打包
4. 部署后立刻检查权限：`ssh root@host "ls -la /var/www/html/app/index.html"`
