## 模块一：AI 产品基础核心概念

### 1.1 基础术语边界

#### 知识点 1：Agent / Workflow / RAG 三者本质区别

| 概念 | 本质 | 核心能力 | 适用场景 |
|:---|:---|:---|:---:|
| Agent | 有记忆、会做决策的智能体 | 自主规划、工具调用、反思迭代 | 复杂任务、多步骤、需要自适应 |
| Workflow | 预设流程的执行器 | 流程编排、节点执行、状态管理 | 固定流程、规则明确、可预测 |
| RAG | 检索增强的问答系统 | 知识召回、上下文增强 | 知识问答、需要最新信息 |

产品设计区别：
- Agent = 规划 + 执行 + 反思（闭环）
- Workflow = 节点 + 路由 + 执行（开环）
- RAG = 检索 + 召回 + 生成（问答闭环）

#### 知识点 2：Function Calling / Skill / Prompt 三层层级关系

| 层级 | 职责 | 产品定义 |
|:---|:---|:---|
| Prompt | 提示词工程，定义输出格式 | 系统提示、few-shot 示例 |
| Skill | 技能封装，一组相关能力集合 | SKILL.md、触发条件 |
| Function Calling | 工具调用，原子化能力执行 | 工具定义、入参出参 |

#### 知识点 3：大模型 / 小模型 / 嵌入式模型 分工与选型

| 模型类型 | 参数量级 | 能力 | 成本 | 适用场景 |
|:---|:---|:---|:---|:---|
| 大模型 | 100B+ | 复杂推理、多模态 | 高 | 核心生成、复杂决策 |
| 小模型 | 1B-10B | 轻量推理、特定任务 | 中 | 路由、判断、过滤 |
| Embedding | - | 向量化、语义编码 | 低 | 知识召回、相似度计算 |

分层降本架构：
用户输入 → 小模型路由/过滤 → 知识召回 → 大模型生成

#### 知识点 4：上下文窗口、Token、轮次、会话 Session 标准定义

| 概念 | 定义 | 计量单位 |
|:---|:---|:---|
| 上下文窗口 | 模型单次能处理的最大 Token 数 | Token |
| Token | 文本最小单元（中文约1-2字，英文约0.75词） | 字符数/词数 |
| 轮次（Turn） | 一次用户输入+模型输出 | 对话轮数 |
| 会话（Session） | 多轮对话组成的完整对话上下文 | 多轮 |

#### 知识点 5：模型上下文漂移 vs 窗口透支

| 现象 | 本质 | 原因 | 治理差异 |
|:---|:---|:---|:---|
| 上下文漂移 | 核心信息被稀释 | 上下文过长，有效信息密度降低 | 定期压缩、摘要 |
| 窗口透支 | 超出窗口限制 | 上下文 > 最大 Token 数 | 截断、拒绝、压缩 |

### 1.2 部署与交付形态

#### 知识点 6：本地 / 私有 / 私有化 / 离线部署 四者区分

| 部署方式 | 定义 | 特点 | 适用场景 |
|:---|:---|:---|:---|
| 本地部署 | 在本地机器运行 | 单机、无网络依赖 | 开发测试、个人使用 |
| 私有部署 | 在客户私有服务器部署 | 独占资源、可控 | 企业内网、数据敏感 |
| 私有化部署 | 完全隔离的定制部署 | 定制化、一次性交付 | 金融、政务、军工 |
| 离线部署 | 完全无网络环境 | 物理隔离、无法更新 | 机密场景 |

#### 知识点 7：公有云 SaaS / 专属云租户 / 本地机房部署

| 部署形态 | 合规适用 | 数据主权 | 运维责任 |
|:---|:---|:---|:---|
| 公有云 SaaS | 通用合规、数据可出境场景 | 云服务商 | 云服务商 |
| 专属云租户 | 金融等保存本地、隔离需求 | 企业 | 企业+云商共担 |
| 本地机房 | 数据不出域，强监管 | 企业 | 企业全担 |

#### 知识点 8：模型部署模式

| 部署模式 | 说明 | 性能 | 成本 | 适用 |
|:---|:---|:---:|:---:|:---|
| 独享实例 | 独占 GPU/CPU 资源 | 稳定高 | 高 | 生产级、高并发 |
| 共享调度 | 多任务共享资源 | 波动 | 低 | 开发测试、低频 |
| 本地私有化镜像 | 完整模型镜像本地部署 | 高 | 高（硬件） | 金融、政务 |

## 模块二：RAG 全链路产品体系

### 2.1 RAG 完整五层架构

#### 知识点 9：RAG 全链路产品职责

文档解析 → 切片分块 → Embedding向量化 → 向量入库 → 召回 → Rerank重排 → 大模型生成

| 层级 | 产品职责 |
|:---|:---|
| 文档解析 | 格式支持、关键信息提取、PDF/Word解析 |
| 切片分块 | 块大小策略、重叠度、语义完整性 |
| Embedding | 模型选型、维度选择、批处理 |
| 向量入库 | 索引类型、分库分表、版本管理 |
| 召回 | 多路召回、TopK、过滤规则 |
| Rerank | 重排模型、评分权重、业务权重 |
| 生成 | Prompt模板、引用标注、格式控制 |

### 2.2 切片与 Embedding

#### 知识点 10：Chunk 分块策略

| 切片策略 | 原理 | 优点 | 缺点 | 选型建议 |
|:---|:---|:---|:---|:---|
| 固定切片 | 按字数/段落硬切 | 简单、可控 | 破坏语义完整 | 简单文档、快速上手 |
| 语义切片 | 按句子/段落语义切 | 语义完整 | 计算成本高 | 复杂文档、高质量场景 |
| 层级切片 | 按文档层级结构切 | 结构保留 | 规则复杂 | 知识库、目录结构重要 |

#### 知识点 11：块大小、重叠度经验值

- 中文：512-1024 字符/块
- 英文：256-512 tokens/块
- 重叠度：10-20%

| 参数 | 太小的影甲 | 太大的影响 |
|:---|:---|:---|
| 块大小 | 丢失上下文、信息碎片化 | 噪声增加、召回稀释 |
| 重叠度 | 上下文割裂 | 冗余增加、成本上升 |

#### 知识点 12：Embedding 维度取舍

| 维度 | 精度 | 存储 | 检索速度 | 适用场景 |
|:---|:---|:---|:---|:---|
| 低维度（256-512） | 较低 | 小 | 快 | 简单语义、精确匹配 |
| 中维度（768-1024） | 平衡 | 中 | 平衡 | 通用场景（推荐） |
| 高维度（1536+） | 高 | 大 | 慢 | 复杂语义、精细差异 |

### 2.3 召回体系

#### 知识点 13-16：召回体系

| 召回类型 | 原理 | 适用场景 |
|:---|:---|:---|
| 关键词召回 | BM25/TF-IDF，词频统计 | 专业术语、精确字段 |
| 向量召回 | 语义Embedding，最近邻搜索 | 语义相似、同义词 |
| 混合召回 | 两路合并+RRF+重排 | 通用场景 |

RRF公式：Score = Σ 1/(k + rank_i)，k通常为60

| TopK | 准确率 | 性能 | 适用场景 |
|:---|:---|:---|:---|
| K=1~3 | 单一最优 | 最快 | 简单查询 |
| K=5~10 | 平衡 | 平衡 | 通用场景（推荐） |
| K=20+ | 召回全 | 慢、噪声多 | 复杂查询 |

### 2.4 Rerank

#### 知识点 17-18：Rerank 核心价值与架构位置

为什么向量相似度不能直接当最终排序？
- 向量相似度 ≠ 语义相关性
- 维度灾难
- 语义漂移
- 业务权重缺失

架构位置：
- 召回层（Recall）→ TopK粗筛（100-500）
- 重排层（Rerank）→ TopN精排（10-20）
- 生成层（Generate）→ 最终使用（3-5）

### 2.5 RAG 工程化治理

#### 知识点 19-21：知识库版本管理、三层过滤、评估指标

版本管理：
| 功能 | 实现方式 |
|:---|:---|
| 版本管理 | 快照+Diff |
| 增量更新 | 增量索引 |
| 过期淘汰 | TTL+状态标记 |

三层过滤：
- 业务维度过滤 → 权限过滤 → 召回过滤 → 最终结果

评估指标：
| 指标 | 定义 | 目标值 |
|:---|:---|:---|
| 召回率 | 相关文档被召回的比例 | >90% |
| 精准率 | 召回内容中相关的比例 | >70% |
| 问答正确率 | 用户满意度/准确率 | >80% |
| 拒绝率 | 无法回答需转人工比例 | <10% |

## 模块三：Agent 核心架构与产品设计

### 3.1 Agent 基础范式

#### 知识点 22：Plan-Act-Reflect

- Plan（规划）：任务分解、工具选择、步骤规划
- Act（执行）：调用工具、获取结果、状态更新
- Reflect（反思）：结果校验、资产沉淀、迭代优化

#### 知识点 23：反思环节三大核心能力

| 能力 | 说明 |
|:---|:---|
| 结果自省 | 比对任务目标和实际输出，识别口径错误、逻辑漏洞 |
| 过程复盘 | 回溯规划路径、工具选择、上下文使用 |
| 资产沉淀 | 修正记忆、迭代Skill规则、补充知识库、归档失败Case |

#### 知识点 24：Agent 设计黄金原则

- 准确优先 > 应答速度
- 模糊不猜 > 臆测回答
- 主动反问 > 沉默处理

### 3.2 记忆体系

#### 知识点 25-27：四层记忆隔离与生命周期

| 层级 | 名称 | 说明 |
|:---|:---|:---|
| L1 | 全局公共记忆 | 共享知识、通用规则 |
| L2 | 任务记忆 | 当前任务上下文 |
| L3 | 会话记忆 | 当前会话历史 |
| L4 | 知识库 | 持久化知识 |

生命周期：短期→长期→归档→淘汰

### 3.3 Skill 工程体系

#### 知识点 28-30：Skill 全生命周期

| 阶段 | 说明 |
|:---|:---|
| 创建 | 定义Skill.md、触发条件 |
| 准入 | 评审、规范检查 |
| 规范 | 命名、参数、输出标准化 |
| 评分 | 使用率、成功率评估 |
| 监控 | 调用链路、质量追踪 |
| 合并 | 相似Skill合并优化 |
| 下线 | 优雅下线、兼容处理 |

Skill vs Prompt区别：
- Prompt：一次性提示词工程
- Skill：可复用、可版本化、有生命周期的能力封装

### 3.4 工具与编排

#### 知识点 31-32：Tools 原子化与多步骤编排

Tools标准：
| 要求 | 说明 |
|:---|:---|
| 原子化 | 单一职责、入参出参明确 |
| 可观测 | 日志、错误码、耗时 |
| 可复用 | 跨Skill调用 |

编排要素：
- 多步骤任务编排
- 分支判断（条件路由）
- 失败重试（指数退避）
- 异常兜底（降级处理）

## 模块四：多 Agent 协作架构

### 知识点 33-37：多 Agent 三种标准架构

| 架构 | 说明 | 适用场景 | 优缺点 |
|:---|:---|:---|:---|
| 主从式 | 主Agent协调，多Worker执行 | 任务分解、并行处理 | 简单高效/单点风险 |
| 对等式 | Agent间平等通信 | 协作决策、专家汇聚 | 灵活/复杂度高 |
| 托管式 | 平台托管任务分发 | 企业级、大规模 | 可控/成本高 |

上下文共享与隔离：
- 共享：全局知识、任务列表
- 隔离：各自记忆、工具权限

跨Agent通信协议：消息队列 / 共享状态 / 事件驱动

租户隔离：知识库私有隔离 + 临时跨租户合规共享流程

## 模块五：AI 产品工程化与稳定性治理

### 知识点 38-39：幻觉三类与溯源机制

| 幻觉类型 | 说明 | 治理手段 |
|:---|:---|:---|
| 知识幻觉 | 知识库无据可查 | 引文透出、来源绑定 |
| 逻辑幻觉 | 推理过程错误 | 步骤验证、逻辑检查 |
| 数值幻觉 | 数字/日期错误 | 精确校验、格式约束 |

溯源机制：引文透出 → 无来源弱标识 → 置信度标记

### 知识点 40-42：限流熔断降级、缓存机制、灰度发布

限流/熔断/降级：
- 限流：并发数限制、Token配额
- 熔断：错误率触发、自动切断
- 降级：功能简化、返回缓存

缓存机制：
| 类型 | 说明 |
|:---|:---|
| 会话缓存 | 多轮对话上下文复用 |
| 冷启动 | 预热常用场景 |
| 热启动 | 保持热点数据 |

灰度发布：按用户 / 部门 / 场景 / 版本 分层放量

### 知识点 43：模型成本治理

分层降本架构：
- 小模型前置过滤（省钱）
- 知识召回（精准）
- 大模型终审（质量）
