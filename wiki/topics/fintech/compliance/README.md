## 核心问题

1. **持牌经营**：哪些主体可以开展金融产品网络营销？
2. **责任边界**：金融机构与平台的责任如何划分？
3. **营销合规**：哪些宣传用语被禁止？
4. **区域限制**：互联网贷款还能异地展业吗？

---

## 合规原则

### 三大核心原则

| 原则 | 说明 |
|------|------|
| **去伪存真** | 清理无资质开展金融业务的主体 |
| **持牌经营** | 只有金融机构和被委托的第三方平台能开展 |
| **划清界限** | 金融机构与平台的责任边界必须清晰 |

### 合规红线

1. **无牌经营**：科技公司/传媒公司不能变相开展金融业务
2. **误导宣传**：不能使用"保本"、"低风险"等用语
3. **平台越位**：平台不能介入合同签订、额度测评等销售环节
