2. **关键 Bug 发现与修复**（防止线上事故）
   - detail.vue 孤儿文件（无路由）→ vite tree-shake 砍了，**dev 改完 ≠ 用户能看到修复**
   - 部署路径坑：nginx alias `/var/www/html/mkt/` ≠ 实际部署目录 `/var/www/mkt/`
   - scp 后 chown 漏 → 403 Forbidden
   - index.html 与 assets hash 不同步 → 浏览器加载错位

3. **部署标准流程沉淀**
   - 总结出 deploy-mkt.sh 5 步法（build→清 assets→同步 dist→chown→curl 验证）
   - **最佳实践**：不信 rsync 成功 / 不信 dev "done"，必须亲自 curl + grep

4. **CC 通道比 OpenClaw LLM 更稳**（长任务场景）
   - qa 跑 Playwright 用 OpenClaw LLM 被 5min timeout 砍
   - 改用 `claude -p` 跑通（CC 没硬超时）
   - **结论**：build/部署/Playwright 等长任务优先走 CC

5. **PM 模型升级生效**
   - 派蒙（PM）从 M2.7+300s 升级到 M3+600s，已生效
   - arch/dev/qa/doc 仍是 M2.7（明日待办）
