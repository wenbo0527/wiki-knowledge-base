### 🏛️ 活动基础信息

本次活动隶属于**世界人工智能大会（WAIC）**系列，落地中国香港举办，是面向AI行业从业者的年度重磅交流盛会。
1.  **活动时间**：2026年1月16日 10:00 - 21:30
2.  **活动地点**：香港科学园12W大楼，覆盖1楼大展览厅、1楼会议厅两大核心区域。
3.  **入场流程**：参会者需完成三步核验入场：第一步在签到处扫码出示门票信息，第二步领取大会专属参会证件，第三步佩戴证件后进入会场。

### 📅 完整活动日程安排

本次盛会设置「同期预热活动」+「主会场全天议程」两大板块，覆盖多维度AI行业交流场景：

#### （一）同期预热活动

| 活动名称 | 举办时间 | 举办地点 | 活动内容 |
| :--- | :--- | :--- | :--- |
| WAIC City Walk(HK) | 2026.1.15 10:00-17:00 | - | 参访香港主流机构、高校和企业 |
| Future Tech Demo Day | 2026.1.15 13:30-17:00 | 香港数码港 | 前沿科技成果展示与路演 |
| WAIC CONNECT | 2026.1.16 13:30-16:30 | 香港科学园 | AI+文化、商业、体育、旅游、教育主题论坛 |

#### （二）主会场全天议程

主会场主题为「WAIC UP! GLOBAL SUMMIT」，完整时间线安排如下：
| 时段 | 环节名称 | 核心主题与内容 |
| :--- | :--- | :--- |
| 08:30-10:00 | Pre-Event Registration | 签到、证件领取、晨间自由交流 |
| 10:00-12:10 | 上午场「Minds Awaken」 | 主题为前沿趋势与生成式未来，包含开幕致辞、3场主旨演讲，覆盖AI产业发展历程、香港AI落地路径、AI科研新方向三大核心议题 |
| 12:10-13:30 | Lunch Break | 大会提供配套商务午餐 |
| 13:30-18:10 | 下午场「Leap & Link」 | 主题为行业应用、创投洞察与全球扩张，设置多场主旨分享与专题论坛，覆盖AI生态构建、AI创新体系建设、量子计算等前沿技术、AI企业全球化布局等热门方向 |
| 18:30-21:30 | 夜晚场「Sparks & Synergy」 | 主题为跨境链接与跨界碰撞，包含AI未来主题脱口秀、深度对话、项目路演、开放式共创交流，同步配套社交晚宴与开放吧台 |
> 补充说明：所有环节日程可能根据现场实际情况微调，实时更新信息将在会场内同步发布。

### 🚶 场地动线与交通指引

#### （一）场地动线布局

会场分布在12W大楼1层，配套区域设置清晰：
- 1F：主盛会活动区、WAIC CONNECT晚餐取餐间
- G层/停车场：午餐餐厅、P3停车场，所有入口均可通过扶梯/电梯直达1F会场
- 周边接驳点：设置的士/巴士落客点、科学廊方向出入口，实现多路径快速抵达会场。

#### （二）多元交通方式指南

| 交通方式 | 详细指引 |
| :--- | :--- |
| 自驾/打车 | 导航定位「香港科学园（三期）12W大楼」，前往P3停车场停放，收费标准为20港币/小时 |
| 地铁+大会班车 | 搭乘东铁线至【大学站B口】出站，步行50米抵达班车接送点搭乘免费班车，非班车时段可选择公交、打车、绿色的士前往园区。大会班车09:10-09:50每10分钟一班，覆盖28座小巴、45座中巴等不同运力车型，返程班车安排可在会场签到处查询 |
| 公交 | 可搭乘#263A、#271B、#43P、#27、#272A / #272K线路，到站后步行即可抵达科学园12W大楼 |

### 📋 参会配套提示
1.  **天气提示**：1月14日-16日活动期间平均气温为13℃-22℃，以晴天为主，参会者可根据体感适当调整着装。
2.  **着装提示**：建议穿着休闲商务装适配多场合交流场景。

4.  会场配套线上入口：设置云相册、门票信息查询双二维码，方便参会者随时调取相关服务。
