## 核心特征

### Agentic Coding vs 传统AI编程

| 维度 | 传统AI编程 | Agentic Coding |
|:---|:---|:---|
| **交互方式** | 单次问答 | 自主规划 + 多步执行 |
| **任务范围** | 单个函数 | 完整功能模块 |
| **错误处理** | 人工修正 | 自我反思 + 自动修复 |
| **上下文** | 短期 | 长期项目理解 |

### 技术特点

1. **自主规划**：理解需求后自主拆解任务
2. **工具调用**：调用IDE、Git、CI/CD等工具
3. **自我反思**：识别错误并自主修正
4. **持续学习**：从项目中学习代码规范
