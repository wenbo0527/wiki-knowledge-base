### 🏆 核心成果是什么？

**9B模型得分近乎翻倍**，接近GPT-5.4水平。
- **训练环境**：共构建 **12个训练世界**（10个深度领域世界 + 2个能力世界）。
- **模型表现**：Qwen3.5-9B 基础分 **36.5% → 67.1%**，距GPT-5.4（80.7%）仅差14分。
- **超越场景**：在EchoMail、EchoBank、嵌套过滤器任务上 **匹配或超过GPT-5.4**。
- **开源内容**：发布4个世界（EchoStay、EchoForge、日期选择器、嵌套过滤器）的代码、数据和验证器。

### 🔄 核心训练循环是什么？

**模型与世界共同进化**，同一次运行同时优化两者。
- **循环流程**：模型在世界中运行任务 → 生成带评分的运行结果 → 失败案例用于训练模型，缺陷用于修复世界。
- **三大杠杆**：
  - **深度**：行为忠实的领域环境（含封闭专有系统）。
  - **能力靶向**：针对模型反复失败的交互构建窄场景。
  - **共同进化**：每次运行都改进环境、任务和验证器，而非仅改进模型。

### 🤔 为什么需要合成世界，而且要"深"？

**真实网站无法用于训练**，浅世界反而会降低模型能力。
- **真实网站问题**：页面会改版、数据会滚动、会限流封禁，基准会漂移，训练需要稳定可重复的环境。
- **深度的5个标准**：
  - **行为保真**：控件、权限、错误遵循产品逻辑。
  - **状态一致**：跨屏幕、跨用户的状态变化连贯。
  - **工作流深度**：早期选择会约束后续操作。
  - **权威验证**：基于应用状态而非像素评分。
  - **领域价值**：工作流本身值得改进。
- **浅世界危害**：训练后模型会养成错误反射（过度点击、循环、重复无效操作），在真实网站上表现反而下降。

### 🏭 Echoverse工厂是怎么运作的？

**两阶段循环流水线**，自动构建世界并生成训练语料。
- **第一阶段：构建世界**
  - 种子场景 → 扩展为规范和声明 → 生成应用（FastAPI + SQLite + React）。
  - 自动验证所有声明，修复数据库/后端/前端，直到全部通过。
- **第二阶段：扩展语料**
  - 基于实时数据库重新生成任务，通过多轮分析器检查（实体真实性、目标合理性、难度匹配、真实UI可完成性）。
  - 失败案例按层级（数据库/后端/前端/任务文本/验证器）修复，回滚回归问题，直到通过率停止上升。
- **验证器机制**：基于数据库真实状态评分（读操作语义等价、写操作前后差异对比），难以被作弊。

### 🗂️ 10个深度领域世界覆盖哪些场景？

**覆盖6大类工作流**，均为真实产品的忠实克隆。

| 工作流类别 | 包含环境 | 核心深度 |
| :--- | :--- | :--- |
| 沟通与协调 | EchoMail、EchoCalendar、EchoChat | 共享线程、日程、权限、历史 |
| 技术创作与运维 | EchoML、EchoForge | 工件、配置、依赖、角色、多阶段变更 |
| 受监管记录与交易 | EchoBank、EchoCare | 余额/记录、授权、审计轨迹、重要写入 |
| 社区媒体与旅行 | EchoForum、EchoTunes、EchoStay | 持久偏好、社交状态、搜索、预订、账户操作 |
- **数据规模**：EchoForum含 **255万条评论**，EchoForge含 **70.5万行数据**（175个项目、8.1万个issue、13.4万个MR）。
- **任务深度**：通常需要5-20步操作，仅当底层状态改变时才算完成。

### 🎯 2个能力世界专攻什么技能？

**日期选择器和嵌套过滤器**，是Agent普遍卡壳的UI控件。
- **日期选择器世界**：6种核心控件类型 × 10种上下文，保留10种未见控件用于评估。
  - 训练效果：分布内 **60.0% → 82.6%**，未见布局 **34.0% → 54.0%**。
- **嵌套过滤器世界**：20种控件家族，保留9种复合面板用于评估。
  - 训练效果：未见过滤器 **62.8% → 84.1%**。
- **技能迁移**：训练其中一项也会提升另一项，同时训练两项在所有拆分上均为最优。
- **泛化效果**：Online-Mind2Web 得分 **29.5% → 34.3%**（未见过的网站）。

### 📊 深度vs浅世界的对比实验结果如何？

**深世界显著提升表现，浅世界反而拖后腿**。
- **Allrecipes站点**：基础80.0% → 浅世界75.0%（降5%）→ 深世界85.0%（升5%）。
- **Hugging Face站点**：基础48.0% → 浅世界48.0%（持平）→ 深世界65.0%（升17%）。
- **差异原因**：深世界训练的模型循环更少，Hugging Face任务中超步长预算的从15个降至9个。

### 🌐 合成训练能迁移到真实网页吗？

**可以迁移**，但提升幅度取决于领域匹配度。
- **整体迁移效果**（无真实网页训练数据）：
  - WebVoyager：**66.5% → 71.5%**（BrowserBase环境）。
  - Online-Mind2Web：**40.5% → 43.4%**（BrowserBase环境）。
- **领域匹配提升**：加入EchoForge（代码托管）训练后，真实GitHub得分 **58.5% → 63.4%**。
- **规模效应**：
  - 增加轨迹数量：域内分数持续上升但收益递减，真实网页迁移早早饱和。
  - 增加环境多样性：合成平均分和WebVoyager得分持续上升，泛化能力更强。
  说白了，训练环境种类多比同一种环境练得多更有用。

### 🧬 共同进化怎么起作用？

**修复世界缺陷能直接大幅提升模型表现**。
- **EchoStay案例**：修复客人数量控件后，可完成预订比例从48%升至78%，模型得分 **16.2% → 38.5%**（翻倍以上）。
- **其他案例**：
  - EchoForum：前端修复+页面加速，37个失败任务从0个解决变为36个解决。
  - EchoChat：验证器与数据重新对齐，可评分任务比例从34%升至99%。
- **核心逻辑**：模型不是唯一在学习的东西，底层的世界、任务、验证器都变好了，模型才能复利提升。

### 🚀 从模仿学习到强化学习有什么提升？

**RL让Agent学会从错误中恢复**，突破模仿学习的天花板。
- **RL设置**：基于5个世界（EchoBank、EchoForge、EchoForum、EchoStay、EchoTunes），每世界约100个困难任务，训练2个epoch。
- **奖励构成**：数据库验证器的轨迹奖励（GPT-4.1）+ 多模态裁判的每步奖励（GPT-4.1视觉）。
- **效果**：保留集裁判得分从 **58% → 69%**，学会了何时停止、何时恢复、何时放弃。

### 🔮 未来方向是什么？

**三方面扩展**，各杠杆相互复利。
- 更多封闭领域的深度世界（公共基准无法覆盖的场景）。
- 更多针对模型失败交互的能力世界。
- 更多基于高保真世界的强化学习（更长运行、更难任务、更广泛奖励探索）。
