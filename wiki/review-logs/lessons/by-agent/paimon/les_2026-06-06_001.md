## 教训沉淀

### 1. 创建软链前必须核查目标路径真实存在
**铁律**：建链前 `ls -la 目标路径/` 至少 3 个文件确认存在，不能信"约定路径"。

### 2. 派蒙维护的不变量（v1.1）
**所有 `{agent}_daily` 软链必须满足**：
- 软链目标路径 `ls` 至少 1 份 `YYYY-MM-DD.md` 文件
- **不能指向"理论上应该存在"的子目录**（如 `daily/`）
- 必须指向 Agent **实际写入**的目录

### 3. 派蒙自检清单（每日 9:00）
- ✅ `for 软链 in /Users/wenbo/.openclaw/memory_share/*_daily; do
       target=$(readlink "$软链");
       count=$(ls "$target"/2026-*.md 2>/dev/null | wc -l);
       [ "$count" -gt 0 ] || echo "❌ $软链 失效 → $target";
     done`

### 4. 跨 Agent 路径对齐 SOP（v1.0 新增）
**所有 Agent 写入日报时**，须在 cron 任务 metadata 注明**实际写入路径**，派蒙建软链时直接复制粘贴，不再"推测路径"。
