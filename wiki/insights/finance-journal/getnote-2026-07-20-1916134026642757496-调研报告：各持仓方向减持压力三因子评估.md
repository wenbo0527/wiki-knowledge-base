## 一、核心发现

**减持压力和估值分位是同一硬币的两面**：PE在98%分位时产业资本疯狂减持（半导体），PE在3%分位时产业资本不愿减持（券商）。原来的⑥只看"大基金减持是否减少"太粗糙，需要升级。

**各方向减持压力差异极大**：

- 零压力方向：券商、银行、上证50
- 低压力方向：创新药（港股）、A500/沪深300、红利
- 极高压力方向：科创50/半导体
- 中高压力方向：中证500

## 三、三因子框架设计

### 原始框架（⑥减持压力释放）

单一指标：大基金减持是否减少 → 定性判断

### 升级框架：三因子复合判断


| 因子          | 指标                  | 数据来源     | 出清触发标准             |
| ----------- | ------------------- | -------- | ------------------ |
| **A. 价格分位** | ETF/指数近1年价格分位       | Wind/雪球  | <30%（价格从高位回落足够多）   |
| **B. PE分位** | ETF/指数PE(TTM)近10年分位 | Wind/估值表 | <40%（估值回到合理区间）     |
| **C. 减持节奏** | 近3个月产业资本减持金额环比变化    | 公告/统计    | 减持金额环比下降>50%且连续2个月 |


**判定规则**：

- 3/3全部触发 → ⑥✅（减持压力充分释放）
- 2/3触发 → ⑥🟡（减持压力部分释放）
- 1/3或0/3 → ⑥❌（减持压力未释放）

## 四、关键洞察

### 1. 减持压力和①估值回归是同一硬币的两面

PE在98%分位 → 产业资本疯狂减持（半导体）
PE在3%分位 → 产业资本不愿减持（券商）

这意味着⑥和①有高度相关性，但不能合并——因为：

- ①看的是"估值是否回到建仓条件"（PE<40倍）
- ⑥看的是"产业资本是否还在出逃"（减持节奏+价格分位）
- 一个方向可能PE已经回到40倍但减持仍在进行（如2021年创业板），或PE还在高位但减持已经放缓

### 2. 不同方向需要不同的⑥触发标准

- **零压力方向（券商/银行/红利）**：⑥根本不需要判断，直接✅
- **已释放方向（上证50/A500）**：⑥主要看资金流向是否反转
- **低压力方向（创新药）**：⑥主要看外资减持节奏
- **极高压力方向（科创50/半导体）**：⑥需要三因子严格判断

### 3. 价格分位的时间窗口选择

你提到看近半年、近1年、近2年的价格分位，建议：

- **近半年**：捕捉短期冲高回落幅度——判断"这次暴跌够不够深"
- **近1年**：看中期趋势——判断"是不是从牛市高点真正回落"
- **近2年**：看长周期位置——判断"当前价格在完整牛熊周期里处于什么位置"

三个窗口交叉验证，避免单一窗口的偏差：

- 如果近半年分位<30%但近2年分位>70% → 说明只是短期暴跌，长期仍在高位（科创50当前状态）
- 如果三个窗口都<30% → 说明真正的底部区域（券商/银行/红利当前状态）

### 4. 减持节奏的数据获取方式

- 大基金减持：上市公司公告（5%以上股东减持必须公告）
- 产业资本减持：Wind统计/雪球汇总
- ETF资金流向：Wind申赎数据（一级市场净申购/赎回）
- 外资流向：北向资金/港股通资金数据

| **科创50**  | 中（+13.31%） | 高（+67.83%）  | 高（~75%）  | ❌ 近半年暴跌21%但近1年+近2年仍高→短期暴跌但长期仍在高位 |
| **红利**    | 低          | 低           | 低（36.8%） | ✅ 三窗口一致偏低→真正底部区域                 |


**关键发现**：

- **三窗口一致偏低**的方向（券商、红利）= 真正底部，减持压力为零
- **近半年低但近1年/近2年仍高**的方向（科创50、中证500）= 只是短期暴跌，长期仍在高位，减持压力仍大
- **近半年+近1年低但近2年中位**的方向（创新药、上证50）= 从高位深度回调，减持压力已部分释放

## 六、⑥与①的关系判断

### 是否合并？

**建议：保持独立但联动判断**

理由：

- ①看"估值是否回到建仓条件"（PE绝对值+分位）
- ⑥看"产业资本是否还在出逃"（减持节奏+价格分位）
- 两者高度相关但不完全同步

**反例证明不能合并**：

- 创新药PE 40.78倍（①未触发<40倍条件），但⑥已经2.5/3（外资减持接近底部+价格分位低）→ 如果合并会误判
- 券商PE 15.19倍（①已触发），⑥也3/3 → 合并不影响判断但增加冗余
- 中证500 PE 35.5倍（①接近触发），但⑥只有0.5/3 → 如果合并会误判为可以建仓

**联动规则**：

- ①✅ + ⑥✅ → 方向可以建仓（券商、红利）
- ①✅ + ⑥🟡 → 方向可以轻仓试水（上证50、A500）
- ①❌ + ⑥❌ → 方向不能建仓（科创50、半导体）
- ①❌ + ⑥🟡 → 方向观望（创新药——PE偏高但减持压力已释放）

## 七、最终框架设计

### ⑥减持压力释放——升级版三因子复合判断


| 因子          | 指标                  | 数据来源          | 出清触发标准                        |
| ----------- | ------------------- | ------------- | ----------------------------- |
| **A. 价格分位** | 近半年+近1年+近2年价格分位交叉验证 | Wind/雪球/东方财富  | 三个窗口中至少2个<30%                 |
| **B. PE分位** | PE(TTM)近10年分位       | Wind估值表       | <40%                          |
| **C. 减持节奏** | 近3个月产业资本减持金额环比变化    | 上市公司公告/Wind统计 | 减持金额环比下降>50%且连续2个月，或方向本身无减持压力 |


**判定规则**：

- 3/3 → ⑥✅（减持压力充分释放）
- 2/3 → ⑥🟡（减持压力部分释放）
- ≤1/3 → ⑥❌（减持压力未释放）

**特殊规则**：

- 零压力方向（券商/银行/红利）→ ⑥直接✅，不需要三因子判断
- 国家队操作方向（上证50/沪深300/A500）→ C因子看资金流向反转而非减持节奏
