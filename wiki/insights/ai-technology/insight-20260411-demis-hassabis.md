# Demis Hassabis：DeepMind CEO关于AGI与AI未来的判断

## 📌 一句话判断

> DeepMind CEO Demis Hassabis在访谈中透露：头部实验室正在用现有模型构建下一代模型，形成"自举效应"——这将关闭中小竞争者的追赶窗口。AGI可能在2030-2035年实现，比工业革命大10倍、快10倍。

---

## 人物侧写

**身份**：Google DeepMind CEO，Isomorphic Labs CEO，2024诺贝尔化学奖得主（AlphaFold）

**行为证据**：
- 2010年联合创立DeepMind
- 每天DeepMind工作结束后，晚上10点开始"第二个工作日"专注药物发现
- 每天与Sundar Pichai通话，DeepMind已成为Alphabet战略核心

---

## 核心观点

### 1. "战时状态"与创业公司式重组

ChatGPT达到1亿用户时，Hassabis在DeepMind内部宣布进入"战时状态"，推动与Google Brain合并（2023年正式完成）。

**关键引言：**
> "Acting almost like a startup, really, to get back to the frontier and be ahead in many areas."

- 合并后获得了DeepMind此前缺乏的大规模算力基础设施
- 用"极致聚焦和节奏"取代了大公司的散漫
- 2026年资本投入$1750-1850亿，几乎翻倍

### 2. "90%的现代AI突破来自我们"

> 约90%的现代AI产业基础突破来自Google Brain、Google Research或DeepMind。

**客观评估**：
- 有依据：Transformer架构(2017)、RLHF早期工作、深度强化学习、AlphaFold
- 但"90%"更像定位声明，而非严格统计

### 3. Scaling Laws远未触顶，但需要1-2个突破

| 判断 | 内容 |
|:---|:---|
| 预训练 | 仍有巨大空间，至少到2027-2028 |
| 后训练 | 推理时计算(inference-time compute)空间巨大 |
| 纯scaling | 大概率不够达到AGI |

**缺失的1-2个突破：**
1. **持续学习（Continual Learning）** - 部署后持续学习，不发生灾难性遗忘
2. **长期记忆/层级记忆** - 超越固定上下文窗口的持久记忆
3. **世界模型（World Models）** - 理解物理、因果、材料、物体行为的内部模拟
4. **高级推理与层级规划** - System 2，融合LLM+搜索/规划

### 4. 自举效应（Bootstrapping Effect）

**最值得深思的判断：**

当前头部实验室正在用现有模型来架构下一代模型，形成"自举效应"——有最好模型的公司获得构建下一代模型的不对称优势。

**这解释了：**
- 为什么Meta砸$143亿买人
- 为什么DeepSeek押注华为芯片（独立路径）
- 为什么Moonshot估值四倍飙升
- **不是因为"还有时间"，而是因为"快没时间了"**

### 5. Isomorphic Labs：第二个工作日

| 维度 | 数据 |
|:---|:---|
| 药物发现 | 晚上10点开始"第二份工作" |
| 2025年4月融资 | $6亿 |
| 合作里程碑价值 | 高达$30亿（Eli Lilly + Novartis） |
| 2026年2月 | 发布IsoDDE药物设计工具（AlphaFold 3准确度翻倍） |
| 2026年晚些时候 | 开始肿瘤学人体临床试验 |

### 6. AGI时间线：5-10年（2030-2035）

| 时间 | 里程碑 |
|:---|:---|
| 2026年 | 世界模型+持续学习原型突破年 |
| 2027年 | 统一基础世界模型与持久记忆融合 |
| 2028年后 | 可能出现自主自我改进循环 |
| 2030-2035 | AGI窗口（偏向较早） |

> "这将比工业革命大10倍、快10倍。" ——Demis Hassabis

## 与文博关注点的交叉

1. **"自举效应"对API创业的警示** - 如果头部实验室用AI构建AI，模型差距将加速扩大。依赖单一模型供应商的产品面临被吞噬风险
2. **"LLM不会商品化"** - 与开源社区"模型趋同"叙事对抗，选择模型供应商比以往更重要
3. **"第二工作日"模式** - 极致创始人精力分配
4. **持续学习+长期记忆** - Agent产品最需要的能力突破
5. **2026年CapEx $1750-1850亿** - AI军备竞赛远未见顶
