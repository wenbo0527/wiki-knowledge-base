## 核心观点

### 1. OpenClaw是"划时代的Agent框架"，不是Claude Code加个UI
罗福莉最初也排斥OpenClaw，觉得"偏运营导向"。但三天体验彻底改变认知：第一天感受到"有灵魂"的产品设计；第二天发现能替代工作；第三天发现能加速研究（2小时做完一个重要研究task）。核心差异：OpenClaw通过精细的Agent框架设计弥补模型短板，而Claude Code只是用最强模型的能力。

### 2. Agent框架能"激发中层模型的上限"
关键发现：接入MiMo-V2（还没做针对性训练的中层模型）到OpenClaw，在85%场景达到接近Claude Sonnet的表现。这意味着：好的Agent框架 + 中层模型 ≈ 顶级模型的可用度。成本逻辑完全变了。

### 3. 范式巨变：Pre-train → Post-train，Chat → Agent
- 用卡比例从3:5:1（研究:预训练:后训练）变为3:1:1
- 顶尖团队预训练和后训练已经1:1
- 核心战场转移到"Agent上怎么做好RL的scaling"
- "上一个时代的成功并不意味着下一个时代的领先，现在基本上大家在同一水平线"

### 4. 1T模型是入场券，但更大的scaling正在决策
- 1T基座是实现接近Claude Opus 4.6水准的入场券
- 但"我们不会在1T水平上走太久"
- 现在立即需要决策：是scaling参数量，还是scaling其他东西？用什么芯片？
- 这个决策决定大半年后谁领先

### 5. Skills = 预训练数据的补充，一种让人主动贡献数据的交互方式
互联网上可访问的知识 ≠ 全部智能。大量企业内部/个人经验是预训练数据里没有的"另类信息"。Skills本质上是一种机制，让人类主动贡献这些信息给Agent。

### 6. 自学习正在发生：模型与Agent框架双向进化
"模型在进步时也改变Agent框架，Agent框架也反过来激发模型能力。" 这不是理论——她在MiMo团队已经观察到：用Opus改好框架 → 切到自家模型 → 发现也很好用 → 用这个框架产生训练数据 → 模型更强。
