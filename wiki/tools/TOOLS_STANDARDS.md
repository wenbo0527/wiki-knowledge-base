## 1. 核心理念

> **"工具原型 > 纯文档"** — 尼克·弗瑞

| 知识形式 | Agent可用性 | 工具价值 |
|----------|-------------|----------|
| 纯文档 | 需理解转化 | ⭐⭐ |
| **工具原型** | **直接调用/组合** | **⭐⭐⭐⭐⭐** |
| 概念描述 | 仅供参考 | ⭐⭐⭐ |

**工具原型的核心价值**：展示能力边界，作为其他工具的输入/输出。

## 2. 准入标准

### 2.1 必须满足的条件

| 条件 | 说明 | 判定标准 |
|------|------|----------|
| **✅ 尼克实际使用** | 必须是尼克正在用的工具 | 已在MEMORY.md或HEARTBEAT.md中记录 |
| **✅ 可执行** | 有完整的运行脚本 | 有依赖声明和执行入口 |
| **✅ 有输出** | 能产生实际结果 | 演示运行效果 |
| **✅ 有文档** | 说明用途和使用方式 | 有README或docstring |

### 2.2 质量分级

| 等级 | 标准 | 说明 |
|------|------|------|
| **⭐⭐⭐⭐⭐** | 核心工具，稳定运行 | 尼克日常使用 |
| **⭐⭐⭐⭐** | 重要工具，定期使用 | 周更或月更 |
| **⭐⭐⭐** | 辅助工具，按需使用 | 手动触发 |
| **⭐⭐** | 实验性工具 | 待验证 |
| **⭐** | 废弃工具 | 移至archived |

### 2.3 格式要求

```markdown
# {工具名称}

> 功能: {一句话说明}
> 状态: {✅稳定|🟡实验|❌废弃}
> 维护者: 尼克·弗瑞
> 创建时间: YYYY-MM-DD

## 功能说明
{详细描述}

## 使用方式
```bash
python3 {tool}.py [参数]
```

## 示例输出
{展示运行效果}

## 维护记录
| 日期 | 更新内容 |
|------|----------|
| YYYY-MM-DD | 创建 |
```

## 3. 目录结构规范

```
tools/
├── README.md                    ← 总索引（必须）
├── {category}/                  ← 按功能分类
│   ├── README.md              ← 分类索引
│   ├── tool-1.py              ← 主工具文件
│   └── tool-1-output.log      ← 可选：运行日志
```

### 推荐分类

| 分类 | 内容 |
|------|------|
| `rss-intelligence/` | RSS情报收集相关 |
| `wiki-maintenance/` | Wiki维护工具 |
| `source-evaluation/` | 信息源评估工具 |
| `daily-report/` | 日报生成工具 |
| `data-analysis/` | 数据分析工具 |

---

## 4. 状态定义

| 状态 | 标识 | 说明 | 处理 |
|------|------|------|------|
| **稳定** | ✅ | 核心功能完成，稳定运行 | 正常维护 |
| **实验** | 🟡 | 功能待验证 | 观察期 |
| **废弃** | ❌ | 不再使用 | 移至archived |

### 状态转换

```
🟡实验 → ✅稳定: 连续运行30天无问题
✅稳定 → ❌废弃: 被新工具替代或需求消失
🟡实验 → ❌废弃: 验证失败
```

---

## 5. 保鲜机制

| 机制 | 说明 |
|------|------|
| **运行日志** | 重要运行记录到 `.log` 文件 |
| **维护记录** | 在README中记录更新历史 |
| **依赖检查** | 每月检查依赖是否过期 |

---

## 6. 禁止事项

| 禁止 | 原因 |
|------|------|
| ❌ 未使用的工具 | 浪费维护资源 |
| ❌ 无法运行的脚本 | 无实际价值 |
| ❌ 无文档的工具 | 他人无法使用 |
