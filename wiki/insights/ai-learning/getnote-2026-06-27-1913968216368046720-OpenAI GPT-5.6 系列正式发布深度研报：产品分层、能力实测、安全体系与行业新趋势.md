### 🏆 发布核心概况

2026年6月27日，OpenAI正式推出GPT-5.6系列大模型，并未采用直接全面开放的模式，而是以**有限预览**的形式先行上线，这是OpenAI迄今发布的最强一代前沿模型，同时完成了自身模型产品线的重新梳理分层。
本次GPT-5.6系列共推出三款定位清晰的型号，命名体系参考了Anthropic的营销思路，以天体名称对应不同能力层级：
| 型号名称 | 产品定位 | 核心特性 |
| :--- | :--- | :--- |
| **Sol（太阳）** | 旗舰前沿模型 | OpenAI当前最强模型，面向高难复杂任务 |
| **Terra（地球）** | 日常工作平衡模型 | 性能可与GPT-5.5竞争，价格仅为GPT-5.5的一半 |
| **Luna（月亮）** | 高性价比轻量模型 | 主打速度快、调用成本低，是系列内最便宜的型号 |

新的命名规则中，数字代表代际，Sol、Terra、Luna后缀直接区分模型的智能水平、响应速度与调用成本，彻底改变了过往OpenAI模型命名体系模糊的问题，让开发者和用户可以快速匹配适配自身需求的产品。

### 📊 核心能力实测表现

GPT-5.6系列的核心能力聚焦于**agentic capabilities（智能体自主执行能力）**，针对复杂、长链条、强上下文依赖的任务进行了深度优化，重点覆盖编程、生物信息学、网络安全三大高门槛场景：
1.  **编程场景**
    在测试命令行复杂工作流能力的Terminal-Bench 2.1基准测试中，全系列模型表现全面领先竞品，具体得分如下：
    | 模型 | Terminal-Bench 2.1得分 |
    | :--- | :--- |
    | GPT-5.6 Sol Ultra | 91.9% |
    | GPT-5.6 Sol | 88.8% |
    | Claude Mythos 5 | 88.0% |
    | GPT-5.6 Terra | 84.3% |
    | Claude Fable 5 | 84.3% |
    | GPT-5.5 | 83.4% |
    | GPT-5.6 Luna | 82.5% |
    | Claude Opus 4.8 | 78.9% |
    | Gemini 3.1 Pro Preview | 70.7% |
    其中新增的Sol Ultra模式支持调度多个子Agent，自动拆分复杂开发任务、分别处理不同环节后汇总结果，大幅提升了真实开发场景下的复杂任务完成效率。
2.  **生物信息学场景**
    在面向长周期基因组学、定量生物分析任务的GeneBench v1评测中，GPT-5.6 Sol相比GPT-5.5不仅取得了更强的性能结果，还实现了更低的资源消耗：在输出tokens数量、模拟延迟、API调用成本三个维度上，均以更少的资源投入拿到了更高的任务得分，对于生物医药研发、实验室科研场景的大规模落地有极高的实用价值。
3.  **网络安全场景**
    在漏洞研究相关的ExploitBench评测中，GPT-5.6 Sol的表现接近Anthropic的Mythos Preview，但仅使用了约三分之一的输出tokens。在UC Berkeley联合前沿实验室打造的ExploitGym评测体系中，全系列模型的安全任务能力均有明显提升。
    OpenAI明确说明，当前Sol仅擅长漏洞发现与修复，尚不能稳定生成端到端完整攻击链，在Chromium、Firefox相关测试中仅能识别基础漏洞组件，未跨过Preparedness Framework中的网络安全关键风险阈值。

### 🔒 全链路安全防护体系

本次GPT-5.6发布中，安全相关内容占据了极大篇幅，OpenAI为全系列模型搭建了**分层安全栈**防护机制，能力越强的模型对应越严格的防护等级：
1.  模型训练层：训练模型主动拒绝违规网络安全请求，可抵御用户伪装、常规越狱等绕过尝试。
2.  生成拦截层：引入实时高风险内容分类器，高风险内容会自动交由更强模型复核后再决定是否输出。
3.  账号管控层：跨对话追踪用户行为与风险信号，精准识别持续性滥用行为。
4.  差异化访问层：针对企业客户提供隐私保护检测、自主安全控制、风险分级访问等定制方案。
5.  持续测试层：投入超过70万A100等效GPU小时开展自动化红队演练，辅以专家人工测试，建立新漏洞快速响应修复流程。

### 💰 定价与上线节奏
1.  **定价体系**（按每百万tokens计费）
    | 型号 | 输入单价 | 输出单价 |
    | :--- | :--- | :--- |
    | Sol | 5美元 | 30美元 |
    | Terra | 2.5美元 | 15美元 |
    | Luna | 1美元 | 6美元 |
    同步升级了prompt caching机制，支持显式缓存断点，缓存生命周期至少30分钟；缓存写入按未缓存输入价格的1.25倍计费，缓存读取可享受90%的费用折扣，大幅降低高频重复场景的调用成本。
2.  **上线安排**
    - 初期仅向约20家经美国政府审核的可信合作伙伴开放，首批入口可能包含亚马逊Bedrock平台，个人用户暂无申请通道。
    - 官方计划未来几周内逐步扩大开放范围，后续陆续覆盖ChatGPT、Codex和更广泛的API用户。
    - GPT-5.6 Sol将于7月登陆Cerebras平台，最高响应速度可达每秒750 tokens，初期同样仅面向部分客户开放。

### 📌 关键行业洞察

本次GPT-5.6的发布标志着前沿大模型的发展进入全新周期：
1.  前沿AI模型的发布节奏已经不再由企业完全自主决定，开始被纳入国家安全与出口管制框架，OpenAI在发布前已向美国政府完整展示模型能力与发布计划，首批访问名单需要经过政府审核。
2.  OpenAI当前的策略是在性能展示、风险管控、商业开放三者之间寻找可控平衡点，既对外证明旗舰模型的技术领先性，也通过严格的安全体系打消监管顾虑，同时逐步争取更广泛的开放权限。
3.  行业已经形成共识：当大模型能力跨过编程、网络安全、生物科研等关键任务阈值后，模型的使用资格、访问权限管控，将成为比性能参数更受关注的核心事项。
