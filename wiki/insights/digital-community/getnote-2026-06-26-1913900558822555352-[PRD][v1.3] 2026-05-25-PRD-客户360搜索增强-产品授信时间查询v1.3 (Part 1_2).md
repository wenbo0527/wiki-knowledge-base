## 三、需求背景

### 3.1 目标

在现有客户360搜索的基础上，新增**产品授信时间查询**模式，支持业务人员快速抽查业务明细数据。同时增强客户详情页字段展示，新增外部系统对接字段，便于业务人员与外部系统数据对照。

### 3.2 业务现状

现有客户360搜索支持两种模式：
1. **精确搜索**：按客户ID精确查询
2. **模糊搜索（模式一）**：按姓名+身份证组合模糊查询

现有客户详情页已实现的字段：
- **客户基本信息**：客户号（内部ID）、姓名、身份证、手机、户籍等
- **授信列表**：授信编号（内部ID）、授信日期、渠道、初始额度等

业务反馈：
- 需要支持按**产品+授信时间**进行查询，以便抽查特定时间段内特定产品的授信客户
- 客户详情页需要展示**三方客户号**和**三方借据号**，以便与外部系统数据对照

### 3.3 痛点

| 痛点 | 描述 |
|:---|:---|
| 痛点1 | 现有模糊搜索无法按产品维度筛选 |
| 痛点2 | 无法按授信时间范围锁定客户群 |
| 痛点3 | 业务抽查效率低，需人工导出数据再筛选 |
| 痛点4 | 客户基本信息缺少三方客户号，无法与外部征信系统数据对照 |
| 痛点5 | 授信列表缺少三方借据号，无法追溯外部借据系统记录 |

### 3.4 核心挑战

| 挑战 | 描述 |
|:---|:---|
| 挑战1 | 数据量大，组合查询性能需保证在2秒内 |
| 挑战2 | 产品下拉需支持模糊匹配，与现有产品中心数据同步 |
| 挑战3 | 授信时间与客户授信记录需准确关联，避免跨客户数据混淆 |
| 挑战4 | 三方客户号/借据号需从外部系统同步，数据一致性需保证 |
| 挑战5 | 外部系统数据可能存在延迟或缺失，需做好容错处理 |

## 四、需求范围

### 4.1 功能范围

本次需求包含两个Feature：

**Feature 1：产品授信时间查询**（搜索模式二）
- **产品下拉搜索**：支持产品名称模糊匹配，自动补全
- **授信时间区间**：支持选择开始日期~结束日期
- **组合查询**：产品名称AND授信时间区间
- **查询结果**：与现有模糊搜索结果格式一致

**Feature 2：客户详情页外部系统字段对接**
- **客户基本信息新增三方客户号**：外部征信系统的客户ID
- **授信列表新增三方借据号**：外部借据系统的借据ID

### 4.2 字段说明

| 字段类型 | 字段名称 | 来源系统 | 说明 |
|:---|:---|:---|:---|
| 内部字段 | 客户号 | 内部系统 | 现有字段，保持不变 |
| **新增外部字段** | **三方客户号** | **外部征信系统** | **外部系统的客户ID，用于与外部数据对照** |
| 内部字段 | 授信编号 | 内部系统 | 现有字段，保持不变 |
| **新增外部字段** | **三方借据号** | **外部借据系统** | **外部系统的借据ID，用于追溯外部记录** |

### 4.3 不在本次范围内

- 精确搜索模式改造（保持不变）
- 模糊搜索模式一改造（保持不变）
- 客户360详情页其他改造（三方客户号、借据号以外的字段）
