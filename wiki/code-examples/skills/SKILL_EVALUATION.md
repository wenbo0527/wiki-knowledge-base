## 2. Skill四维评价模型

### 2.1 维度定义

| 维度 | 权重 | 说明 |
|:---|:---:|:---|
| **完整性** | 30% | Skill结构是否完整，描述是否清晰 |
| **可用性** | 25% | 是否易于理解和使用 |
| **规范性** | 25% | 是否符合OpenClaw Skill规范 |
| **有效性** | 20% | 执行效果和产出质量 |

### 2.2 评分标准

| 等级 | 分数 | 说明 |
|------|------|------|
| ⭐⭐⭐⭐⭐ | 90-100 | 卓越Skill，团队标杆 |
| ⭐⭐⭐⭐ | 75-89 | 优秀Skill，可直接使用 |
| ⭐⭐⭐ | 60-74 | 良好Skill，需小幅调整 |
| ⭐⭐ | 45-59 | 一般，需较大改动 |
| ⭐ | <45 | 较差，不推荐使用 |

## 3. 详细评价标准

### 🔷 完整性 (30%)

| 等级 | 标准 |
|------|------|

| ⭐⭐⭐⭐ | 变量清晰 + 有示例 |
| ⭐⭐⭐ | 基本可理解 |

**检查清单**:
- [ ] 触发条件描述清晰

### 🔷 规范性 (25%)

| 等级 | 标准 |

| ⭐⭐⭐⭐ | 符合主要规范 |
| ⭐⭐⭐ | 基本符合规范 |

**检查清单**:
- [ ] 符合OpenClaw Skill命名规范

### 🔷 有效性 (20%)

| 等级 | 标准 |

| ⭐⭐⭐⭐⭐ | 执行效果好 + 产出质量高 + 反馈优秀 |
| ⭐⭐⭐⭐ | 执行效果较好 |

**检查清单**:

## 4. 入库决策

### 4.1 入库标准

| 类型 | 入库阈值 | 说明 |
|------|----------|------|

| **废弃** | 🔴 | <45 | 不推荐 |

## 5. Skill结构规范

### 5.1 标准目录结构

```
skill-name/
├── SKILL.md              ← 主文件（必须）
├── README.md             ← 简要说明（推荐）
├── references/          ← 参考文档
│   ├── api-details.md   ← API详细说明
│   └── ...
├── scripts/            ← 执行脚本
│   └── run.sh           ← 执行入口
└── CHANGELOG.md        ← 变更日志（推荐）
```

### 5.2 SKILL.md标准模板

```markdown
# {Skill名称}

> 简要描述这个Skill的功能

## 触发条件

当以下情况时使用此Skill：
1. 场景一
2. 场景二

## 执行流程

```
Step 1: ...
Step 2: ...
```

## 输出格式

```json
{
  "key": "value"
}
```

## 错误处理

| 错误 | 处理方式 |
|------|----------|
| 错误一 | 处理方式 |

## 相关文件

| 文件 | 路径 |
|------|------|
| 参考文档 | references/ |

---

*版本: v1.0*
*维护者: {name}*
*最后更新: YYYY-MM-DD*
```

## 8. 评估流程

### 8.1 评估时机

| 时机 | 说明 |
|------|------|
| **新建评审** | 新Skill创建后入库前 |
| **定期复审** | 每季度复审一次 |
| **问题触发** | 发现问题时复审 |
| **版本升级** | Skill重大更新后 |

### 8.2 评估执行

```
1. 读取SKILL.md
2. 检查目录结构
3. 逐维度评分
4. 计算加权总分
5. 确定状态
6. 输出评估报告
```
