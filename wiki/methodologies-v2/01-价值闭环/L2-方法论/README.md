## 二、ROI计算法

### 公式

```
ROI = （收益 - 成本）/ 成本 × 100%
```

### 判断标准

| ROI | 结论 |
|:---|:---|
| > 100% | 强烈建议投入 |
| 50-100% | 建议投入 |
| 0-50% | 谨慎投入 |
| < 0% | 不建议投入 |
