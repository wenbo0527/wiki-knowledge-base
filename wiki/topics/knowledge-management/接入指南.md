## 一、接入流程

### Step 1: 准备文档

将文档放入知识库根目录的对应子目录：

```
/System/Volumes/Data/Users/wenbo/Documents/文档仓库/
├── 产品管理项目/          # Tony (PD-MG)
├── 数字社区项目/          # Tony (PD-*)
├── 行业研究/              # 尼克·弗瑞 (PD-RESEARCH)
├── 技术架构/              # 钟离 (PD-TECH)
└── 知识库配置/
    └── metadata.json      # 文档元数据配置
```

### Step 2: 定义元数据

在文档头部添加元数据（YAML front matter）：

```markdown
---
title: 文档标题
author: Agent名称
product_domain: PD-XX        # 产品域代码
doc_type: PRD/SOP/技术方案/模板/需求/其他
epic: EPIC-XXX             # 关联 EPIC（可选）
tags: [标签1, 标签2]       # 自定义标签
date: 2026-05-18
---
```

### Step 3: 重新索引

文档更新后，Agent 调用知识库工具重新索引：

```python
import sys
sys.path.insert(0, '/knowledge_base/scripts')
from knowledge_tool import knowledge_search

# 验证文档已收录
results = knowledge_search(query="你的文档关键词", top_k=5)
```

## 四、分块规则

### 标题层级分块

文档按 H1/H2/H3 标题自动分块：

```markdown
# 文档标题           → Chunk 1 (H1)
## 第一章            → Chunk 2 (H2)
### 1.1 节          → Chunk 3 (H3)
内容...             → 归属 Chunk 3
### 1.2 节          → Chunk 4 (H3)
内容...             → 归属 Chunk 4
## 第二章            → Chunk 5 (H2)
```

### Token 限制

- 每个 Chunk 最大 **512 tokens**
- 超过按段落二次拆分
- 保留上下文标题信息

## 五、命名规范

### 文件命名

```
格式: YYYY-MM-DD-类型-标题.md

示例:
- 2026-05-18-PRD-客户分群功能.md
- 2026-05-18-SOP-需求拆解流程.md
- 2026-05-18-技术方案-数据同步架构.md
```

### 必填字段

| 字段 | 说明 | 必填 |
|:---|:---|:---:|
| title | 文档标题 | ✅ |
| author | 作者 Agent | ✅ |
| product_domain | 产品域代码 | ✅ |
| doc_type | 文档类型 | ✅ |
| date | 日期 | ✅ |
