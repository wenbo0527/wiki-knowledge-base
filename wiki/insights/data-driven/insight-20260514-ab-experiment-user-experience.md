## 核心问题

### 问题1：实验配置位置的优化

#### 配置复杂性的根源

- **系统流程与业务认知的差异**：AB实验部署涉及前端请求、橱窗内容获取、推荐流程（召回→粗排→精排→打散）等复杂系统链路
- 但实际操作人员通常只了解业务层面

---

## 优化方向

### 1. 配置入口优化

| 优化前 | 优化后 |
|:---|:---|
| 多系统配置 | 统一配置平台 |
| 代码层面配置 | UI可视化配置 |
| 技术术语 | 业务语言 |

### 2. 流量分层简化

```
业务视角：
用户 → 实验A（产品策略）→ 实验B（推荐策略）→ 实验C（营销策略）

技术视角：
同一流量 → 多层正交实验 → 互不干扰
```

### 3. 用户体验提升

| 功能 | 说明 |
|:---|:---|
| **向导式配置** | 分步骤引导配置 |
| **配置预览** | 实时预览配置效果 |
| **冲突检测** | 自动检测配置冲突 |
| **历史版本** | 支持配置回滚 |
