## 一、最小样本量估计

### 场景案例

- **背景**：为未成交用户提供利息减免活动
- **已知条件**：
  - 笔均成交方差 = 500元
  - 95%置信水平下可接受真实成交额浮动 = 50元

### 均值类边际误差公式

```
ξ = z_{α/2} × (σ / √n)
```

| 参数 | 说明 |
|:---|:---|
| **ξ** | 边际误差 |
| **z_{α/2}** | 标准正态分布分位数（95%置信水平对应1.96）|
| **σ** | 标准差 |
| **n** | 样本量 |

### 计算过程

```
50 = 1.96 × (22.36 / √n)
n = 384.16
```

**结论**：最小样本量需 **385笔**

### 实验时间预估

根据实际成交频率推算（如日均成交100笔，约需4天）

### 工具推荐

- 在线样本量计算器：https://www.evanmiller.org/ab-testing/sample-size.html

## 二、灵敏度（MDE）优化

### 核心概念

| 概念 | 说明 |
|:---|:---|
| **MDE (Minimum Detectable Effect)** | 检验中可识别的最小变化程度 |
| **关键影响** | MDE过高会忽略真实效果 |

### MDE与样本量/方差的关系

```
MDE ∝ σ / √n
```

| 关系 | 说明 |
|:---|:---|
| **方差(σ)越大** | MDE越高，灵敏度越低 |
| **样本量(n)越大** | MDE越低，灵敏度越高 |

### 提升灵敏度的实操方法

| 方法 | 说明 |
|:---|:---|
| **降低方差** | 按用户静态维度拆分客群 |
| **选择前置指标** | 如用转化率替代成交金额 |
