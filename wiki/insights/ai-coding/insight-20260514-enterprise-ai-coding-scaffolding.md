# 企业级AI Coding脚手架：从Landing Zone共识到工程化落地

## 核心问题

**现状挑战**：许多团队已理解Landing Zone概念（包含AGENTS.md、Spec文档、门禁与治理红线），但仅通过文档和会议达成的**组织共识不等于工程落地**。

> 各服务仓库中目录结构、Spec表头、Lint规则等需要统一规范。

---

## Landing Zone核心组件

| 组件 | 说明 |
|:---|:---|
| **AGENTS.md** | Agent角色定义、工作方式 |
| **Spec文档** | 需求规格、验收标准 |
| **门禁规则** | 代码质量红线 |
| **治理红线** | 安全、合规底线 |

---

## 工程化落地关键

### 1. 脚手架标准化

```
✅ 统一目录结构
✅ 统一Spec表头
✅ 统一Lint规则
✅ 统一CI/CD流程
```

### 2. 从共识到可执行

| 层次 | 传统方式 | 工程化方式 |
|:---|:---|:---|
| **文档** | Markdown | 可执行脚本 |
| **规范** | 会议传达 | 自动检查 |
| **验收** | 人工Review | 自动化测试 |

### 3. 团队协作模式

```
人类开发者 ←→ AI Coding工具 ←→ 脚手架
     ↑                              ↑
  制定Spec                    自动执行
     ↑                              ↑
  审查结果                    质量门禁
```
