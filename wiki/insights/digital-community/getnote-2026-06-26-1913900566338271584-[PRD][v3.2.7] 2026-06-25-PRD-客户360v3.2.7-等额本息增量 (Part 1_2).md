### 拍 B 理由 4 条

1. **行业标准**：消费金融/银行个人贷款主流方式（央行 2020 指引推荐）
2. **用户体验**：每月还款额固定 → 客户预算规划简单，降低逾期风险
3. **可逆性**：提前还款可减少总利息，客户有选择权
4. **反陷阱**：避免"前期还的全是利息"的认知偏差（前期本金比例逐步上升是行业共识，可解释）

## 四、计算公式（等额本息 B）

### 4.1 核心公式

**每月固定还款额 M**：
```
M = P × r × (1 + r)^n / ((1 + r)^n - 1)

其中：
  P = 贷款本金
  r = 月利率 = 年利率 / 12
  n = 还款期数
```

**每月利息**：
```
interest_t = remainingPrincipal_{t-1} × r
```

**每月本金**：
```
principal_t = M - interest_t
```

**当期剩余本金**：
```
remainingPrincipal_t = remainingPrincipal_{t-1} - principal_t
```

### 4.2 边界条件：r = 0（零利率场景）

```
M = P / n
interest_t = 0
principal_t = P / n
```

### 4.3 数值示例（期数 **B=36 期 · Tony 11:00 拍板** · 200,000 · 年利率 4.35%）

```

```
