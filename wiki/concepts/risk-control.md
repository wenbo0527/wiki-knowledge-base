## 一句话概括

**风险防控 = 识别风险 → 评估影响 → 设计机制 → 持续监控**

---

## 核心问题

| 问题 | 回答 |
|:---|:---|
| **有什么风险** | 风险识别 |
| **影响多大** | 风险评估 |
| **如何控制** | 风控机制 |
| **是否有效** | 持续监控 |

---

## 风险管理流程

```
┌─────────────────────────────────────────┐
│              风险管理                     │
├─────────────────────────────────────────┤
│                                          │
│  ① 风险识别                              │
│      ↓ 识别潜在风险                       │
│  ② 风险评估                              │
│      ↓ 概率 × 影响                        │
│  ③ 风险应对                              │
│      ↓ 规避/转移/减轻/接受                │
│  ④ 监控与复盘                            │
│      ↓ 持续跟踪 + 复盘改进                │
│                                          │
└─────────────────────────────────────────┘
```

---

## 风险分类

| 类型 | 示例 | 控制手段 |
|:---|:---|:---|
| **技术风险** | 系统故障/数据丢失 | 容灾/备份 |
| **业务风险** | 需求变更/市场变化 | 敏捷响应 |
| **合规风险** | 监管要求/法律风险 | 合规审查 |
| **安全风险** | 数据泄露/攻击 | 安全防护 |
| **运营风险** | 人为错误/流程缺陷 | 流程规范 |
