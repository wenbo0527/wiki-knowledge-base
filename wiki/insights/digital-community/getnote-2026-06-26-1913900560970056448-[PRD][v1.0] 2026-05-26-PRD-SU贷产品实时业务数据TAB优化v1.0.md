## 三、需求背景

### 3.1 目标

简化客户360中SU贷产品的"实时业务数据"TAB，精简指标，聚焦授信和用信数据的结构化展示。

### 3.2 现状问题

当前"实时业务数据"TAB包含过多指标，与SU贷产品核心业务无关：

| 当前指标 | 问题 |
|:---|:---|
| 当前余额 | 与授信额度概念重复 |
| 当日放款金额 | 非核心指标，喧宾夺主 |
| 当日还款金额 | 非核心指标，喧宾夺主 |
| 实时利率 | 利率固定，无需实时展示 |
| 风险评分 | 应在风控模块，不在此TAB |
| 逾期天数 | 应在风控模块，不在此TAB |
| 预警等级 | 应在风控模块，不在此TAB |
| 实时交易流水 | 展示过于杂乱，应替换为结构化的用信列表 |

### 3.3 核心挑战

1. **信息聚焦**：删除冗余指标，只保留授信额度、可用额度
2. **结构化展示**：授信列表和用信列表以表格形式展示
3. **数据一致性**：授信/用信数据需与业务系统实时同步

## 四、需求范围

### 4.1 功能范围

| 功能 | 说明 | 优先级 |
|:---|:---|:---:|
| 授信额度展示 | 展示客户在SU贷产品的总授信额度 | P0 |
| 可用额度展示 | 展示客户当前可用授信额度 | P0 |
| 授信列表 | 表格展示客户授信记录（产品、额度、状态） | P0 |
| 用信列表 | 表格展示客户用信/贷款记录（产品、金额、状态） | P0 |

### 4.2 删除内容

| 删除项 | 原因 |
|:---|:---|
| 当日放款金额 | 非核心指标 |
| 当日还款金额 | 非核心指标 |
| 实时利率 | 利率固定，无需实时展示 |
| 风险评分 | 风控模块，不在此TAB |
| 逾期天数 | 风控模块，不在此TAB |
| 预警等级 | 风控模块，不在此TAB |
| 实时交易流水 | 替换为结构化的用信列表 |

### 4.3 不在本次范围内

- 其他产品域的实时数据TAB
- 实时数据推送功能（仅展示）
- 风控相关指标
