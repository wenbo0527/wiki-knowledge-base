# 案例-数据门户设计模式

> 版本: v1.0
> 创建: 2026-05-13
> 类型: 文博实战萃取
> 涉及能力: 04产品设计

---

## 一、项目背景

### 1.1 项目信息

| 字段 | 内容 |
|:---|:---|
| **项目名称** | 数据门户 |
| **公司** | 苏银凯基 |
| **时间** | 2023-2024年 |
| **类型** | 数据中台/数据平台 |
| **规模** | 700+数据表统一管理 |

### 1.2 业务挑战

| 挑战 | 说明 |
|:---|:---|
| **表太多** | 700+数据表，散落在各处 |
| **找不到数** | 不知道哪些表在哪里 |
| **不敢用** | 不知道表的质量和含义 |
| **不敢信** | 不知道数据是否准确 |

---

## 二、解决方案

### 2.1 产品定位

| 定位 | 说明 |
|:---|:---|
| **统一入口** | 找数、用数的统一平台 |
| **知识沉淀** | 数据资产的知识管理 |
| **质量保障** | 数据质量的评估和监控 |

### 2.2 核心功能

| 功能 | 说明 |
|:---|:---|
| **数据目录** | 700+表的目录和检索 |
| **表说明** | 每个表的业务含义说明 |
| **字段说明** | 每个字段的定义和口径 |
| **血缘关系** | 表与表之间的关系 |
| **质量评分** | 数据质量的可视化评分 |

---

## 三、设计模式萃取

### 3.1 数据字典模式

```
┌─────────────────────────────────────────┐
│           数据字典核心要素               │
├─────────────────────────────────────────┤
│                                         │
│  表基础信息                              │
│  ├── 表名（英文）                        │
│  ├── 表名（中文）                        │
│  ├── 所属主题                            │
│  ├── 负责人                             │
│  └── 更新频率                            │
│                                         │
│  业务含义                                │
│  ├── 表描述                              │
│  ├── 字段列表                           │
│  │   ├── 字段名（英文）                  │
│  │   ├── 字段名（中文）                  │
│  │   ├── 数据类型                       │
│  │   └── 业务定义                       │
│  └── 样例数据                           │
│                                         │
│  技术信息                                │
│  ├── 数据源                             │
│  ├── 调度周期                           │
│  └── 存储量                             │
│                                         │
└─────────────────────────────────────────┘
```

### 3.2 标准化模式

| 标准化项 | 说明 |
|:---|:---|
| **命名规范** | 英文缩写+下划线 |
| **码值规范** | 枚举值标准化管理 |
| **口径统一** | 指标口径唯一 |
| **质量规范** | 空值率/重复率标准 |

## 四、产品设计原则

### 4.1 极简智能

| 原则 | 落地方式 |
|:---|:---|
| **智能推荐** | 基于用户行为推荐相关表 |
| **语义搜索** | 支持中文描述搜索 |
| **智能解释** | AI解释字段含义 |

### 4.2 一致性

| 原则 | 落地方式 |
|:---|:---|
| **风格统一** | 全平台UI一致性 |
| **交互统一** | 操作体验一致 |
| **术语统一** | 专业术语统一 |

### 4.3 可控性

| 原则 | 落地方式 |
|:---|:---|
| **权限清晰** | 表级别权限控制 |
| **操作留痕** | 所有操作可追溯 |
| **质量透明** | 质量评分可见 |

---

## 五、效率提升

| 指标 | 提升效果 |
|:---|:---|
| **找数效率** | 从3天→10分钟 |
| **用数门槛** | 从需要IT→自助 |
| **数据质量** | 问题发现率提升80% |
