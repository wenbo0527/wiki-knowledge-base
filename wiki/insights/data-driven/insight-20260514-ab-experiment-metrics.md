## 指标选择框架

### 1. 基础指标要求

| 要求 | 说明 |
|:---|:---|
| **可测量** | 能被数据化 |
| **可归因** | 能追溯到实验原因 |
| **可重复** | 同样条件能得到同样结果 |
| **有时效** | 在实验周期内能观察到变化 |

### 2. 统计指标

| 指标 | 说明 |
|:---|:---|
| **显著性水平** | 判断差异是否显著的标准 |
| **统计功效** | 正确检测出真实差异的概率 |
| **灵敏度** | 检测微小变化的能力 |
| **最小样本量** | 达到统计显著所需样本数 |

## 业务决策指标

### 决策层级

```
北极星指标
    ↓
辅助指标
    ↓
护栏指标
```

| 层级 | 作用 | 示例 |
|:---|:---|:---|
| **北极星** | 核心衡量标准 | DAU、留存 |
| **辅助** | 辅助理解 | 转化率、时长 |
| **护栏** | 保障底线 | 错误率、延迟 |
