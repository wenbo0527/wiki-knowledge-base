## 一、背景

### 1.1 问题背景

文博的Wiki知识库需要优化两个使用场景：

| 场景 | 使用者 | 核心需求 |
|:---|:---|:---|
| **Agent访问** | 托尼/钟离/尼克 | 执行效率+机器可读 |
| **人类阅读** | 文博/团队 | 可读性+快速理解 |

**RAG场景**：由Tony的知识库系统（knowledge_base）处理，不需要Wiki侧优化。

### 1.2 Tony RAG系统现状

Tony已实现完整的RAG系统：

```
文档仓库（688个.md）
    ↓
parse_documents.py（按H1/H2/H3分块）
    ↓
bge-m3向量化 + Chroma存储
    ↓
混合检索（向量+BM25+RRF）+ Cross-Encoder重排
    ↓
API → Agent调用（localhost:8082/search）
```

### 1.3 Wiki优化目标

- **Agent访问**：支持渐进式加载，提升执行效率
- **人类阅读**：快速理解核心要点，降低阅读成本

## 二、优化方案

### 2.1 Agent访问优化

#### 目标
让Agent能够快速找到执行任务所需的知识，并按需加载详细内容。

#### 方案：SKILL.md + 渐进加载

```
Agent启动 → L1索引加载（~1000 tokens）
         → 匹配场景 → L2按需加载（~3000 tokens）
         → 执行任务 → 结果反馈
```

#### 2.1.1 SKILL.md结构

**文件位置**：`Wiki/insights/{topic}/SKILL.md`

```markdown
# {Topic} SKILL

> 版本: v1.0
> 更新: 2026-05-21
> 维护者: 尼克·弗瑞

## L1 执行索引（Agent启动时加载）

### 能力概览
[简洁描述这个Skill能让Agent做什么]

### 场景映射表
| 场景 | 文档路径 | 触发关键词 |
|:---|:---|:---|
| 场景A | insights/xxx.md | 关键词A, 关键词B |
| 场景B | insights/yyy.md | 关键词C, 关键词D |

### 元数据
- **适用范围**: [Agent类型]
- **依赖**: [前置Skill或知识]
- **产出**: [执行结果]

## L2 详细内容（按需加载）

### 执行模板
[具体的执行步骤/模板]

### 案例
[实际案例]

### 注意事项
[常见问题/避坑指南]
```

### 2.2 人类阅读优化

#### 目标
让人类读者能够快速理解文档核心要点，降低阅读成本。

#### 方案：文档头模板 + TOC自动生成 + 排版规范

#### 2.2.1 文档头模板

```markdown
---
title: "文档标题"
date: 2026-05-21
author: 尼克·弗瑞
tags: [tech-understanding, agent-skills]
---

# 文档标题

> **TL;DR**: 一句话核心总结（50字内）

## 关键洞察
- 洞察1
- 洞察2
- 洞察3

## 目录
- [背景](#背景)
- [分析](#分析)
- [建议](#建议)

---

## 背景
[背景说明]

## 详细内容
...
```

#### 2.2.2 TL;DR规则

| 规则 | 说明 |
|:---|:---|
| **字数** | 50字以内 |
| **位置** | 文档开头，blockquote格式 |
| **内容** | 一句话总结核心观点 |
| **语气** | 结论性，避免疑问句 |

#### 2.2.3 关键洞察规则

| 规则 | 说明 |
|:---|:---|
| **数量** | 3条（不超过5条） |
| **格式** | 无序列表 |
| **内容** | 核心发现/关键结论 |
| **排序** | 重要性降序 |

#### 2.2.4 TOC自动生成规则

| 规则 | 说明 |
|:---|:---|
| **层级** | 提取H2、H3标题 |
| **格式** | Markdown链接 |
| **位置** | TL;DR之后，正文之前 |
| **示例** | `- [背景](#背景)` |

#### 2.2.5 排版规范

| 元素 | 规范 |
|:---|:---|
| **标题层级** | H1仅文档标题，H2/H3用于章节 |
| **列表嵌套** | 不超过2层 |
| **代码块** | 必须标注语言类型 |
| **表格** | 必须有表头 |
| **引用** | 使用>块引用，标注来源 |

#### 2.2.6 实现步骤

```
Step 1: 制定文档头模板规范
Step 2: 编写TOC自动生成脚本（可选）
Step 3: 更新现有高频文档（优先insights）
Step 4: 制定排版规范文档
```

## 四、示例

### 4.1 agent-skills SKILL.md示例

```markdown
# Agent Skills SKILL

> 版本: v1.0
> 更新: 2026-05-21
> 维护者: 尼克·弗瑞

## L1 执行索引

### 能力概览
本Skill涵盖Agent技能的设计、开发、评测全流程，适用于需要构建或优化Agent技能的场景。

### 场景映射

| 场景 | 文档路径 | 触发关键词 |
|:---|:---|:---|
| 技能设计 | insights/agent/agent-skills/skill-design.md | 设计技能、创建Skill |
| 技能评测 | insights/agent/agent-evaluation/ | 评测技能、benchmark |
| 技能优化 | insights/agent/agent-skills/skill-optimization.md | 优化技能、迭代 |

### 元数据
- **适用范围**: 所有Agent（托尼/钟离/尼克）
- **依赖**: 无
- **产出**: Skill设计文档/评测报告

## L2 详细内容

### 技能设计模板

**触发条件**：用户提到"设计技能"或"创建Skill"

**执行步骤**：
1. 确定技能边界（name/description/location）
2. 编写SKILL.md结构
3. 配置渐进式加载
4. 编写测试用例

### 案例
[见 skill-design.md]

### 注意事项
- name必须唯一
- description不超过100字
- location使用绝对路径
```
